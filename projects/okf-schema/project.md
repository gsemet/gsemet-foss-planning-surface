# OKF-Schema

Structured OpenKnowledge Format

Subsets:
- **okf-schema**: add JSON Schema to your OKF bundle
- **okfreq**: add traceability from code and test to 2 levels of requirements
- **okfkb**: maintain a knowledge base with unfalsiable "findings" at the bottom, never directly read, to facts ans structure build on top, used by agent to discover the current "truth".
