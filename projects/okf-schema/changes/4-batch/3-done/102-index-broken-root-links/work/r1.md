## Open points

1. `just preflight` cannot pass on this host without the symlink privilege; the 8 tests above
   need a host that has it (the CI jobs, or Windows with Developer Mode).
2. Behaviors seen, outside this change and left as they were: `index` drops the blank line between
   two paragraphs of a non-root index introduction (seen in step 4 on `api/index.md`); a directory
   that holds only subdirectories gets no `index.md`, so its parent line is the generic sentence;
   a schema with neither `x-okf-summary` nor `description` still writes an empty summary.
3. Limits of the literal specification: only lines starting with `<!--` are skipped, so the
   following lines of a multi-line comment enter the introduction; in a linked image
   `[![i](a.png)](b)` only the inner link is matched; backslashes in authored targets are kept.
   `is_broken_link` reports a `%00` target, and a target that looks external only once decoded,
   as broken.
