   that permits symlinks; the 7 new symlink cases and acceptance test 14 need that run too.
2. Deviation from the specification's wording "(Path.resolve(), links followed)": the code
   uses `os.path.realpath` (`_real_path`). With Python 3.12 and older, `Path.resolve()` raises
   `RuntimeError` on a link loop, which would turn today's "Concept not found" into a
   traceback. Reproduced with a junction loop on 3.12.10 (`work/scratch/probe_loop.py`). A
   test for the loop was added (marker CORE-005#S2).
3. Requirement wording: the specification's `<path>`, `<bundle>`, `<bundle name>.md` and
   `<name>.md` made `--prose` report W002 (unfilled placeholder) on CORE-005 and CORE-010; the
   requirements guideline says to replace every angle-bracket placeholder. They now read
   `PATH`, `BUNDLE`, "a file named like the bundle folder with `.md` added" and "the same
   name with `.md` added". The meaning is unchanged.
4. A refusal, with its exact text. A Write of a probe script to the session scratchpad got:
