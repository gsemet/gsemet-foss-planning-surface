CR-101 scenario steps, real runs of the package built from the worktree.
<worktree> = the CR worktree; <disposable> = a fresh folder under work/scratch.
Paths are absolute where the specification writes them relative to <disposable>.

[1-init] PowerShell
$ uv run --no-sync --project '<worktree>' -- okf-schema init '<disposable>/my-knowledge-base'
Created OKF bundle '<disposable>/my-knowledge-base'.
exit code: 0

[2-new] PowerShell
$ uv run --no-sync --project '<worktree>' -- okf-schema new --path '<disposable>/my-knowledge-base/bundle' --name api/health-check
Created concept '<disposable>\my-knowledge-base\bundle\api\health-check.md'.
exit code: 0
