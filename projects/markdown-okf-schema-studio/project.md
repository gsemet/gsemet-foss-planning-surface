# Markdown OKF-Schema Studio

Schema-aware Markdown editor and live preview for OKF bundles: a VS Code extension where you read
a clean rendered page and click any block to edit its source. It renders CommonMark, GitHub
Flavored Markdown, Sphinx MyST, OKF and OKF-Schema.
