# CR-450 round 1: campaign facts (for the later note)

Written by the round-1 Coder. Sample: `src/core/find`, `src/core/syntax`, `src/core/scroll` (4 files, 767 mutants). Evidence: `evidence/r1-evidence.md`; logs: `work/logs/`.

- Command: `just mutation-core "src/core/find/**/*.ts,src/core/syntax/**/*.ts,src/core/scroll/**/*.ts"` (compile, `ts7-checker.mjs --self-test`, core phase, others phase, `mutation-report.mjs`). The Stryker binary is run as `node node_modules/@stryker-mutator/core/bin/stryker.js run <config>` (`npm exec -- stryker` ended silently under `fnm exec` on Windows).
- Concurrency: Stryker default (15 on 16 CPUs): 8 checker processes (each its own `tsgo`) and 7 test-runner processes. No override.
- Checker: whole-program TS 7 check, one mutant per check, 1.86 s per check alone, 2.1 s with 8 processes at once. Results: 111 of 767 CompileError.
- Mechanism for test IDs: a `--import` preload (`scripts/mutation/node-test-preload.mjs`) hooks `Module._load` so `require("node:test")` returns a Proxy; it wraps `test`, `it`, `describe`, `suite` (and `skip`, `todo`, `only`), sets `__stryker__.currentTestId`, and writes one JSON per test file at exit. Installed only when `NODE_TEST_CONTEXT` is set (the per-file child of `node --test`). ID = `<file relative to out/test>::<describe > test>` (` #n` for repeats). Load-time coverage of a file is credited to each test that ran in it (mt-Q9); reported static coverage is empty. The per-test fallback was not needed.
- Bail: core phase off (`killedBy` lists every failing test: 263 of 366 killed mutants have several killers); others phase on.
- Results (core): 366 Killed, 77 Timeout, 198 Survived, 15 NoCoverage, 111 CompileError, 0 Ignored. Score: find 78.6, scroll 67.8, syntax 65.3. Others phase killed 17 of the 213 holes (syntax only); 196 holes no test kills.
- Timing: core 25 min 02 s (dry run 1 min 25 s, 1396 tests); incremental rerun of the unchanged sample 1 min 13 s; others 19 min 44 s (dry run 2 min 49 s, 2938 tests, 371 mutants for 136 hole ranges).
- Projection: 29,049 mutants x 1.96 s = 15.8 h for the core phase alone, about 23 h with the others phase: over the 6 h rule. 2.9 s per core mutant with both phases, so at most about 7,400 mutants in 6 h; recommended sample at most 6,000 mutants (about 4.8 h), by sub-folder. Checker alone: 29,049 / 3.8 per s = 2.1 h, in parallel with the tests.
- Files left out of the core phase: none (144 files matched, 0 left out; 3 tests marked `needsSymlinks` are skipped by their own options on Windows and get no coverage). Others phase, left out with reasons (their tests need the real checkout): `out/test/build/lineEndingFixtures.test.js` (asks git for tracked CRLF fixtures; the sandbox copy is not tracked), `out/test/build/readmeCommentThreads.test.js` (README images are not copied: `ignorePatterns` `/images`). Found by the first others dry run, which failed on them.
- Windows path findings: `.stryker-tmp` (default `tempDirName`) works, no path-length error; sandbox build `npm run compile` works because the sandbox is under the project (tsc and types resolve from the root `node_modules`). A timed-out `timeout 60 stryker` leaves the checker and runner children alive (kill by command line), tree kill in the runner uses `taskkill /T /F`. Stryker's `mutate` range is `file:line:col-line:col` with 1-based lines and 0-based columns, the report 1-based columns: `holeRanges` subtracts 1 (the first version did not, and the others phase then reached only 66 mutants).
- Plugins file loading: plain `node` loads `.mjs` plugins by absolute path; `tsconfigFile` is an absent name so Stryker core never imports `typescript`.
- Ignorer: no mutant of the three folders matched a rule; proven on `src/core/protocol/router.ts` (1 Ignored: "thrown error message (new Error)").
- Reader notes: the test universe is the whole `test/core` (1396 tests), so with a sample the zero-kill (498) and redundant (513) lists include tests of other folders that only load the sampled modules (their load-time coverage). Read them with that in mind; a later round with the whole of `src/core` removes the effect. Others-phase Timeouts (85) are not counted as kills.
- Evidence of the reading of the report on SwRS: `StRS`/`SwRS` IDs come from `@tests_req` markers above or inside the test and from `*.markers.ts` companions (scenario text match); 234 IDs scored.
