# Clip: keyboard navigation in nested admonitions and lists

New feature clip, longer than usual: keyboard navigation while editing a complex file, with nested admonitions and lists. The mouse is never used.

Show how easy it is to enter editing (the `e` key), go down to the block to edit (for example a list), and go right to descend through the levels.

Scenario, fairly complex: a page with an admonition that holds text and a list.
1. Select the admonition and press Enter: the whole block enters editing.
2. Escape to leave editing.
3. Right to enter the admonition's text.
4. Down to reach the list inside the admonition.
5. Right to select the list.
6. Edit (`e`), change one word.
7. Ctrl/Cmd+Enter to validate.
