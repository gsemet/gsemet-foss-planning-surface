# Short video: S3: "Edit where you read"

Status: scenario draft, 2026-10-28. Common rules: [00-common.md](00-common.md).

| Time | Frame | Subtitle |
| --- | --- | --- |
| 0–2 s | Wide: the preview; a paragraph with a visible typo, a small table right below it. | *Spot a mistake?* |
| 2–6 s | Click the paragraph: its raw Markdown opens in place. Fix the word, select a phrase, Cmd+B, Done. | *Fix it in place.* |
| 6–10 s | Click a table cell: it becomes editable in place. Type the new value, Tab to the next cell, type, Enter. | *Even in a table cell.* |
| 10–12 s | Overlay: `git diff` showing only the changed lines (the paragraph line and the table row). | *Only what you touched changes. No reformatting.* |
| 12–15 s | End card. | |

Zoom: one, 1.3x framing both the paragraph and the table, 2–10 s (the demo document places the
table right under the paragraph so one frame holds both edits).
