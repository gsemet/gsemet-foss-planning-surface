after the layout. A scroll that arrives before that pass is taken back and the page reports nothing,
so the test waited for a report that never came. Made deterministic with a temporary probe: scroll
asked to 300, page back at 200, no report, 5 of 5 (`evidence/local/r4-b1-race.txt`; probe in
`work/scratch/r4-race-probe.py`).

scroll; after the edit mode click, one zero-delay timer turn (the click sets one) and two frames.
