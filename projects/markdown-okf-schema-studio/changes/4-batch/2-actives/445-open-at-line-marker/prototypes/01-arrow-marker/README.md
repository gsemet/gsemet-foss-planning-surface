# 01-arrow-marker

Static mockup of three ways to mark the target line in the Studio page, shown to the owner during
the grill (open-at-line-Q6): A arrow in the left margin plus a light band on the exact line, B the
arrow alone, C an outline of the whole block (the look of `markEditorSelection` today).
It is an inline visualization fragment (no `<html>`): it uses the chat host's CSS variables and
Tabler icon font, so it renders as intended only in the chat's widget; opened alone it shows the
layout without colours. Nothing to run.
