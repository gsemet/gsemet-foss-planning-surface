## Deviations and notes for the Inspector

- Fixture number: the spec says 94, but `94-line-marker-precision.md` exists, so the fixture is `95-blank-lines-in-containers`.
- Changed assertion (spec Evidence): in `test/page/runtimeBlankLines.test.ts` the test "a run inside a fence or inside a list of an admonition shows no blank-lines block" became "a run inside a fence in a list item shows no blank-lines block". Its admonition half asserted the old behaviour (nothing shown); the new behaviour is covered in `runtimeBlankLinesContainers.test.ts`.
- The new page tests sit in a second file because `runtimeBlankLines.test.ts` would pass 800 lines; the harness helper is duplicated locally.
- A context-tag panel needs a blank line after its opening tag and before its closing tag to render as a panel (otherwise the opening tag starts an HTML block); the fixture does so.
- The visual fixture starts with a plain paragraph: the shared "paragraph after an admonition keeps the body colour" check takes the first paragraph of the page as its baseline.
- Spec tab example (r1): the real result with a tab after the marker is five spaces after the marker; the core test asserts it.
- `pageToHost.test.ts` checks `containerLine` accepted below `line`, refused at or after it, non-integer, together with `itemLine`, and on a type that takes no run.
