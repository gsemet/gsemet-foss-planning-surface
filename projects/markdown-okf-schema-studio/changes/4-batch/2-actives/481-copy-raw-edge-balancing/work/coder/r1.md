## Hand-over note

- Deviation: enclosure (which construct holds an edge) comes from my own source line scan, `src/core/mapping/rawCopyScan.ts`, not from the frames. The frames are used only for snapping an unplaced edge to its element (SwRS 286).
- Enclosure is strict: a node encloses an offset when `start < o < end`; an edge exactly at a container's end is not enclosed (so `## Hello` from "llo" to the line end gives `## llo`, and an admonition-title end edge gets the closing line).
