# A video gallery on the Pages site, then light GIFs in the README

The owner asks for a new gallery on the GitHub Pages site, dedicated to videos: it gathers the
videos published for the application. Later, the owner and the Chief of Staff choose together some
of these videos to put in the README as fairly light GIFs that illustrate features.

Priority given by the owner: P2.

The owner's words (2026-11-26), verbatim:

"En P2 aussi, il faut que tu rajoutes une nouvelle galerie dédiée aux vidéos. C'est-à-dire que je
veux une galerie sur le site GitHub Pages qui soit en fait la galerie qui rassemble les vidéos qui
sont publiées sur l'application. Et ensuite, on réfléchira ensemble à quelques-unes de ces vidéos à
mettre en GIF assez léger dans le README pour illustrer certaines des features."

Not decided yet, to grill: which videos count as published and where they live today, the second step
(choice of the videos and the weight limit of the GIFs) and whether it is a CR of its own.
