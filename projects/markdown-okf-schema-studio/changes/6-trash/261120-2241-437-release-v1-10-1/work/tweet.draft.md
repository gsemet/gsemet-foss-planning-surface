# Announcement thread for 1.10.1

## 1/

On my Windows machine, I opened a block editor in a Markdown file with CR LF line endings, left it
without changing anything, and the page stayed on "Saving Markdown..." until I reloaded it. 1.10.1
fixes that, and a block you edit now keeps the line endings of its file.

## 2/

The details are in the release notes:
https://github.com/gsemet/markdown-okf-schema-studio/releases/tag/v1.10.1
