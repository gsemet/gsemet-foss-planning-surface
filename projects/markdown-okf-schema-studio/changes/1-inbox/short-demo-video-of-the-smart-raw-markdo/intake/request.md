# Short demo video of the smart raw Markdown copy

Filed by markdown-okf-schema-studio's Chief of Staff, on the owner's word (2026-11-24).

## Request

Make the short demo video of the smart copy-paste feature: Ctrl/Cmd+C on a selection in the
preview copies the exact raw Markdown under it (and the rendered HTML for a rich editor), in read
and edit mode (PR https://github.com/gsemet/markdown-okf-schema-studio/pull/498), with the
`preview.rawCopy.balanceEdges` setting that completes the copy at the selection's edges (PR
https://github.com/gsemet/markdown-okf-schema-studio/pull/499).

The owner writes the scenario and records the video with a Griller session, in this CR.

## Context

- The process is `docs/demo-video/guidelines/short-demo-process.guidelines.md` in the project.
- The feature clips kit from CR-482 (PR https://github.com/gsemet/markdown-okf-schema-studio/pull/501)
  may help for site clips; this CR is the short demo video.
- The owner wants this video before the 1.13.0 release, which will ship the feature; the release
  notes and announcement may use it.
- Not yet proved in a real VS Code window: context-menu Copy, macOS Cmd+C, paste into a rich editor,
  mouse-drag selection. The recording is a chance to see the real-window behaviour.
