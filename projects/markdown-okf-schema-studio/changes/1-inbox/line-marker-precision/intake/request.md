# Line marker: table row, hidden tab-set item, front matter row

Split off from CR open-at-line-marker (2-backlog/P3), decision 31 (decided by the Griller under the owner's autonomy rule, 2026-11-21, from the spec critic's finding 10). When Studio opens at a requested line and marks it (arrow in the left margin and light band, from open-at-line-marker), make the marker precise in three more places that CR leaves at the top of the enclosing block: (1) a table: the row of that line (header row on the table's first line, the delimiter line to the header row, body row n on the table line plus n+1); (2) a line inside a non-selected {tab-item} of a {tab-set}: select that tab first, like an unfold, then mark the line; (3) a line in the front matter: mark the property's row in the properties table, else the top of the table.
