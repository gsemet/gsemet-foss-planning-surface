# Requirements state that only top-level blocks widen in Auto

The request reported that code blocks inside lists, admonitions, tabs or cards keep a horizontal scroll bar in Auto width mode. The owner decided the behaviour stays: the requirements state that only top-level blocks (and the paragraph holding only an image) widen, instead of listing it as a known issue (answer 1). No change of what the user sees. Widening nested blocks would need a new request and a new specification.
