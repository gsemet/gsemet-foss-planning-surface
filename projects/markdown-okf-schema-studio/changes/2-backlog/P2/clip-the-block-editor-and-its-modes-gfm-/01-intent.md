# Feature clip: the block editor and its GFM and MyST modes

This clip shows the editor of a normal block and its palette modes. In edit mode, a click on a
paragraph opens its block editor, with the edition palette above the text box in GFM mode, the
default: the plain Markdown buttons plus the GitHub ones (alert, checkbox, collapsible, footnote,
Mermaid, key...). One shortcut switches the palette to MyST, which adds the MyST buttons
(admonition, definition list, math, figure, card, tabs...). The mode changes the buttons only:
Studio renders GitHub and MyST syntax the same in every mode, so the GitHub alert and the MyST tip
around the paragraph do not change. A writer learns that the mode is a choice of tools, not of
what the page can show.

It is made with the merged clip kit (`docs/demo-video/clip-kit/`) and the feature clip recipe
(`docs/demo-video/guidelines/feature-clip-process.guidelines.md`): two captions in turn, orange
marks in turn, key badges, 1280x720 at 15 fps, no card, the logo top right, a loop, 12.0 s. The
clip lives in `docs/demo-video/clips/block-editor-modes/`.

The storyboard draft is `work/storyboard/clip.md`, with the stage in `work/storyboard/stage/`.
The batch films the trial take from this draft, puts its pictures in the storyboard, renders the
clip and opens the PR with the clip watchable (the GIF inline, the MP4 and the WebM linked at the
PR's head). The owner reviews the storyboard and the clip in that PR, which stays a draft until the
owner approves it (block-editor-Q3).
