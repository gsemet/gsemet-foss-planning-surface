# Feature clip: paste spreadsheet cells into a table

Studio has a feature clip kit (`docs/demo-video/clip-kit/`, CR-482, PR #501) and a recipe
(`docs/demo-video/guidelines/feature-clip-process.guidelines.md`). The CR `short-demo-video-of-the-smart-raw-markdo`
gives them a Markdown storyboard the owner reviews, two captions in turn, several marks in turn,
combined key badges and a PR whose review plays the clip. This CR makes one more clip with the kit and
the recipe as that CR leaves them.

Clip: copy a block of cells from a spreadsheet, click a table cell in Studio, paste; the cells fill
right and down and the missing rows and columns are added. One continuous shot, the spreadsheet on
one side and the page on the other.

The clip lives in `docs/demo-video/clips/paste-spreadsheet-cells/` with its storyboard `clip.md`, its
stage document and its scenario; the batch films the take, renders the GIF, MP4 and WebM, and opens
the PR.
