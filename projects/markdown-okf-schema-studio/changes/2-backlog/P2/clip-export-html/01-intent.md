# Feature clip: export the page to one HTML file

This clip shows that a Studio page can be handed to someone who has no editor: the Export button of
the floating toolbar writes the page as one `.html` file, with its theme, its diagrams embedded and
its tabs working without JavaScript. Opened in a browser, it is the same page. Sharing a rendered
plan or handbook with a reader outside VS Code is the use the clip sells.

The kit films the VS Code window only, so the browser is VS Code's built-in Simple Browser, opened
beside Studio on the exported file served by a small local server that the scenario starts off
camera (the Simple Browser does not load `file://` pages).

It is made with the clip kit (`docs/demo-video/clip-kit/`) and the feature clip recipe
(`docs/demo-video/guidelines/feature-clip-process.guidelines.md`) as the CR
`short-demo-video-of-the-smart-raw-markdo` leaves them: two captions in turn, several orange marks
in turn, combined key badges, 1280x720 at 15 fps, no card, the logo top right, a loop. This CR
depends on it. The clip lives in `docs/demo-video/clips/export-html/`.

The storyboard draft is `work/storyboard/clip.md`, with the stage in `work/storyboard/stage/`. The
batch films a trial take, puts its pictures in the storyboard and gets the owner's review of the
storyboard before the final take and before the render (the recipe's gates). Then it opens the PR
with the clip watchable in its description: the GIF inline, the MP4 and the WebM linked at the PR's
head.
