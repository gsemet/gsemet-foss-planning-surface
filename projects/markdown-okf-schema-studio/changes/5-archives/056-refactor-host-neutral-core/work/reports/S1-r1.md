## What each test pins

**pageTimers** (harness clock, no wall time):
1. Webview state write: first at once; writes inside 100 ms held; none at 99 ms; one trailing write at 100 ms with the last state; immediate again after a quiet window.
2. An unthrottled `setState` (Description toggle) drops the held-back write (never written later) and opens a new 100 ms window.
3. `previewState` messages throttled the same way (none at 99, trailing at 100 with last scrollTop); `previewScroll` never held back.
4. `pagehide` and `visibilitychange→hidden` write the held-back state and post the held-back `previewState` at once, nothing twice.
5. Block-editor autosave: 400 ms after the **last** input (none at 399 after it, i.e. 699 after the first), each input restarts, carries the last text, nothing further.
6. Host flush (`previewFlushEdit`) waiting on a pending frontmatter plain save answers at exactly 1000 ms (not 999), and a late result does not answer twice.

**pageMessages**: for 13 host message types: the well-formed message has an observable effect (so
refusals are never vacuous); per identity rule the refusals/acceptances:
- `render` rule (pending overlay, content patch, properties table, pairing, themeChanged, show comments, history state, navigateAnchor, sourceScroll, edit source): refused with another/no documentId, older/newer/string documentVersion, older/newer/string/absent requestId.
- `document` rule (`previewPlantUmlIncludesChanged`): refused on documentId, **still accepted** with another version/request.
- `own-id` rule (`previewEditorWatch`, `previewFlushEdit`): **still accepted** with another or no identity (the host may already follow the next document); refused on a bad id.
- Payload refusals: overlay (`visible` non-boolean, label non-string / >500, message absent), patch (next missing / string version / bad pin, contentHtml non-string, unknown status, label absent, diagnostics not an array / malformed entry), properties markup non-string, history non-boolean, navigateAnchor (non-string, no `#`, malformed escape, missing target), sourceScroll line 0 / −3 / "abc" / absent, edit source for another editId.
- Non-objects / unknown types (`null`, string, number, array, `{}`, numeric type, wrong case) change nothing and never throw.
- After a content patch the old identity is stale and the next one is current.

**runtimeBundle**:
1. The runtime of this build (`createPreviewRuntimeScript()`) reads no undeclared name except `acquireVsCodeApi`: checked with the project's TypeScript (`--allowJs --checkJs --lib es2022,dom`, "Cannot find name" diagnostics) on the whole assembled script.
