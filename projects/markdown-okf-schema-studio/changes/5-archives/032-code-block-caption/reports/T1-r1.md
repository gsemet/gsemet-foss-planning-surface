## What was done
Root cause: the MyST writer renders a captioned code-block as `<figure><pre>..</pre><figcaption><p>..</p></figcaption></figure>`;
the generic `figure { text-align: center }` (made for images) centred the code and the caption was an italic centred line below.
Fix (stylesheet only, no inline style, no renderer change): `figure:has(> pre)` is a left-aligned flex column; its figcaption is drawn
first (`order: -1`) as a title bar: same width and 1px border as the block, rounded top 4px, no bottom border, monospace
(editor font var), upright, 0.85em, theme-variable colours with a translucent gradient over the code background (readable light/dark/cream);
the pre gets margin 0 and square top corners. The inner `<p>` has margin 0 and `font: inherit` (a generic p rule would otherwise
reset font family/size). Line numbers, emphasize-lines and the copy button (fixed-position, anchored on the pre) are untouched.
Plain fences and figures with images do not match `:has(> pre)`: unchanged.
