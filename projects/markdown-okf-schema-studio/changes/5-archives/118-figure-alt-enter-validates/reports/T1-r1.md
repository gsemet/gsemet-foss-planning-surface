# T1 round 1 - CR 118 Enter in the image alt text

## Behaviour
In the block source editor, plain Enter with the selection inside the alt text of a Markdown image
(`![alt](path)`, e.g. the name selected after a paste or a pick, or a caret after typing there) keeps
the text, prevents the line break and puts the caret just after the closing parenthesis. Shift+Enter
stays native, Cmd/Ctrl+Enter is still Done, Enter elsewhere (list continuation, plain text) unchanged.
Scope: Markdown image alt only; the `:alt:` option of a `{figure}` directive is not touched.
