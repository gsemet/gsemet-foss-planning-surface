# Retro at the end of each CR and each run

Owner, 2026-11-11, after the Auto-fix of PR #355: "Il faut une rétro à la fin pour fixer le process pour la prochaine fois".

As in Chantier (`retro.md` gained at the archive): each landed CR gets a `retro.md` listing what cost a round, a rerun, an owner correction, a refusal or a CI failure, with its root cause and the process fix. At the end of a run or a release, the Chief of Staff gathers them and proposes the fixes to the owner.
