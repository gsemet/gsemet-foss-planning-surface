## What
- Static `DIFF_BUTTON` (`data-sphinx-preview-diff-toggle`, aria-pressed="true" default, tooltip) is last in
  row 2 (Back, Next, Zoom -, Zoom +, Width, TOC, Diff). Markup is the same for any setting.
- `installIncomingToggle(document, vscode, context)` (self-contained, injected with `.toString()`): state from
  webview state `viewIncomingChanges`, else `initialViewPreferences.incomingChanges`, else on. Sets
  `<html data-sphinx-preview-incoming="on|off">`, aria-pressed, label/title/tooltip; click flips, saves state and
  posts `previewViewPreferenceChanged` preference `incomingChanges` (already in the T03 registry and handled by the
  host, which re-posts ranges, or none, via `scheduleIncomingChanges`; per-workspace storage already existed from T08).
  No host change was needed.
- CSS: `html[data-sphinx-preview-incoming="off"] ... [data-sphinx-preview-changed] { box-shadow: none }` and
  `html[data-okf-incoming-changes="false"] [data-sphinx-preview-diff-toggle] { display: none }`.
- Reused T16's `data-okf-incoming-changes` attribute to hide the button (no duplicate attribute). Separate module
  rather than extending `installIncomingChanges`, so its existing unit test signature stays untouched.
