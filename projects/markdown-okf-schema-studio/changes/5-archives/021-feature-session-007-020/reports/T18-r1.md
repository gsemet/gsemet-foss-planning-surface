## What was done
- confParser: static tokenizer (comments, quotes, triple quotes, line joins); `=`, `+=`, `.append`, `.extend`, `+` of literal lists.
  Anything else touching either name (non-literal, f-string, indented/conditional, `.insert`, `from x import *`) gives `certain: false`.
- confLocator: walk from document folder up to workspace root (document outside root: own folder only), nearest conf.py wins.
  Cache by directory and (path, mtime, size); trusted for 2 s (no disk per keystroke), then re-stat; `invalidateConfCache()` from the watcher.
  Returns a set only when certain and `extensions` has `myst_parser` or `myst_nb`.
- Detection of all 11 extensions from the brief; first use per extension, at most 10 warnings; U17 wording exact.
  Tasklist is detected from source lines (the renderer replaces checkbox markers before parsing), skipping code ranges and frontmatter.
  Inline line numbers are refined inside the block, since the parser gives paragraph-level lines for inline nodes.
  `$5 and $6` is not detected: the parser makes math from it, so inline math whose value starts or ends with whitespace is ignored.
