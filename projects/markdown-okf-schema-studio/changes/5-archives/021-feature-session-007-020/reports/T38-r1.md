## What
Page: textarea `paste`: non-empty text/plain stays native; else first png/jpeg/gif/webp file item ->
preventDefault, >10 MB refused in the status line, FileReader base64, `previewPasteImage {mime,
dataBase64}` through `hostRequests` (answer matched by request edit id, 30 s timeout), status "Saving
image…"; on `{ok,fileName}` inserts `![name](name)` over the remembered selection (clamped) with the alt
selected via `applyTextEdit` (one undo step); a reply for another edit or after the editor closed is ignored.
Host: refuses readOnly, non-`file:` document ("Save the document before pasting an image."), folder outside
the workspace folder (realpath both sides), bad mime/base64, >10 MB, bytes whose sniffed type differs from the
announced one. Name chosen only by `nextImageName` from `readDirectory` (case-insensitive, existing symlinks
count as taken), written with `workspace.fs.writeFile(Uri.joinPath(folder, name))`. Reply type is
`previewPasteImageResult {ok, fileName | reason}` (T31 pattern) instead of `previewPastedImage`.

## Deviations
- No "matching active edit" check on the host: the host sets `activeBlockEdit` only at the first
  autosave, so a freshly opened editor would be refused, and the document version moves with autosaves.
  D7 is enforced by the page (only an open textarea listens). Documented in the handler comment.
- Reply message name `previewPasteImageResult` (shared hostRequests path), no separate `previewPastedImage`.
- Existence check by `readDirectory` instead of repeated `stat`.

## Manual check §9.5 (for the user)
1. Open a saved `.md` in the workspace, edit mode, open a block, take a screenshot to the clipboard, paste:
   `image.png` appears next to the file, `![image.png](image.png)` is inserted with `image.png` (alt)
   selected; type to replace the alt. Paste again: `image-1.png`. Cmd/Ctrl+Z removes the inserted text.
2. Copy text from a web page that also puts an image on the clipboard: only the text is pasted.
3. Paste in an untitled document, in an untrusted workspace, and a >10 MB image: a message in the editor
   status line, no file written. Pasting with no block editor open does nothing.
4. Remove the `image*.png` files you created.

No screenshots (no visual UI change).
