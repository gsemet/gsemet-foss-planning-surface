## What was done
- Deviation from the brief (as instructed): no `data-line` / `data-sphinx-source-line` on the anchor. The label's
  source line travels in `data-okf-label-line` (both inline span and row span). The sanitizer is a blacklist, so
  `data-*` passes through and needed no change; the T27 test (no tabindex, not a mapped block) is kept and now also
  asserts no `data-sphinx-source-line`.
- Host (`handleLabelRename`, registered `previewLabelRename`): refuses read-only/untrusted preview, open block edit,
  stale document version, and any line that is not exactly `(oldName)=` (trim). Never searches elsewhere. One edit
  via `sourceEditor.edit` with undo stops (WorkspaceEdit fallback), as the checkbox toggle does. Replies
  `previewLabelRenameResult { ok, remainingRefs | reason }`. `countRefUses` counts `{ref}` with and without title.
- Page (`installLabelRename`, injected like codeCopy): capture-phase click on `.okf-anchor` in edit mode only
  (outside edit mode it stays a link target), popover with `input[aria-label="Label name"]` prefilled and selected,
  same validation as the host, Enter sends, Escape/outside click closes, status line shows the remaining `{ref}`
  count; 6 s no-answer fallback. Result is matched by edit id (not sameContext) because the edit itself moves the
  document version first. Popover closes when edit mode is turned off.
- CSS in the stylesheet (pointer cursor in edit mode, popover). No inline `style=` (CSSOM only for position).
