## What I did
- `convertCommentMarkers` runs right after `autolinkBareUrls` (so URLs containing TODO are already
  links and skipped). A block `html` node that is exactly one comment becomes `div.okf-comment`
  with `data-line`/`data-end-line` (from `sourcePositionProperties`, so included files keep the
  include-line behaviour), `data-okf-comment-kind`, a `span.okf-chip[role=button][tabindex=0]`
  with `title` = comment text, and a hidden `div.okf-comment-body` holding a hast text node.
- Inline comments (parent paragraph, heading, tableCell, emphasis, strong, delete) become
  `span.okf-comment` wrapping the chip and a hidden `span.okf-comment-body`. Deviation: the brief
  lists chip and body only; the wrapper is there so T15 can expand them together.
- `TODO` as a whole word in text nodes -> `span.okf-chip.okf-chip--todo`. Skipped under code,
  inlineCode, html, link(Reference), image(Reference), crossReference, cite, footnoteReference,
  mystRole, mystTarget, math, inlineMath. `<!-- TODO ... -->` gets kind `todo` and a green chip.
- Tool comments (`markdownlint-`, `prettier-ignore`, `toc`, `/toc`, `cspell:`, `vale `) are left as
  they were (hidden). Context tags and raw-HTML tables are untouched (they are not comments).
- A comment followed by other markup in the same html block (`<!-- --><script>`) is not exactly one
  comment, so it stays as before: dropped, nothing reaches the DOM (the brief says "stays text";
  today it is dropped, which is stricter, and the test asserts no script element).
- CSS: gray chip (descriptionForeground on editorWidget background), green chip via
  `--vscode-charts-green` (already redefined for light/dark/cream), `font-size: .78em`,
  `line-height: 1.4`, inline-block, so line height is unchanged. Body hidden by
  `.okf-comment-body[hidden]`.
- Edit mode: the block `div.okf-comment` is a mapped block, so a click on it opens the block editor
  on the raw lines. The click and keydown handlers in `scrollSync.ts` now return early for
  `div.okf-comment > .okf-chip` (chip reserved for T15 expansion). Inline chips edit with their
  paragraph. No new message type, no inline styles.
- Book check: rendering the 22 white paper chapters gave 49 gray and 4 green chips, no errors.
