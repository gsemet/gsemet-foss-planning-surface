# T35 r1 - palette inline group merged into the table-cell bar

## Files changed
- src/webview/editPalette.ts: new dep `scope?: "block" | "cell"`. In "cell" scope the palette has no mode
  select, lists only actions whose registry scopes include `cell` (current mode), and passes `scope: "cell"`
  to actions. Root is `role=group`, `data-sphinx-edit-palette="cell"`, class
  `sphinx-preview-edit-palette sphinx-preview-edit-palette-in-bar`.
- src/webview/textEditing.ts: new `cellSafeEdit(value, edit)` (escape unescaped `|`, backslash-parity aware,
  CR/LF/CRLF to a space, selection remapped).
- src/webview/scrollSync.ts: `renderTableCellEditor` creates one cell palette per edit (moved into every
  rebuilt bar after a `role=separator`), closes link panel and popover when the control is replaced, wires
  mousedown/input/keyup/select, `palette.handleKey` (Escape closes a popover first) and `paletteShortcut`
  (scope derived from the open edit: cell-scope actions only). `applyTextEdit` sanitizes through
  `cellSafeEdit` when the control is the cell input (covers palette buttons, link panel, shortcuts).
  `openLinkPanel` works for a cell: panel is appended inside the table bar (full-width row), frame check
  includes the bar. Cell palette destroyed with the edit.
- src/preview/previewStyles.ts: separator, in-bar variant (no pill, no shadow), popover item height reset,
  link panel as a full-width row inside the bar.
- README.md (one added sentence after the figure sentence), CHANGELOG.md (new top bullet). User's own
  edits untouched.
- Tests: test/webview/scrollSync.test.ts (11 T35 tests), test/webview/textEditing.test.ts (3),
  test/visual/capture.py (`check_cell_bar_formatting`, runs in the 4 edit-table-wrapped scenarios + the
  alias), test/integration/realInput.test.ts (`scenarioTableCellBold`: select cell text, Cmd/Ctrl+B, Enter).

## Notes / open questions
- The serializer already escapes bare `|` outside code spans on save (markdownTable.escapeCellPipes) and
  keeps `\|`; `cellSafeEdit` is idempotent with it and also escapes inside code spans (GFM needs it).
- Focus-loss: the 500 ms pointer heuristic is unchanged; focus inside the bar (palette, popover filter,
  link panel) counts as inside; focus going to nowhere/outside commits (unit tests for emoji picker and
  link panel).
- Cosmetic: at 360-460 px the group wraps as a unit under the four buttons, leaving a trailing separator
  at the end of the first row. The two keyboard buttons (kbd, roleKbd) share an icon (pre-existing).
- A table row/column operation closes an open popover (the group is kept; the cell input is replaced).
- Fake DOM does not empty a parent on `textContent = ""`, so the "rebuilt bar" unit test checks identity of
  the group, not counts.
