## Step 1: output before any change (verified)
- `$$\begin{align}…\end{align}$$` and ```` ```{math} ```` with align: the renderer emits
  `<div class="math-display">` with the raw environment; `renderMathHtml` (webview step) typesets it
  with KaTeX (two `mtr` rows, no error). **amsmath already renders; no code change.** A guard test
  was added (passes before and after).
- Figure `:width: 60%` `:align: center`: `<img class="align-center" width="60%">`, figure had no
  align class; `em`/`rem` widths do not work as a `width` attribute; no validation.

  dropped, no id, and `{ref}` to it stayed an "unhandled" role.
