## What was done
- Model: strict `parseSidecar` (<= 2 MB, 1000 threads, 200 comments, strings <= 10 000, ISO dates,
  unique ids, line <= endLine); any error rejects the whole file (no threads). Copies into fresh
  objects, so unknown fields and `__proto__` are dropped. `serializeSidecar` stable; `sidecarNameFor`.
- Host: sidecar read via `workspace.fs` (stat first for the size cap), watcher per shown document
  (create/change/delete, debounced), posted after each render and on `previewReady`
  (`previewComments` with the current ids). No sidecar: no message. Invalid: one warning per content
  (`showWarningMessage`) and no threads. Fresh page load resets `commentsShown`; threads shown earlier
  are cleared by an empty post.
- Page: innermost `data-line` block covering the anchor line; first occurrence of the quote inside
  ONE text node is wrapped in `mark[data-okf-comment-thread]` (whitespace-collapsed retry); else an
  empty `button[data-okf-comment-badge]` (no text, so block text is unchanged; placed after tables,
  lists, pre, etc.). Skips code, math, mermaid, plantuml, properties, chips, included content and
  open editors (O10). `apply()` removes its own previous additions first (idempotent) and is called in
  `initializeContent`. Popover: `textContent`/`setAttribute` only, fixed position set through CSSOM,
  Escape/outside click close, resolved shown as note and dimmed. Click/dblclick/Enter/Space on a
  mark or badge is intercepted in capture before the edit/reveal/link handlers.
- No new webview-to-host message, so `previewMessages.ts` is unchanged.
