## What was done
- `createEditActions()` returns `{ actions, byId, shortcutFor(event) }`. `EditAction` carries
  id, label, icon, group, modes, scopes, optional `shortcut` data
  (`codes`, `keys`, `anyShift`), optional `popover` name and `apply(ctx)`. Later tasks only
  append to `actions` (shortcut matching is data-driven). Types are exported.
- `bold`/`italic`: toggle via an asterisk-run count (bold if run >= 2, italic if run is odd), so
  `***x***` carries both and each toggle removes only its share. Works with markers outside or
  inside the selection, and the word at the caret; an empty selection with no wrapped word
  inserts the pair with the caret inside; an empty pair toggles off; selection whitespace edges
  are excluded from the wrap.
- `todo`: per non-blank line of the touched lines; all wrapped means unwrap, otherwise wrap the
  unwrapped ones; blank lines are left alone; an empty single line gets `<!-- TODO:  -->` with
  the caret inside; indentation is kept; selection ending at a line start excludes that line.
- scrollSync: factory injected with `.toString()`; `paletteShortcut()` is called right after
  `keepUndoInControl` in the block textarea keydown (also serves the insertion editor, same
  textarea). It consumes the key (preventDefault + stopPropagation) and runs the edit through
  `applyTextEdit` (one `execCommand("insertText")`). Composition, AltGr (any altKey) and Shift
  (except for `/`) are ignored.
- CHANGELOG bullet, README sentence, glossary term "Edit action".

## Deviations
- Shortcuts apply to the block/insertion textarea only (as the brief's Done-when); the table
  cell input is deliberately untouched (a test pins this). `bold`/`italic` list scope `cell`
  in the registry so a later task can enable it; `todo` is block only.
- Cmd and Ctrl are both accepted on every platform (no platform sniffing in the page).
- TODO on multiple lines is per line, not one comment spanning lines.
- After a TODO or multi-line edit, the selection covers the whole new text of the touched
  lines (including indent); collapsed caret single-line edits keep a mapped caret.

## Open points

- Cmd+B also takes the key from VS Code's "toggle sidebar" while the text box is focused,
  as D14 intends.
