- Registry: new actions heading (arg 0-5), strikethrough, codeFence (arg language), quote, rule;
  `title`, `options`, `shortcutLabel()` (Cmd/Ctrl); `createEditActions(languages)`.
- editPalette.ts: data-driven pill bar (role=toolbar), popovers role=menu, every control
  mousedown-preventDefault, tooltips with the platform shortcut, mode filter (additive).
- scrollSync: palette is first child of the block-editor frame (also insertion editor; not table
  cell, not frontmatter), destroyed in closeBlockEdit, Escape closes a popover first, popover closed
  on textarea mousedown/input, reveal reuses revealTableToolbar. Language list injected from
  highlight.ts (registrations + aliases, "text" first). Text-stays-put: edit anchor moves up by the
  bar height, limited so the bar stays under the toolbar/sticky band, and not applied at scrollY 0.
  Final-save pin adds the applied shift so the rendered block returns to its original place.
