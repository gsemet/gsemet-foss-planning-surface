## What was done
- lineDiff: EOL-insensitive, prefix/suffix strip, Myers; > 20 000 middle lines or D > 2000 -> whole middle.
- headBaseline: injected vscode.git extension (fake in tests), activates it, `read` (file: only, <= 1 MB,
  cache per commit+path, any failure -> undefined) and `watch` (notifies only when HEAD commit id changes).
- Host: `postIncomingChanges` posts `previewIncomingChanges {enabled, ranges, ids}`; scheduled 300 ms after
  each render/patch, 0 ms on previewReady, setting change and `incomingChanges` view preference change
  (`previewViewPreferenceChanged` handler). Only when setting + preference + trust are on; nothing is
  posted for untracked files unless marks / the `enabled` value must be taken back. Stale stage
  results are dropped. Watch disposed with the preview. Setting `preview.showIncomingChanges`, order 22.
- Page: `installIncomingChanges` marks innermost `[data-line]` elements meeting a range with
  `data-sphinx-preview-changed`, skips open editors, re-applies in `initializeContent`. Message sets
  `data-okf-incoming-changes` on <html> (true/false) for T17 to hide its toggle (absent = enabled).
  CSS: inset 3px box-shadow, `--vscode-editorGutter-addedBackground`, fallback #2ea043. Shell untouched.
