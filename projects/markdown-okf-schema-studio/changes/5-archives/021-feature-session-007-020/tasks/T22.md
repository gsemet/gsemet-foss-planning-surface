# T22 — Link mini-panel (text + URL, focus first empty), Cmd/Ctrl+K

Backlog: block-edition-palette · Phase 4 · Size M · Depends on: T21 · Gate: B T
Commit (draft): `feat(editor): insert links from a small text and URL panel`

## Goal

The Link button and Cmd/Ctrl+K open a small panel under the palette with two fields, Text
(prefilled with the selection) and URL (prefilled when the selection is itself a URL, then Text
is empty). Focus goes to the first empty field. Enter inserts `[text](url)` replacing the
selection; Escape returns to the text box without change.

## Decisions

D14 (fallback Cmd/Ctrl+Shift+K if the workbench swallows Cmd+K; record the manual result), O13
(empty URL → `[text]()` with the caret inside the parentheses).

## Changes

1. Blur relaxation: in the textarea `blur` handler, do not save when `event.relatedTarget` is
   inside the editor frame (palette and panels). When focus leaves the panel to outside the
   frame, run the normal final save. Unit-test both paths.
2. Panel (`role="dialog"`, `aria-label="Insert link"`): two labelled inputs, Insert and Cancel
   buttons; remember the textarea selection on open; on Enter (either field) or Insert:
   refocus the textarea, restore the selection, `applyTextEdit` with `[text](url)`, caret after
   the link; Escape or Cancel: refocus, restore selection. Selection inside an existing link
   `[a](b)`: prefill both and replace that link.
3. Registry action `link` (modes strict, scopes block+cell) with shortcut Cmd/Ctrl+K handled in
   `paletteShortcut` (preventDefault + stopPropagation).
4. CHANGELOG bullet.
