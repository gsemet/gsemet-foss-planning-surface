# T07 — Inline-image editing gaps (linked image, raw <img>, ArrowUp into properties)

Backlog: edit-inline-image · Phase 1 · Size S · Depends on: — · Gate: B T
Commit (draft): `fix(editor): edit linked and HTML images, keep the editor at the top`

## Goal

In edit mode: (1) clicking an image inside a link (`[![a](x.png)](url)`) opens the block editor
(Cmd/Ctrl+click still follows the link); (2) a raw HTML `<img …>` block is a normal block (click
edits it, "+" after it, arrows reach it); (3) ArrowUp from the first body block when a
properties table exists keeps the editor open instead of closing it.
