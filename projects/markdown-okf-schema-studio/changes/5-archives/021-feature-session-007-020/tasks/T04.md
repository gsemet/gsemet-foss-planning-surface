# T04 — Copy button on every code block

Backlog: copy-code-block · Phase 1 · Size S · Depends on: T03 · Gate: B T
Commit (draft): `feat(render): copy any code block with one click`

## Goal

Pointing at any code block (labelled or not, preview and edit mode) shows a copy icon at its top
right; a click puts the raw code on the clipboard and the icon becomes a check mark for 1.5 s.

## Decisions

U7, D27 (host clipboard through a validated message).

## Changes

1. Runtime-only UI (no renderer change, shell untouched): new `src/webview/codeCopy.ts`
   `installCodeCopy(document, window, post)` injected like `installLinkNavigation`. One
   `<button type="button" data-sphinx-preview-code-copy aria-label="Copy code">` appended to
   `document.body`, `position: fixed`, shown while the pointer is over a
   `#sphinx-myst-preview-content pre` or over the button; placed 6 px inside the pre's top-right
   corner; hidden when the visible part of the pre is under the sticky band or < 30 px tall, when
   the pre is being edited (`data-sphinx-preview-editing`), on scroll end outside, and after a
   content patch.
2. Text = `pre.querySelector("code")?.textContent ?? pre.textContent` (raw code only).
3. Button: `mousedown` preventDefault (keeps an open editor's focus); `click` stopPropagation;
   post `{ type: "previewCopyText", documentId, documentVersion, requestId, text }`; swap to a
   check icon, `aria-label="Copied"`, for 1500 ms.
4. Register `previewCopyText` (`text` string ≤ 1_000_000) and a host handler
   `vscode.env.clipboard.writeText(text)` (allowed in read-only previews: it does not edit).
5. CSS: 26 px square, editorWidget background, widget border, icon foreground; z-index 1050.
6. CHANGELOG bullet.
