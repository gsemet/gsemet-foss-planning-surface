# T43 — Create a thread from a selection, reply, author

Backlog: local-comment-mode · Phase 6 · Size M · Depends on: T42, T02 · Gate: B F
Commit (draft): `feat(vscode): comment on selected preview text and reply to threads`

## Goal

Selecting text in the preview shows a small "Comment" button; it opens a box to write the first
comment; saving creates the thread in the sidecar (creating the file). The thread popover gets a
reply box. Author = setting, else Git `user.name`, else the OS user name.

## Decisions

D25, O8 (read-only previews: no create/reply). Setting
`markdownOkfSchemaStudio.comments.authorName`, string, default `""`, order 50.

## Read first

- T42 modules; extension.ts readOnly; scrollSync.ts:147 selection reading, 3128 block lookup;
  T16 `src/git/headBaseline.ts` (Git API adapter: add `getConfig("user.name")`).

## Changes

1. Page: on mouseup/selectionchange with a non-collapsed selection inside one or more mapped
   body blocks (not in editors, code, properties) → floating button near the range rect; hidden
   while a block editor is open. Anchor = `{ line, endLine, quote (whitespace-collapsed, ≤ 500),
   prefix, suffix (≤ 32 each) }`.
2. Registered messages `previewCommentCreate { anchor, body }`,
   `previewCommentReply { threadId, body }` (body 1–10 000 chars). Host: refuse read-only;
   per-document write queue: read latest sidecar, apply, `serializeSidecar`, `writeFile`; ignore
   the watcher event caused by its own write (content hash); repost `previewComments`.
3. Author resolution helper `src/comments/author.ts` (setting → git → `os.userInfo().username`
   → "Anonymous").
4. Ids: `t_` / `c_` + 8 random hex chars (crypto).
5. package.json setting, README, CHANGELOG bullet.
