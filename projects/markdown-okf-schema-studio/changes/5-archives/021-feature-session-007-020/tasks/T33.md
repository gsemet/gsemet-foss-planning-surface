# T33 — Keep restricted <span style> colours (sanitizer + runtime)

Backlog: block-edition-palette · Phase 4 · Size S · Depends on: — · Gate: B T
Commit (draft): `feat(render): show text and background colours set with span styles`

## Goal

`<span style="color: #c00">x</span>` and `background-color` render coloured. Only those two
properties with hex (`#rgb`, `#rrggbb`, `#rrggbbaa`) or `rgb()/rgba()` numeric values are kept;
everything else is still removed with the existing diagnostic.

## Decisions

U14. CSP blocks `style=` markup, and a head stylesheet would change the shell key: the sanitizer
converts allowed values to `data-okf-color` / `data-okf-background`, the runtime applies them with
`style.setProperty` in `initializeContent`.

## Read first

- html-sanitizer.ts:233 (style removal, diagnostic `blocked-inline-style`), 70
  `sanitizeTableStyle` (value parsing precedent), 194–197; scrollSync.ts:3278 `initializeContent`.

## Changes

1. Sanitizer: for `span` only, parse `style` declarations; keep `color` / `background-color`
   matching the allowed value grammar as data attributes; drop `style`; emit the existing
   diagnostic only when something was dropped.
2. Runtime: in `initializeContent`, for `[data-okf-color]`, `[data-okf-background]` inside the
   content, re-validate with the same grammar and set the property.
3. CHANGELOG bullet.
