# T40 — Copy, cut, paste selected blocks as Markdown

Backlog: multibloc-selection · Phase 5 · Size M · Depends on: T39, T03 · Gate: B T
Commit (draft): `feat(editor): copy, cut and paste whole blocks as Markdown`

## Goal

With a block selection: Cmd/Ctrl+C puts the exact Markdown source of the selected span on the
clipboard; Cmd/Ctrl+X does the same and removes the blocks (one undo step); Cmd/Ctrl+V with a
selection or a focused insert point inserts the clipboard text after it as new blocks (one undo
step). Inside text boxes and inputs the keys stay native.

## Decisions

U13, D5 (cut + paste = two undo steps; no drag and drop), D1, R5, R11, R12.
