# T32 — Figure editor (source, alt, caption, legend, width, align, name)

Backlog: block-edition-palette · Phase 4 · Size M · Depends on: T31, T27 · Gate: B T
Commit (draft): `feat(editor): edit figure source, caption, size and alignment in a form`

## Goal

In edit mode, hovering a rendered figure shows an "Edit figure" button; it opens the block editor
on the figure with a form above the text box: Source (with Browse), Alt text, Caption, Legend,
Width, Align (none/left/center/right), Name. Apply rewrites the directive (one undo step); the
text box stays available for raw edits. A palette "Figure" button with the caret inside a
`{figure}` directive opens the same form.

## Decisions

O11 (legend = paragraphs after the caption), D15. Other ideas (`:class:`, `:figwidth:`) are
listed as preserved-but-not-edited options.

- mystRenderer.ts 1048–1052 (figure mapping), T27 width/align rendering, T31 picker messages;

## Changes

1. Pure `src/webview/figureDirective.ts` (self-contained factory for injection):
   `parseFigure(text)` → `{ fence, source, options (ordered, unknown kept), caption, legend }`
   for colon and backtick fences; `serializeFigure(model)` keeps fence style, unknown options and
   their order, drops empty known options.
2. Form panel in the palette area (T21 popover infrastructure, inputs use the T22 blur
   relaxation); Browse uses `previewPickImage` (T31) and fills Source; Apply = one
   `applyTextEdit` replacing the whole textarea value; invalid width shows an inline error.
3. Hover button on `figure` elements in edit mode (runtime UI, mousedown preventDefault), opening
   the mapped editor and the form.
4. Markdown image `![alt](src)` in MyST mode: "Convert to figure" in the form header.
5. CHANGELOG bullet.
