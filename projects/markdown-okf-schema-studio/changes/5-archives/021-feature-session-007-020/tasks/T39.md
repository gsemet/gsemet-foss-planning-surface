# T39 — Multi-block selection (Shift+click, Shift+↑/↓)

Backlog: multibloc-selection · Phase 5 · Size M · Depends on: T05 · Gate: B T
Commit (draft): `feat(editor): select several blocks with Shift+click and Shift+arrows`

## Goal

In edit mode, Shift+click on a block selects all body blocks from the anchor block (last
clicked/opened) to that block; Shift+↑/↓ extends or shrinks a selection; Escape or a plain click
clears it. Selected blocks get an outline and a screen-reader count ("3 blocks selected").
Contiguous only; properties table and included blocks never selected.
