# T18 — MyST autodetect warnings in the preview

Backlog: myst-autodetect · Phase 3 · Size M · Depends on: T06 · Gate: B
Commit (draft): `feat(render): warn when MyST syntax needs an extension not enabled`

## Goal

When the document belongs to a Sphinx project whose `conf.py` lists `myst_enable_extensions`
and the document uses syntax that needs an extension missing from that list, the preview status
area shows one warning per extension, with the first line where it is used. No `conf.py`, or a
`conf.py` that cannot be read statically: no warning. Rendering is not changed.

## Decisions

U17 (exact wording, below), D20, D21, D22. Warn only when `extensions` contains `myst_parser`
or `myst_nb`.

Wording: ``Warning: `<syntax>` is used but this needs the MyST extension `<ext>`, which is not enabled in your conf.py. Add "<ext>" to `myst_enable_extensions`.``

## Changes

1. `src/myst/confParser.ts` (pure): strip comments, read string literals of
   `extensions` and `myst_enable_extensions` (list/tuple, multi-line, trailing comma, `+=`,
   `.append`, `.extend`); any non-literal → `certain: false`. Result
   `{ extensions: string[]; mystExtensions: string[]; certain: boolean }`.
2. `src/myst/confLocator.ts`: from the document folder up to its workspace folder root, first
   `conf.py` wins; cache by directory and by (path, mtime, size).
3. `src/render/mystSyntaxDetect.ts` (pure, on the document's own AST before include expansion,
   skipping code/inlineCode/html): `colon_fence` (`:::` directive), `dollarmath` (`$`/`$$`
   delimiters), `amsmath` (`\begin{align|equation|gather…}` at top level), `deflist`, `fieldlist`,
   `tasklist`, `strikethrough` (`~~`), `substitution` (`{{ name }}`), `attrs_inline` (`]{.`/`]{#`),
   `html_image`, `html_admonition`. Returns `{ ext, syntax, line }[]` (first use per ext).
4. `MystRenderContext.enabledMystExtensions?: ReadonlySet<string>`; set in the pipeline from the
   locator result only when `certain`; diagnostics with code `myst-extension`, severity
   warning, line; at most 10.
5. CHANGELOG bullet; README section on Sphinx projects (no "Sphinx" in literals of the listed files).
