# T12 — Table of contents column (toggle, h1–h4, click to scroll)

Backlog: toc-in-vscode-markdown-studio · Phase 2 · Size M · Depends on: T08 · Gate: B S T
Commit (draft): `feat(vscode): show a table of contents next to the preview`

## Goal

A TOC button on toolbar row 2 shows a right-hand column below the toolbar listing the
document's h1–h4 headings; clicking an entry scrolls the preview to the heading. Off by default,
remembered per workspace, hidden on narrow panes.

## Decisions

U8 (collapsible nodes and current highlight come in T13), O6 (which headings).

## Read first

- scrollSync.ts:3278 `initializeContent`, 438 sticky heading band (heading selection logic),
  the function that scrolls to an element respecting the band (used by `navigateAnchor`, ~3382).
- previewStyles.ts:1226 column, 2194 width variable; T10 width modes.
- T08 `previewViewPreferences` (`toc`).

## Changes

1. New `src/webview/tocColumn.ts` factory `installTocColumn(document, window, deps)` injected with
   `.toString()`: creates `<nav data-sphinx-preview-toc aria-label="Table of contents">` in
   `document.body` (runtime UI, not shell), fixed at the right, top = toolbar bottom + 8, bottom
   16 px, width 240 px, own scroll. Entries from `#sphinx-myst-preview-content` h1–h4 excluding
   those inside `[data-okf-properties]`, admonitions, block editors and the sticky band; indent by
   level; text = heading text without the permalink glyph.
2. Click: scroll to the heading with the existing scroll helper (heading at the reading line,
   not under the sticky band); does not open an editor.
3. Toggle `data-sphinx-preview-toc-toggle` (`aria-pressed`) posts `previewViewPreferenceChanged`
   `toc`. `<html data-sphinx-preview-toc="open">` reserves the column: CSS reduces the available
   width (content and sticky band) by 256 px. Pane narrower than 760 px: column hidden even if
   on (button still reflects the preference).
4. Rebuild after `initializeContent` (debounced to one per frame).
5. CHANGELOG bullet.
