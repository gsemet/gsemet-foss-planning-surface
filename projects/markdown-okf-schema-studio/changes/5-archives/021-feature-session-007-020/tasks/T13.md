# T13 — TOC: collapsible nodes, current section highlight

Backlog: toc-in-vscode-markdown-studio · Phase 2 · Size S · Depends on: T12 · Gate: B S
Commit (draft): `feat(vscode): fold TOC sections and highlight the current one`

## Goal

Each TOC entry that has sub-entries gets a twisty to collapse/expand it; the entry of the section
at the reading line is highlighted and kept visible in the TOC while scrolling.

## Decisions

U8. Collapse state per panel in webview state (`vscode.setState`), keyed by heading level +
text + occurrence index, kept across content patches; not persisted across restarts.

## Read first

- T12 `src/webview/tocColumn.ts`; the reading-line helper used by the sticky heading band
  (scrollSync.ts ~438) to know which heading is current; webview state usage (~93, 166, 756).

## Changes

1. Twisty button per parent entry (`aria-expanded`), keyboard: Enter/Space toggles; collapsing
   hides descendants. "Collapse all"/"Expand all" are not required.
2. Current entry: the last heading whose top is above the reading line; update on scroll with
   one `requestAnimationFrame` per frame; `aria-current="location"` + highlight class; if inside
   a collapsed parent, highlight the parent; scroll the TOC so the entry stays visible (do not
   scroll the page).
3. CHANGELOG bullet (can merge into T12's bullet if still unreleased).

## Tests (fail before)

- tocColumn test: collapse hides children and survives a rebuild; current entry follows a
  simulated scroll; collapsed parent highlighted.
- Visual: highlight contrast in light/dark/cream.

## Done when
