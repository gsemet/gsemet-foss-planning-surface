Backlog: block-edition-palette · Phase 4 · Size M · Depends on: — · Gate: B T
Commit (draft): `feat(render): show figure size and alignment, math blocks and anchors`

## Goal

Three MyST syntaxes used by the palette render faithfully before their buttons ship (D13
superseded by intent line 8): (1) amsmath environments (`\begin{align}…\end{align}`) in `$$` and
`{math}`; (2) `{figure}`/`{image}` `:width:` (px, %, em) and `:align:` (left, center, right);
(3) a `(name)=` label shows a small anchor icon at the left of the labelled block, with the
label in its tooltip, and is a link target (`#name`).

## Changes

1. Verify first and record: output today for `$$\begin{align}a&=b\\c&=d\end{align}$$`,
   `{math}` with align, a figure with `:width: 60%` and `:align: center`, and `(intro)=` + heading.
2. amsmath: if not rendered, let KaTeX handle the environment (display mode; wrap in `aligned`
   when needed); errors show the existing math error style.
3. Width/align: renderer emits `data-okf-width="60%"` (validated `^\d+(\.\d+)?(px|%|em|rem)?$`)
   and class `align-center|align-left|align-right` on the figure/image; sanitizer keeps both;
   runtime applies width with `style.setProperty("width", …)` in `initializeContent` (CSP);
   CSS for alignment (float left/right with margin, centre).
4. Labels: `mystTarget` → `span.okf-anchor[id=name][data-okf-label=name]` with an icon and
   `title="Anchor: name"`, `data-line` = label line, placed as the first child of the following
   block (or alone when nothing follows); `{ref}` links to it resolve (`#name`).
