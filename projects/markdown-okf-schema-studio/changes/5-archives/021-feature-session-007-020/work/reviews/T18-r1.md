## Findings

### 1. MEDIUM - dollarmath false positive on currency amounts (real chapters)
File: `src/render/mystSyntaxDetect.ts` (case "inlineMath", ~line 100).
The renderer's parser (mystmd) turns `$19 ... ($200)` into `inlineMath`; markdown-it-dollarmath (Sphinx) does not,
because a closing `$` followed by a digit does not close math. Result: a `dollarmath` warning for text that
is plain text in Sphinx (so the warning is wrong, with or without the extension).
Real hits on the white paper chapters (run with an empty enabled set):
- `03-setting-up-github-copilot.md:481` `**$19 base subscription** ... ($200) ...` (math spans 2 lines)
- `10-steering-model-limits.md:12` `$100-$380 in token spend`
(`$5 and $6` is correctly not detected.)
Fix: in the `inlineMath` case, find the actual delimiters in the source block and skip when the closing `$`
is followed by a digit (dollarmath rule). Simplest: require `value` to not match `/\$\d/` neighbours, i.e. inspect
the source text of the node (`position` start/end offsets, or the refined line) and require that the character after
the closing `$` is not `[0-9]`; also keep the existing no-space rules. Add tests for `$19 ... ($200)` (multi-line)
and `$100-$380` => no detection, and `$x$ and $y$` => detected.

### 2. LOW - fallback applies to documents outside the workspace root
File: `src/myst/confLocator.ts` `findConf` (fallback call, ~line 88).
A document outside `root` skips the walk-up (good, only its own folder) but still gets `findFallback(root)`, so it
inherits the root's `sphinx/conf.py`. In the extension the root is the document folder when there is no
workspace folder or the workspace is untrusted (`extension.ts:3058`), so this is mostly theoretical.
Fix: call `findFallback` only when `isInside(root, directory)`.

### 3. INFO - strikethrough belongs in the list
`~~` is a MyST optional extension (`strikethrough`) in myst-parser/Sphinx even though T06 enabled it in our
renderer; the warning is correct for Sphinx builds. No change. Detection ignores `~~` in code/inline code (verified).
