# T20 — Editing shortcuts Cmd/Ctrl+B/I, Ctrl+/ TODO toggle

Backlog: block-edition-palette · Phase 4 · Size M · Depends on: — · Gate: B T
Commit (draft): `feat(editor): bold, italic and TODO shortcuts in the block editor`

## Goal

In a block text box: Cmd/Ctrl+B toggles `**bold**`, Cmd/Ctrl+I toggles `*italic*` on the
selection (or inserts the pair with the caret inside), Ctrl+/ (Cmd+/ on macOS too) toggles
`<!-- TODO: … -->` around the current line or the selected lines. Each is one undo step. This
task also creates the action registry that the palette (T21+) renders.

## Changes

1. New `src/webview/editActions.ts`, self-contained factory `createEditActions()` returning
   `{ actions, byId, shortcutFor(event) }`. `EditAction = { id; label; icon; group; modes:
   ("strict"|"gfm"|"myst")[]; scopes: ("block"|"cell")[]; shortcut?; popover?; apply(ctx) →
   TextEdit | undefined }`, `ctx = { value, selectionStart, selectionEnd, scope, arg? }`.
   Modes are additive: an action listed for `strict` shows in all modes, `gfm` in GFM and MyST.
2. Actions now: `bold`, `italic` (toggle: unwrap when the selection or the word at the caret is
   already wrapped; `*` vs `**` disambiguation tested), `todo` (wrap lines in
   `<!-- TODO: … -->`; on lines already wrapped, unwrap; empty line → `<!-- TODO:  -->` caret inside).
3. scrollSync: inject the factory like `createTextEditingTools`; in the keydown chain, right after
   `keepUndoInControl`, a `paletteShortcut(event)`: ignore while `event.isComposing` or with
   AltGr (`ctrlKey && altKey`); match `event.code === "KeyB"|"KeyI"` with Cmd (mac) or Ctrl,
   `event.code === "Slash" || event.key === "/"` with Ctrl or Cmd; run the action through
   `applyTextEdit`; `preventDefault()` + `stopPropagation()`.
4. CHANGELOG bullet; README editing section lists the shortcuts.
