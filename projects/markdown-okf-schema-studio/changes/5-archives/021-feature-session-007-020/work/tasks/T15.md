# T15 — Expandable chips, preview.showComments setting

Backlog: todo-comments · Phase 3 · Size S · Depends on: T14, T02 · Gate: B S T
Commit (draft): `feat(render): expand comment chips and turn them off in settings`

## Goal

Clicking a chip (or Enter/Space on it) opens an admonition-like box under the line with the
comment text; clicking again closes it. A new setting hides the gray comment chips (TODO chips
stay). Expansion survives typing (content patches) in the same panel.

## Decisions

U9, O7 (state per panel, keyed by source line). Setting
`markdownOkfSchemaStudio.preview.showComments`, boolean, default `true`, `order` 21.

## Changes

1. Runtime (new `src/webview/chipToggle.ts` factory): delegated click/keydown on `.okf-chip`
   toggles `aria-expanded` and the sibling body's `hidden`; body styled like an admonition
   (title "Comment" or "TODO"). Keep a `Set` of expanded lines in `vscode.setState`; re-apply in
   `initializeContent`; refresh the layout cache after toggling.
2. Setting: in `package.json` (T02 style), configuration reader, and as a `<html>` attribute
   `data-okf-show-comments="false"` set by the runtime from the runtime context so CSS hides
   `.okf-comment` and gray inline chips without a re-render (add the value to
   `runtimeContextKey` only if the page cannot update it live; prefer a live host→page message
   `previewShowComments` re-posted on `previewReady`).
3. README "Settings", CHANGELOG bullet.
