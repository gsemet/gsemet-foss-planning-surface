## Goal (U22, user 2026-10-16)

"In any case, the figure and table needs to be centered, and take the space they need up to the
max available horizontal space. Do not forget to illustrate this nice clever margin break with a
screenshot, using creme theme, in the readme."

## Current state (read first)

- `src/webview/widthMode.ts` `update()`: in Auto, a wrapper of `table, figure, img, pre,
  .myst-mermaid-diagram` wider than the column gets `--sphinx-preview-breakout` =
  `min(natural, available) - column`; CSS (`previewStyles.ts`, ~1369) widens it by that amount and
  shifts it by half of it on each side, so it is centered on the **column**, not on the available
  area. `available` = pane − TOC reserve − 2 gutters.
- Elements narrower than the column are not centered (left-aligned) in Margin, Auto and Full.

## Changes

1. Tables and figures (MyST `figure`, Markdown images alone in a paragraph, Mermaid/PlantUML
   diagrams; not inline images in text, not code blocks) narrower than the column are centered
   horizontally in all three width modes. Captions stay centered under their figure. Do not change
   the width of narrow tables (no stretching to 100 %).
2. Auto: a wide table/figure takes exactly the width it needs, capped at the available width, and
   is centered on the **available area** (pane minus TOC reserve and gutters), never overflowing
   the pane on either side and never under the TOC column. When the column itself is centered in
   the available area the result is unchanged from T10.
   Full width: same centering rule. Margin: unchanged (column width, scroll inside), but centered
   when narrower.
3. Code blocks (`pre`) keep their current behaviour (decide and document if they should stay in
   the breakout list; do not center them).
4. README: add a section/row illustrating the clever margin break in Auto, in the **cream** theme:
   a narrow text column with a wide table (and ideally a wide figure) breaking out, centered.
   Produce the PNG with the existing screenshot tooling (find how `images/readme/*.png` are made,
   e.g. the visual capture in `test/visual/`); store it in `images/readme/`; keep it small
   (optimize, < 300 KB). Link it like the other README images.
5. CHANGELOG bullet.

## Tests (fail before)

  gaps equal within 2 px); wide table in Auto centered on the available area, inside the pane, not
  under the TOC; caption centered.
- Scroll suite green; no reading-line jump when switching modes (existing checks).
