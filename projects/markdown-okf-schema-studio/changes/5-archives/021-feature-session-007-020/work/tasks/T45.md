# T45 — Re-anchor threads after edits

Backlog: local-comment-mode · Phase 6 · Size M · Depends on: T44 · Gate: B T
Commit (draft): `feat(vscode): keep review comments attached when the document changes`

## Goal

Threads follow their text: while the document is edited their lines shift with the edits; when
the document is opened or changed outside the editor, each thread's quote is searched near its
old line, then in the whole document (exact, then whitespace-normalized, then fuzzy within 20 %);
found → anchor updated, not found → orphaned. The sidecar is written only on save or when threads
change, never per keystroke.

## Decisions

D25. Prefer orphaning over a weak fuzzy match.
