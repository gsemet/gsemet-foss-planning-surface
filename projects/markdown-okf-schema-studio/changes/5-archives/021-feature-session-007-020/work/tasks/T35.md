# T35 — Palette inline group merged into the table-cell bar

Backlog: block-edition-palette · Phase 4 · Size S · Depends on: T21 · Gate: B T
Commit (draft): `feat(editor): format table cells from the table bar`

## Goal

When editing a table cell, the existing table bar (Row +/−, Col +/−) also shows the inline
palette actions allowed in a cell (bold, italic, strikethrough, link, emoji, colour, sub/sup,
kbd: whatever exists with scope `cell` and the current mode), after a separator. Block actions
never appear there. Inserted `|` is escaped.
