# T31 — Image file picker (document folder) and Figure button

Backlog: block-edition-palette · Phase 4 · Size M · Depends on: T23, T03 · Gate: B T
Commit (draft): `feat(editor): pick an image file to insert in the block editor`

## Goal

Image button (all modes): a native file dialog opens in the document's folder; the chosen image
is inserted as `![name](relative/path.png)` with `name` selected. Figure button (MyST): same
dialog, inserts `:::{figure} path` + `:alt: name` + an empty caption line + `:::`. The block
editor stays open across the dialog. Cancel changes nothing.

## Decisions

D15, D8 (images refused in read-only/untrusted/outside-workspace documents; png, jpeg, gif,
webp, svg accepted for references since nothing is written).

## Read first

- extension.ts readOnly checks (~2367), `src/security/resource-policy*` (path policy),
  `ActivePreview` active edit (`activeBlockEdit`, edit id); scrollSync.ts:2769 blur → save.
- T22 blur relaxation; T03 registry.

## Changes

1. Page: before posting `previewPickImage { editId, kind: "image"|"figure" }` set
   `edit.suspendBlurCommit = true` (blur handler returns early while set); clear it on the reply,
   on editor close, or after 60 s.
2. Host handler: refuse read-only previews (status message); `showOpenDialog({ defaultUri:
   documentFolder, canSelectMany: false, filters: { Images: [...] } })`; compute a POSIX
   relative path from the document folder (`path.relative`, `/` separators, wrap in `<…>` when it
   contains spaces or parentheses); refuse targets outside the workspace folders; reply
   `previewPickedImage { editId, path, name }` (name = file stem) with current ids, or
   `{ editId, cancelled: true }`.
3. Page: ignore replies for another edit id; refocus the textarea, restore the selection, insert
   through `applyTextEdit`.
4. Registry actions `image` (strict) and `figure` (myst).
5. CHANGELOG bullet.
