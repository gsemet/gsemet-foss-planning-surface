Backlog: block-edition-palette · Phase 2 · Size M · Depends on: T03 · Gate: B T S R

## Goal

The floating toolbar has two rows: row 1 Refresh/Anchor/Edit/Theme (unchanged), row 2 view
controls. This task adds Zoom − and Zoom + to row 2 (70–200 %, 10 % steps, text and column scale
together) and the per-workspace store that later view controls (Margin T10, TOC T12, Diff T17)
reuse. Back/Next (T11) go at the start of row 2.

## Decisions

U16 (row layout, zoom range, per workspace), O4 (no reset button; tooltip shows the percentage).
Final row-2 order: Back, Next, Zoom −, Zoom +, Margin, TOC, Diff.

## Changes

1. `src/state/previewViewPreferences.ts` (no `vscode` import): type
   `{ zoom: number; widthMode: "margin"|"auto"|"full"; toc: boolean; incomingChanges: boolean }`,
   defaults `{100,"margin",false,true}`, `normalizeViewPreferences(unknown)` (clamps zoom to
   70–200 and rounds to 10), `applyViewPreference(prefs, key, value)`; storage key
   `markdownOkfSchemaStudio.viewPreferences`; read/write helpers taking a Memento-like object.
2. Host: read at page creation → runtime context `initialViewPreferences` (not in
   `runtimeContextKey`); registered message `previewViewPreferenceChanged`
   `{ preference: "zoom"|"widthMode"|"toc"|"incomingChanges", value }` (validator per key) →
   store; keep a session copy like `setSessionPreviewThemeMode` so a new panel sees it at once.
3. Toolbar markup: `<div data-sphinx-preview-toolbar …>` containing
   `<div data-sphinx-preview-toolbar-row="main">` (existing buttons) and
   `<div data-sphinx-preview-toolbar-row="view">` with `data-sphinx-preview-zoom-out` /
   `-zoom-in` buttons (codicon-style inline SVG like the others, `data-tooltip` "Zoom out (90 %)").
   Static markup only; states are set by the runtime.
4. Runtime: on load and click set `document.documentElement.style.setProperty("--sphinx-preview-zoom", "1.1")`
   and `data-sphinx-preview-zoom="110"`; disable − at 70 and + at 200; post the message; keep the
   current source line at the reading line across the change (same capture/restore used on
   resize); mirror in `vscode.setState`.
5. CSS: content font-size `calc(var(--sphinx-preview-font-size) * var(--sphinx-preview-zoom, 1))`
   and column max-width multiplied by the same factor; toolbar becomes a column of two rows
   (radius 14 px), row 2 right-aligned; move the pending overlay below the toolbar (≈ 96 px).
6. CHANGELOG bullet.
