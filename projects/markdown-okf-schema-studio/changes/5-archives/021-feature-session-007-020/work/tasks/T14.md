# T14 — Comment and TODO chips in the preview

Backlog: todo-comments · Phase 3 · Size M · Depends on: — · Gate: B T S
Commit (draft): `feat(render): show HTML comments and TODO markers as chips`

## Goal

HTML comments, invisible in the preview today, show as a small gray chip (`<!--`) where they
are; the word `TODO` outside code shows as a green chip; `<!-- TODO … -->` shows as a green
"TODO" chip. Tool comments (`markdownlint-*`, `prettier-ignore`, `toc`, `cspell:`, `vale `)
stay hidden. The chip's `title` holds the comment text. Expansion is T15.

   (after include expansion, before `mystToHtml`):
   - block `html` node that is exactly one comment → positioned `div.okf-comment`
     (`data-line`/`data-end-line` from the node, `data-okf-comment-kind="comment|todo"`) holding
     a chip `span.okf-chip[role=button][tabindex=0]` and a hidden
     `div.okf-comment-body` with the text (hast text node, never raw HTML);
   - inline comment → `span.okf-chip` + hidden `span.okf-comment-body`;
   - `TODO` in text nodes (skip set: code, inlineCode, html, link, mystRole, math) → `span.okf-chip.okf-chip--todo`
     "TODO", the rest of the sentence unchanged;
   - tool comments and context tags untouched.
3. CSS: gray chip (descriptionForeground on widget background), green chip
   (`--vscode-charts-green`/testing passed colour) in light/dark/cream; chip does not change line height.
4. Edit mode: clicking a block comment (not the chip) opens the block editor on the raw
   comment lines; inline chips edit with their paragraph.
5. CHANGELOG bullet.
