## Changes

1. `admonition` (modes myst, popover list): wraps the selected lines (or inserts an empty body)
   in `:::{type}\n…\n:::`; when the selection already contains a colon fence, the new outer
   fence uses one more colon than the longest one inside. "Custom…" inserts `:::{admonition} Title\n:class: note\n\n…\n:::` with
   `Title` selected.
2. `deflist`: `Term\n: Definition` (selection becomes the term).
3. `math` (popover): inline wraps the selection in `$…$`; display inserts `$$\n…\n$$`; aligned
   inserts `$$\n\begin{align}\na &= b\n\end{align}\n$$`.
4. `sub`, `sup` (scopes block+cell): wrap selection in the role; empty → caret inside.
5. `label` (scopes block): insert `(label-name)=\n` before the first line of the edited block
   text, select `label-name`.
6. `footnote` (only if T26 is dropped or not approved): as described in T26, modes myst.
7. CHANGELOG bullet.
