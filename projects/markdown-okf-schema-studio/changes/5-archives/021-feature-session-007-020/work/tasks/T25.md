Backlog: block-edition-palette · Phase 4 · Size M · Depends on: T23 · Gate: B T
Commit (draft): `feat(editor): add GitHub alert, checkbox and HTML table actions`

## Goal

In GFM and MyST modes the palette adds: **Alert** (inserts `> [!NOTE]` + `> ` and shows a type
dropdown at the caret: Note, Tip, Important, Warning, Caution), **Checkbox** (toggles `- [ ] ` on
the touched lines), **HTML table** (with the caret in a Markdown table: converts it to an HTML
`<table>`; otherwise inserts a new 2×2 HTML table).

## Decisions

U3 (additive modes), D13 superseded (all three render today: alerts `expandGithubAlerts`,
checkboxes `checkboxMarkers.ts`, raw tables `normalizeRawHtmlTable`; prove it with render tests).

## Changes

1. `alert` (modes gfm): insert at the caret line (`> [!NOTE]\n> ` + selected lines prefixed), then
   open a type list positioned at the caret (mirror-div caret coordinates inside the textarea);
   picking replaces the type; Escape keeps NOTE. An existing alert at the caret: the dropdown
   changes its type.
2. `checkbox` (modes gfm): lines without a list marker get `- [ ] `; list items get `[ ] ` after
   the marker; lines already checkboxes lose it (toggle).
3. `htmlTable` (modes gfm, scopes block): pure `toHtmlTable(model)` in markdownTable.ts
   (escape `&<>`, keep inline Markdown text as text, alignment → `align` attribute, header in
   `<thead>`); caret inside a pipe table → replace that table's lines; else insert a 2×2 table.
4. CHANGELOG bullet.
