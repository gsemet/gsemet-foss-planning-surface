# T34 — Colour picker (text + background) and colour-code swatch

Backlog: block-edition-palette · Phase 4 · Size S · Depends on: T33, T21 · Gate: B T
Commit (draft): `feat(editor): colour text and backgrounds from the palette`

## Goal

A Colour button opens a picker with two tabs, Text and Background: 16 swatches, a hex field,
"Remove". It wraps the selection in `<span style="color:#hex">…</span>` (or `background-color`),
or updates/removes the span the selection is in. When the caret is inside a colour code
(`#rgb`, `#rrggbb`, `rgb(…)`) the palette shows a swatch of that colour; clicking it opens the
picker on that value and replaces the code in place.

## Changes

1. Registry actions `color` (modes strict, scopes block+cell) and `colorCode` (shown only when
   `available(ctx)` finds a code at the caret).
2. Popover: tabs, swatch grid (theme-independent palette: red, orange, yellow, green, teal,
   blue, purple, gray at two intensities), hex input with live validation; Enter applies.
3. Span merge rules: selection exactly inside a generated span → change its property (add the
   second property when switching tabs); "Remove" unwraps when no property remains.
4. CHANGELOG bullet.
