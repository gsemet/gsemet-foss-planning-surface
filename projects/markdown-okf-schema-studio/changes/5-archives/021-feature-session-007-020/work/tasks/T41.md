# T41 — Alt+↑/↓ moves the selected blocks

Backlog: multibloc-selection · Phase 5 · Size S · Depends on: T39, T37 · Gate: B T
Commit (draft): `feat(editor): move a selection of blocks with Alt+Up and Alt+Down`

## Goal

With a block selection, Alt+↑/↓ (and the insert-bar arrows of its last block) moves the whole
selected span past the neighbouring block, in one undo step; the selection follows.

## Decisions

## Changes

   moving range; add tests for multi-block spans (inner separators untouched).
2. Page: Alt+Arrow with a selection posts the move with the span; after the re-render, restore
   the selection from the new start line and block count.
