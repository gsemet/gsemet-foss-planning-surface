# T37 — Alt+↑/↓ (Ctrl/Cmd+Alt in the text box) moves the block

Backlog: move-block-up-down · Phase 5 · Size S · Depends on: T36 · Gate: B T
Commit (draft): `feat(editor): move blocks with Alt+Up and Alt+Down`

## Goal

Alt+↑/↓ moves the focused block (keyboard focus on a mapped block or its insert bar). Inside an
open block text box, Ctrl+Alt+↑/↓ (Cmd+Alt on macOS) saves the edit, moves the block and reopens
the editor on it with the caret where it was (Option+arrow keeps word navigation on macOS).

## Changes

1. Document keydown (edit mode, no editor open, focus on a mapped body block or an insert-point
   button): Alt+ArrowUp/Down → same request as the T36 buttons; focus follows the moved block
   after the re-render (new pending variant "focus", no editor).
2. Textarea keydown (before `navigateBlockEdit`): Ctrl+Alt (Cmd+Alt on mac) + ArrowUp/Down →
   final save, then on the save acknowledgement send the move, then reopen the editor on the new
   line with the saved caret (pending variant "edit").
3. preventDefault + stopPropagation for handled chords only.
4. CHANGELOG bullet (merge with T36 if unreleased).
