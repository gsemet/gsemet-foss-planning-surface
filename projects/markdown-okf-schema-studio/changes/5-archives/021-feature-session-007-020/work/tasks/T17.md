# T17 — Toolbar toggle for incoming-change marks

Backlog: show-incoming-diff · Phase 3 · Size S · Depends on: T16 · Gate: B T R
Commit (draft): `feat(vscode): toggle incoming-change marks from the preview toolbar`

## Goal

A Diff button at the end of toolbar row 2 shows or hides the incoming-change marks; the choice
is remembered per workspace. The button is hidden when the setting turns the feature off.

## Decisions

U11, U16, O1.

## Read first

- T08 toolbar row 2 and `previewViewPreferenceChanged` (`incomingChanges`); T16 host poster and
  page module.

## Changes

1. Static button `data-sphinx-preview-diff-toggle` (aria-pressed, tooltip "Show changes since
   last commit" / "Hide changes since last commit") as the last button of row 2.
2. Runtime: click flips the preference, posts it, hides marks immediately (attribute on `<html>`
   `data-sphinx-preview-incoming="off"` + CSS); host stops/starts posting ranges.
3. Setting off → runtime context flag hides the button (attribute on `<html>`, CSS hides it; the
   markup stays identical so the shell key is stable).
4. CHANGELOG bullet (can merge with T16's if still unreleased).

## Tests (fail before)

- Webview harness: click toggles attribute and posts; hidden when the setting flag is off.
- Visual: row 2 with the button, pressed and unpressed states.
- Reload suite: the off state survives a webview reload.
- contentPatch test: the shell key is equal with the setting on and off.

## Done when
