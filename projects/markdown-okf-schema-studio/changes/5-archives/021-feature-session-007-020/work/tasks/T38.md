# T38 — Paste an image into the block editor

Backlog: paste-image-in-edit-mode · Phase 5 · Size M · Depends on: T03 · Gate: B F
Commit (draft): `feat(editor): paste images from the clipboard into the block editor`

## Goal

Pasting an image (screenshot) into an open block text box saves it next to the document as
`image.png` (then `image-1.png`, `image-2.png`, …) and inserts `![image.png](image.png)` with
the alt text selected. Text on the clipboard wins over an image.

## Decisions

U12, D6, D7 (no editor open → ignored), D8 (≤ 10 MB; png/jpeg/gif/webp; magic bytes checked;
refused in read-only/untrusted/non-file/outside-workspace documents), R11.

## Changes

1. Pure `src/mapping/pastedImage.ts`: `sniffImage(bytes)` → `png|jpeg|gif|webp|undefined`,
   `nextImageName(existing: ReadonlySet<string>, ext)` (`image.ext`, `image-1.ext`, … ≤ 1000).
2. Page: textarea `paste` listener: non-empty `text/plain` → native; else first image file item
   of an allowed type → preventDefault, size check (status message if too big), base64 via
   `FileReader.readAsDataURL`, post registered `previewPasteImage { editId, mime, dataBase64 }`
   with the selection remembered; status "Saving image…".
3. Host: validator caps base64 length (14 000 000) and charset; handler refuses read-only,
   untrusted, non-`file:` scheme ("Save the document before pasting an image"), no matching
   active edit, folder outside the workspace; decode, sniff (must match), pick a free name with
   `workspace.fs.stat`, write with `workspace.fs.writeFile` using
   `Uri.joinPath(documentFolderUri, name)`; reply `previewPastedImage { editId, fileName }` or
   `{ editId, error }`.
4. Page: on the reply for the same edit, restore the selection and insert
   `![name](name)` selecting `name` (alt); other edit → ignore.
5. CHANGELOG bullet; README note (where images go).
