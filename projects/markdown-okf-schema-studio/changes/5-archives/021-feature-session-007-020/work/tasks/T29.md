# T29 — Anchor edition: click the anchor icon to rename the label

Backlog: block-edition-palette · Phase 4 · Size S · Depends on: T27, T21 · Gate: B T
Commit (draft): `feat(editor): rename a MyST label from its anchor icon`

## Goal

In edit mode, clicking an anchor icon (T27) opens a small field with the label name; Enter
renames the `(name)=` line in the source (one undo step); Escape cancels. A status line says how
many `{ref}` uses of the old name remain in the document.

## Decisions

O12 (only the label line changes). Refused while a block editor is open or in a read-only
preview.

## Read first

- T27 anchor markup (`span.okf-anchor[data-okf-label][data-sphinx-source-line]`);
  extension.ts checkbox toggle handler (~1586 `previewCheckboxResult`, ~1603 edit-lock pattern) as
  the model for a small atomic host edit; status message helpers in scrollSync.ts.

## Changes

1. Runtime: click on `.okf-anchor` in edit mode (capture before the mapped-block click handler)
   opens a popover with one input (`aria-label="Label name"`), prefilled and selected.
   Validation in the page and on the host: `^[A-Za-z0-9][A-Za-z0-9_.:-]*$`, ≤ 100 chars.
2. Registered message `previewLabelRename { line, oldName, newName }`: host checks not
   read-only, no active block edit, the line is exactly `(oldName)=` (trim), applies one
   WorkspaceEdit, counts `` {ref}`oldName` `` and `` {ref}`text <oldName>` `` uses, replies
   `previewLabelRenameResult { ok, remainingRefs, reason? }`; page shows the status.
3. CHANGELOG bullet.
