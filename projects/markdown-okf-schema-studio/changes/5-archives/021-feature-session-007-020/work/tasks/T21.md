# T21 — Palette bar, strict group

Backlog: block-edition-palette · Phase 4 · Size M · Depends on: T20, T06 · Gate: B T
Commit (draft): `feat(editor): add an edition palette above the block being edited`

## Goal

While a block text box is open (edit mode), a palette bar sits right above it with the strict
group: Heading dropdown (Paragraph, H1–H5), Bold, Italic, Strikethrough, Code block (language
dropdown), Blockquote, Horizontal rule, TODO (icon, tooltip "Toggle TODO comment (Ctrl+/)").
Clicking a button never closes the editor; each action is one undo step. Link, table, image,
emoji and colour buttons are added by T22, T24, T31, T34.

`src/render/highlight.ts` registrations and aliases, plus "text"), D16 (also in the insertion
editor, not in the frontmatter editor), D13 superseded (strikethrough renders since T06).

## Changes

1. New `src/webview/editPalette.ts` factory `createEditPalette(document, deps)` (deps:
   `actions`, `getControl`, `applyTextEdit`, `mode`), returns `{ element, refresh(), destroy(),
   handleKey(event) }`. Data-driven from the registry; `role="toolbar"`; buttons with icon +
   `title` (shortcut in the title); every control `mousedown` preventDefault (R6).
2. Popovers (heading list, language list) as children of the palette, `role="menu"`;
   pointer-only, Escape closes the popover first (handle before the existing Escape branch).
3. New actions in the registry: `heading` (arg level 0–5; replaces an existing `#…` prefix on
   the caret line(s)), `strikethrough` (`~~`), `codeFence` (arg language; wraps selection or
   inserts a fence with caret inside), `quote` (`> ` prefix on touched lines, composes with list
   markers), `rule` (`\n\n---\n\n` at line end).
4. scrollSync wiring: create in `receiveBlockEditSource` after the textarea exists, as the frame's
   first child, before the anchor is applied; destroy in `closeBlockEdit`; reveal like the table
   bar. Make sure a content patch keeps it (it lives inside the editor frame).
5. CSS: pill bar like the table menu, wraps on narrow widths, light/dark/cream tokens.
6. CHANGELOG bullet.
