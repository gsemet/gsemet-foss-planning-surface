# T24 — Table 9×9 grid (hover highlight) and emoji picker

Backlog: block-edition-palette · Phase 4 · Size M · Depends on: T21 · Gate: B T
Commit (draft): `feat(editor): insert tables from a size grid and emoji from a picker`

## Goal

Table button: a 9×9 grid opens; hovering highlights the rectangle from the top-left cell to the
pointer and shows "3 × 4"; one click inserts a pipe table of that size (first row = header).
Emoji button: a picker with categories and a filter field inserts the Unicode character at the
caret (also allowed in table cells).

## Decisions

D11 (Unicode only), D10. Strict group (intent lines 45–48, 84).

## Read first

## Changes

1. Registry action `table` (scopes block): popover grid of 81 `div` cells with event
   delegation (`mouseover` highlights, `click` inserts); keyboard: arrows move the highlight,
   Enter inserts. Output built with the table serializer: header `Column 1 … Column n`, separator,
   empty rows; inserted on its own lines (blank line before/after as needed); caret in the first
   header cell.
2. Registry action `emoji` (scopes block+cell): popover with ~150 curated emoji in 6 categories
   (smileys, people/hands, objects, symbols/status ✅ ⚠️ ❌, nature, flags excluded), a filter input
   matching English names (data table inside the factory, no network), grid buttons with `title`.
   Insert the character at the caret; popover stays open with Shift+click, closes otherwise.
3. CHANGELOG bullet.
