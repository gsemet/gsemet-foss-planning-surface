# T30 r1 - MyST proposals: reference, document link, citation, dropdown, captioned table, key

Approval source: decisions.md U19 (T30 approved fully, all five proposals).

## What was done
- Palette actions (MyST mode only, group `myst`, no shortcuts): `ref` (Reference, filter popover of
  the document's `(label)=` names with the following heading/text), `doc` (Document link, native
  open dialog, `{doc}` path relative to the document, no extension), `cite` (Citation, filter
  popover of `.bib` keys), `dropdown` (`:::{note} Title` + `:class: dropdown`, wraps touched lines,
  fence one colon longer than inner fences), `tableCaption` (wraps the pipe table at the caret in
  `:::{table} Caption`, inserts a new one otherwise, leaves an already captioned table alone),
  `roleKbd` (`{kbd}` role, sample `Ctrl+K`). `{kbd}` already rendered (verified by a render test),
  no renderer change was needed.
- Host round trips (registered messages `previewListTargets`, `previewListCitations`,
  `previewPickDocument`, validated by an edit id; answers `<type>Result` matched by edit id, the
  T29 pattern). All three refuse nothing destructive; citations and the dialog refuse read-only
  (untrusted) previews.
- `src/webview/hostRequests.ts`: generic `ask/receive/isDialogOpen/cancelAll`. A request with
  `{dialog: true}` suspends the block editor's blur handling (textarea blur and palette `onLeave`
  in scrollSync.ts) until the answer, error or timeout (10 min safety). T31 can reuse it:
  `hostRequests.ask("previewPickImage", {}, { dialog: true }, cb)`.
- Bounded scan: `src/preview/bibScan.ts`: `findFiles` with exclude (node_modules, .git, _build,
  .venv, venv, out, dist), max 20 files (document's folder first, then its workspace folder),
  5 s cancellation, total read budget 2 MB (stat before read, oversize files skipped), async,
  keys capped at 1000. Labels capped at 500.
- Pure helpers `src/mapping/mystTargets.ts`: `documentTargets`, `bibKeys`, `collectBibKeys`,
  `docReference`.
