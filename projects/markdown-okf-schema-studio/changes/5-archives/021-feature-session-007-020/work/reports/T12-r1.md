## What
- `installTocColumn` (injected with `.toString()`): runtime `<nav data-sphinx-preview-toc aria-label="Table of contents">`
  appended to the body; built only while open (dirty flag), one rebuild per frame (rAF, setTimeout fallback);
  h1-h4 of `#sphinx-myst-preview-content` minus `[data-okf-properties]`, admonitions, block editors, sticky band;
  permalink glyph removed; `li[data-level]` plus `--sphinx-preview-toc-depth` (relative to the shallowest level);
  "No headings" when empty; click button -> `revealElement` (new, shares `revealAt` with `navigateAnchor`,
  which I extracted without behaviour change). Top = toolbar bottom + 8 via `--sphinx-preview-toc-top`.
- Toolbar row 2 gets `data-sphinx-preview-toc-toggle` (aria-pressed). Toggle posts `previewViewPreferenceChanged`
  `toc` (already in the registry/host handler), saves `viewToc` in webview state; start value = saved state, else
  workspace preference, else off. `<html data-sphinx-preview-toc="open|closed">`.
- CSS: `@media (min-width: 760px)` sets `--sphinx-preview-toc-reserve: 256px` and body `padding-inline-end`; nav fixed
  right 16px, bottom 16px, 240px, own scroll; hidden otherwise. Sticky band: `max-width: calc(100% - reserve)` and
  padding formulas subtract the reserve. `widthMode` Auto subtracts the published reserve from the available width.
  Zoom, Margin, Auto and Full coexist (checked visually).
- Structure ready for T13: entries are `li[data-sphinx-preview-toc-entry][data-level]` holding a button; heading
  references are in closures of `rebuild()`.
