# T04 r2

## Changes vs r1
- `src/webview/codeCopy.ts`: new `textOf(pre)`. Wrapped blocks (diff, line numbers, emphasized lines)
  hold one `.myst-code-line` span per line with no newline characters; the lines are joined with
  "\n" plus one trailing "\n" (what the renderer emits for plain blocks, so all shapes agree).
  Plain / token-highlighted blocks keep `code.textContent`; no `code` falls back to `pre.textContent`.
  Renderer untouched.
- `test/webview/codeCopy.test.ts`: fake elements gained textContent aggregation and classList; a
  small parser turns REAL `highlightCodeBlocks` output into them. 10 shape tests: plain, highlighted
  (blank lines, indentation), line numbers, line numbers from 7, emphasized lines, diff, diff with
  line numbers, filename label, filename + highlighted + numbered, multi-line token (comment and
  template string spanning lines). Each asserts the posted text equals the original code.
- Edit-mode coverage: harness test with a spy document click handler standing for the block-editor
  opener; a click on the button posts the text and never reaches it, a click on the block does.
- Note: a wrapped block whose source lacked a final newline is copied with one; the renderer always
  supplies it, so real blocks are byte-exact.
