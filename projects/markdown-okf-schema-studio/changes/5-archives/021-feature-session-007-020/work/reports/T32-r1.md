## What was done
- figureDirective.ts: `createFigureTools()` (injected factory): parse/serialize `{figure}` for colon,
  backtick and tilde fences, indentation, unknown options kept in order with their original line until
  their value changes, empty known options (alt, width, align, name) dropped, caption = first body
  paragraph, legend = later paragraphs (O11), body and head kept byte-identical when untouched, fence
  grown when a legend holds a fence, blank line forced before the body only when the option count
  changes. `locateFigure` finds the directive around the caret (innermost), the first one without a
  caret, or a lone Markdown image paragraph. `validate` uses T27's width pattern. A `---` YAML option
  block is refused (status line: edit it in the text box).
- figurePanel.ts: `createFigurePanel` (form: Source + Browse, Alt, Caption, Legend, Width, Align select,
  Name; inline errors; Enter / Cmd-Ctrl+Enter apply, Escape cancels, Tab cycles, T22 blur relaxation)
  and `installFigureEditButton` (floating "Edit figure" button, child of body, placed through the
  CSSOM, mousedown cancelled, hidden on scroll).
- scrollSync.ts: `openFigurePanel` (Apply = one `applyTextEdit` replacing the directive range;
  no write when unchanged; shift compensation like the link panel; closes on text box input/mousedown
  and with the editor), `openFigureEditor` (hover button opens the mapped editor, form opens when the
  source arrives), Browse = `hostRequests.ask("previewPickImage", {}, {dialog:true}, ...)`, hover wiring.
- editActions/editPalette: new `panelWhenInside: "figure"` on the Figure action and `caretInside`
  dep; `openPanel(action, panel?)`. A Markdown image alone in its paragraph opens the form in
  "image" mode whose submit button reads "Convert to figure" (brief item 4; header button replaced by
  the submit button).
- Styles for the form and the button in previewStyles.ts.

## Deviations / open questions
- Image conversion is reachable from the palette Figure button (caret on a lone `![alt](path)`), not
  from the hover button (images are not mapped as figures); the form's submit reads "Convert to figure"
  instead of a separate header button. Image titles (`"title"`) are dropped on conversion.
- Cmd/Ctrl+A then typing in a form field lost the first typed character under Playwright/VS Code (the
  scenario uses triple-click instead). Not reproduced in unit tests; worth a manual check on macOS.
- Form closes when the user types in the text box (same as the link panel) so it never applies a stale
  range; Apply with no change writes nothing.
- Name is only checked for line breaks (MyST names may contain spaces); caption must be one paragraph and
  a legend needs a caption.
- Hover button hides on any scroll; keyboard users reach the form via the Figure palette button
  (MyST mode).
