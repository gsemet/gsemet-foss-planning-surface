## Behaviour
- details: no selection inserts a sample after the selection; with a selection wraps the touched lines; "Summary" selected; blank line after summary so content renders as Markdown.
- footnote: `[^n]` after the selection, n = highest numeric label + 1; `[^n]: ` appended at end (single newline after existing definitions), caret in it, trailing newline kept after.
- mermaid: fence with `flowchart TD`, "Start" selected.
- columnAlign: only the delimiter-row cell of the caret column is rewritten; width kept from trailing padding (`| ------ |` -> `| -----: |`), minimum 3 dashes; same alignment = no edit; outside a table no edit.
- kbd: wraps / unwraps (inside or around the selection) / sample `<kbd>Key</kbd>`.
