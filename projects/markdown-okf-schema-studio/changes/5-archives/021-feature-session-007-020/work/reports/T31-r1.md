## Design (deviation from brief: reuse T30)
- No second `suspendBlurCommit` flag. The image pick goes through
  `hostRequests.ask("previewPickImage", {}, { dialog: true }, cb)`: blur and palette `onLeave` already
  stand down while a dialog request is pending; results matched by edit id; `cancelAll()` in
  `closeBlockEdit`. One mechanism, one timeout (hostRequests' own 10 min safety).
- Never unsaveable: only blur/onLeave are suspended. Done, Cmd+Enter, Escape and Cancel call
  `saveBlockEdit`/close directly and `closeBlockEdit` runs `cancelAll()`. Test added (Done saves
  with the dialog open).
- Reply is `{ ok, path }` / `{ ok, cancelled }` / `{ ok:false, reason }`; no `name` field: the name
  (file stem, brackets stripped) is derived in the action from the path, so palette and
  keyboard-free `run(action, arg)` need only one string. The host sends the PLAIN POSIX relative
  path; `<…>` wrapping (spaces or parentheses) is done by the Image action only (Figure's
  argument takes the rest of the line, so no wrapper there).
- Host refuses: readOnly/untrusted (message), stale/non-file document, non-image extension,
  file outside workspace folders (`getWorkspaceFolder`), other Windows drive, `<>`/newline names.
  Accepted: png, jpg, jpeg, gif, webp, svg (nothing is read or written, per brief).
- Figure: `:::{figure} path` / `:alt: name` / blank / empty caption line / `:::`; caret on the
  caption line. With a selection the touched lines become the caption and the fence is one colon
  longer than any colon fence inside (T28 pattern as in Dropdown).
- Registry order: `image` after `link`, `figure` after `tableCaption`.

## Manual check for the user (§9.6)
1. Open a Markdown doc in a subfolder with images around; edit a paragraph. Strict/GFM: click Image;
   the dialog opens in the document folder; pick `img/logo.png`: `![logo](img/logo.png)` with `logo`
   selected, editor still open, Cmd+Z removes it in one step.
2. Pick a file with spaces or `(1)` in the name: `<…>` wrapper. Pick from a parent folder: `../`.
3. Cancel the dialog: nothing changes, editor stays open and typing continues; click outside saves.
4. Pick a file outside the workspace, a `.txt`, (Windows: another drive): status message, no insert.
5. MyST mode: Figure inserts `:::{figure}`, `:alt:`, empty caption line; with lines selected they
   become the caption; renders as a figure. 6. Untrusted workspace: buttons absent/read-only preview.
7. With the dialog open, switch to another app and back, then Escape/Done: editor closes and saves.
