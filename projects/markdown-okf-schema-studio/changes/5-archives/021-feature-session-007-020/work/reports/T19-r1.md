## What was done
- Diagnostic collection `markdownOkfSchemaStudio.myst` created in activate, in context.subscriptions
  (disposed on deactivate too). After each render `publishMystDiagnostics` sets the document's
  entries from `myst-extension` diagnostics (whole-line range, Warning, source
  "Markdown OKF-Schema Studio", code "myst-extension"). Skipped when the workspace is untrusted.
- Cleared (`clearMystDiagnostics`) in disposePreview, when a followed preview switches to another
  document (old one), and on onDidCloseTextDocument, always only if no other live preview shows
  that document.
- Watchers: the T18 per-preview `refreshForConf` in the dependencyWatcher was REMOVED and replaced
  by one extension-wide `**/conf.py` watcher (change/create/delete). It skips IGNORED_WATCH
  segments, calls `invalidateConfCache()` and refreshes all open previews. It sees D29 fallback
  conf.py files (workspace-root docs/, sphinx/ ...) since it watches every workspace folder.
- Bug fixed on the way: T18's refresh used `refreshOpenDocument(preview)` which is a no-op for a
  ready, up-to-date preview (needsRefresh); the new handler passes isDependencyChange=true.
- CHANGELOG: merged into the T18 bullet.
