## Behaviour
- Admonition: wraps touched lines in `:::{type}`; outer fence = longest inner colon fence + 1; no
  selection inserts an empty body (caret on the blank body line); Custom writes
  `:::{admonition} Title` + `:class: note`, Title selected; unknown/missing type refused.
- Deflist: selection becomes the term, `: Definition` appended (selected); no selection inserts a
  `Term` / `: Definition` block.
- Math: inline `$..$` (empty -> `$x$`, x selected); display `$$` block; aligned `\begin{align}` block.
- Sub/Sup: `{sub}`..``; empty puts caret inside; refuses selections with backtick or newline.
- Label: `(label-name)=` above the first non-blank line, name selected; refuses if already labelled.
