## Fix (finding 1)
- Native lists give no event when closed without a change. Focus entering the select resets a "list open" flag; each click
  toggles it, so the click that closes the list returns focus to the text box. A change already did.
- Select blur: relatedTarget inside the frame keeps the editor open; otherwise one final save (`saveBlockEdit`, guarded by
  `activeBlockEdit === edit && !edit.finishing`). This also covers "click outside" and "click another block".
- Escape on the select: returns focus to the text box (a second Escape there cancels the editor). Enter: back to the text box.
  Cmd/Ctrl+Enter: finish (final save). Deviation from "Escape closes the editor": I chose the permitted fallback (return focus).
