## Behaviour
- The select's mousedown stops propagation (a cancelled mousedown would stop the native list opening); focus moving to it
  stays inside the editor frame so the T22 blur relaxation does not save. After a change, focus returns to the text box.
- Choosing a mode rebuilds buttons only; same value posts nothing; an unknown value resets the select.
- Read-only: no edit toggle, so no palette, so nothing posted; the host handler also refuses readOnly.
- contentPatch key unchanged (mode not in the key, like edit mode).
