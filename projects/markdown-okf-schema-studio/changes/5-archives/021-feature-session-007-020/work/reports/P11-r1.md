# P11 r1: `/` command menu with completion

## Design
- **Single source of truth**: `createEditPalette` gains `menuEntries()` and `runMenuEntry(key, range)`.
  `menuEntries` uses the new shared `visibleActions()` (the same scope + additive `MODE_RANK` filter
  that `build()` now uses for the buttons), skips caret-dependent actions whose `available()` is
  false (colour code), and adds the variants an action declares. The button click handler was
  extracted into `activate(action, button)`; buttons and menu both call it.
- **Data next to the actions** (`src/webview/editActions.ts`): new optional `EditAction.slash`
  (`aliases`, `variants[{label,arg,aliases}]`, `variantsOnly`). Heading is variants-only (Heading 1-5,
  Paragraph: `/h1` `/h2` `/title`), Alert and Admonition keep their picker entry and add one entry per
  type ("Note alert", "Warning admonition": `/note` `/tip` `/warning`). Every action has aliases.
- **Applying**: plain actions and variants run `action.apply` on the text WITHOUT the `/query` and the
  result is written as ONE replacement over the original text through the same `applyTextEdit`
  (execCommand path), so one undo step restores the `/query`. Actions with a popover, panel or
  dialog (table grid, code language, link panel, image dialog, colour, ref/doc/cite lists, alert
  type list, figure panel) remove the query (one step) and then run `activate()` = exactly the
  button's behaviour.
- **Menu** (`src/webview/slashMenu.ts`, new, injected via `.toString()`, no dependencies):
  `createSlashMenu(document, window, deps)`; fed by `handleInput`, `handleKey`, `sync`, `close`.
  Trigger rules (`canOpenAt`): `/` at start or after whitespace, collapsed caret, `insertText` of
  `/` only (no paste, no IME), not in fenced code, fence info string or an inline code span (paragraph
  scan with matching tick runs), `//` and `/ ` close it, as does anything with whitespace or `/`
  in the query, a selection, the caret leaving the token. Ranking: exact > prefix > word start >
  contained > subsequence (subsequence needs 2+ letters), label +10 over aliases, ties in registry
  order. Empty query: grouped by category (Blocks, Text, Insert, Annotations, GFM, MyST, in order of
  first appearance); a query lists a flat best-first list with a category tag. Keys: Up/Down wrap,
  Enter/Tab apply, Escape closes and keeps the text (consumed, so the next Escape is the editor's),
  no match: "No command" row and Enter/Tab fall through; Cmd/Ctrl/Alt chords close it and are left to
  the page (Alert shortcut, block moves, Cmd+A, comments chord untouched); mousemove highlights, click
  applies, mousedown cancelled (focus stays). Closes on blur, save/cancel (`destroy` in the edit
  teardown), scroll-away (listeners on scroll/resize while open reposition it and close it when the
  caret leaves the viewport).
- **Placement**: `caretRectOf`; left edge fixed at the open position, below the caret line, flips
  above when below is too small and above is bigger, clamped inside the viewport, max-height 320 or
  the available room. `position: fixed; z-index: 1400` (toolbar 1100, palette popovers 1300). Style
  only via stylesheet and CSSOM; entry text via `textContent`, icons are the palette's own static SVG.
- **ARIA**: textarea gets `aria-expanded`, `aria-controls`, `aria-activedescendant` while open
  (removed on close); `role=listbox`, items `role=option` + `aria-selected`, groups `role=group`,
  hidden polite live region ("N commands available" / "No command").
- **Wiring** (`scrollSync.ts`): block editor (paragraph editor, insert point, Start writing share it)
  and the table cell editor (`edit.cellSlash`, cell palette entries, so only cell actions). No new
  host messages.

## Deviations / notes
- No plain "bullet/numbered list" action exists in the registry (the only list action is the
  GFM checkbox), so `/bullet` finds nothing; `/todo` `/task` `/checklist` find the TODO comment and
  the checkbox. Adding list actions would change the palette (and P6's pinned button lists), so I
  did not. Open question: add Bullet/Numbered list actions (palette button + slash entry)?
- Heading is offered as 5 levels + Paragraph variants instead of the popover entry (one keystroke
  `/h2`); the Heading popover itself is not listed. Alert and Admonition keep the picker entry.
- In MyST `/note` shows the GFM "Note alert" before "Note admonition" (registry order);
  labels carry the kind. Say if admonitions should win in MyST.
- Undo: popover/panel/dialog commands are two steps (query removal, then the action), plain ones one.
- The menu anchors its left edge at the slash (does not slide with the query); it may cover the
  Done/Cancel row of the editor, by design (floating).
- Subsequence matching is permissive for 2-letter queries (`/ta` also lists Italic, Horizontal rule
  via letters); ranking keeps the good matches first.
