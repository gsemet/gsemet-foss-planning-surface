# P2 + P7 r1: width-mode break series, Full width uses 16 px side margins

## Cause (P7)
`--sphinx-preview-content-gutter: clamp(16px, 8vw, 78px)` is the side padding of the content. In
Full width the column limit is lifted but that padding stayed: 72 px at 900, 78 at 1600, 36.8 at 460.
A table breaking out in Auto keeps only a 16 px pane gutter. Fix: in Full width the gutter variable is 16 px
(`html[data-sphinx-preview-width="full"]`). The sticky band, the orphans box and the content all
read the same variable, so they stay aligned with the text.
