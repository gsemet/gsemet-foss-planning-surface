# P9 e2e audit — findings

Scope: `test/visual/scenarios.ts` + `capture.py` (mock host, Playwright), the integration suites
(`run-tests.ts`: scroll, untrusted, trusted incl. realInput/checkbox/previewEditing, standalone,
reload), `scripts/run-e2e.mjs`, `test/integration/review-index.ts`,
`scripts/generate-readme-images.py`, `test/site/curateGallery.ts`. Evidence: last visual run
(revision 6f7a893, 245 scenarios, passed), latest real-window runs, PNG hashes and thumbnail
similarity (`tools/png_similarity.py`), sampled PNGs viewed by hand. Per-capture decisions:
`inventory.md` and `migration.md` (generated by `tools/build_inventory.mjs`).

Numbers: 245 visual scenarios (5 aliases) → 240 primary + 95 step PNGs = 335 PNGs;
117 real-window PNGs in the latest runs; 26 integration test files with no screenshot.
