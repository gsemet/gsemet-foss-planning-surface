## Campaign identity
Workflow env sets `STUDIO_E2E_RUN_ID=${run_id}-${run_attempt}`, `STUDIO_E2E_COMMAND`, and `STUDIO_E2E_STARTED_AT=1970-01-01T00:00:00.000Z`. Reason: workflow env cannot compute a timestamp without an extra step, and `validateReviewEvidence` only needs each manifest's startedAt to be >= the campaign start, so a fixed earliest time validates. `begin` uses these env values (or creates a random id and `now` locally, command default `just preflight`), writes `out/reports/e2e/review-start.json` (so each job's artifact carries the same file) and prints `export` lines. Locally, `preflight` calls `begin` once so all stages share it; running the stages by hand needs one `eval` first (documented in CONTRIBUTING).
