## Behaviour
Edit mode on, no editor open:
- Up / Down: first press selects the block nearest the top of the viewport; later presses collapse the selection onto the neighbour of its free end (included blocks skipped, stops at the ends). The block is outlined (existing selection outline, follows the theme), focused and announced.
- Enter: opens the selected block (page input already did it for a focused block; new path covers focus on body).
- In a block editor, Esc (cancel) and Cmd/Ctrl+Enter (save) close it and leave the edited block selected (after a save, once the patch is in), without scrolling the page.
- The edit-mode toggle button holding the focus no longer blocks Up/Down.
