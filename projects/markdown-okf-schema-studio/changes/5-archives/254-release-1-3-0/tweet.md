# Release 1.3.2 announcement for X

Three posts, per the release process guideline. The image of post 1 is the 1.3 hero capture.

## 1/

Markdown OKF-Schema Studio 1.3 is out.

Most of the Markdown I read these days is written by coding agents: plans, design notes, reviews.
They love MyST. Cards in a grid, notes, captioned code blocks. It looks great in the preview, right
up to the moment I want to add one card myself and I'm back searching how `{grid-item-card}` takes
its footer.

So this release is about writing that Markdown, not only reading it. Card, grid and code-block now
open a small form. Put the caret on the type of a note and the other types show up right there.
Anything the preview can render, you can now insert from the slash menu.

Two smaller things I kept tripping over are fixed too: a table stays in the reading column when it
fits, and a narrow side pane keeps its table of contents, as a thin rail.
