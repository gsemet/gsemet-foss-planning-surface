## Pillow 13 changelog

Source: the [13.0.0 release notes](https://pillow.readthedocs.io/en/stable/releasenotes/13.0.0.html),
released 2026-10-16.

**Breaking changes:**
- Python 3.10 is dropped.
- Saving 32-bit `I` mode images as PNG no longer clips the values.
- `Image.fromarray(mode=)` is now restricted.
- `get_child_images()` moved to `ImageFile`.
- `Image._show()` is removed.
- `ImageCms...product_name/product_info` are removed.
- `ExifTags.IFD.Makernote` is removed.

**Deprecations:**
- The IM format.
- `JpegImageFile.load_djpeg`.
- `ImageQt.align8to32`.

**Our uses:**
- Only `scripts/generate-readme-images.py` imports PIL. It uses `Image.open`, `convert("RGB")`,
  `crop`, `resize(..., Image.Resampling.LANCZOS)`, `save(optimize=True)` and `tobytes`, always
  on RGB images. None of these is affected.
- `scripts/version.py`, `scripts/release_notes.py`, `test/visual/capture.py` and
  `test/build/test_release.py` do not import Pillow.

**Empirical check:**
- I rendered the 9 README crops taken from visual captures with Pillow 12.3.0 (read-only use of
  the main checkout's `.venv` python, no sync) and again with Pillow 13.0.0 (scratch venv).
- I compared the outputs pixel for pixel: 9 compared, **0 differ**.
