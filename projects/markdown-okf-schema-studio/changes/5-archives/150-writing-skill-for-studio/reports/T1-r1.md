## Decisions
- Findings from probing the real pipeline, encoded in the skill: inline `<svg>` in Markdown is dropped, so raw SVG is a file shown with `{figure}`/`![]()`; `[[toc]]` is literal text (only `[TOC]`, `[[_TOC_]]`, `{contents}`); emoji shortcodes do not render; palette mode only affects buttons, all syntax renders in all modes.
- Bug found, not fixed: a bare `:::{dropdown}` renders an empty `<details></details>` (body lost). Skill uses `:class: dropdown`; worth a backlog item.
- VSIX/install command: `skills/` is not in `.vscodeignore`, so the VSIX already carries the folder; no install command built (needs command, folder prompt, test, SwRS); recorded in the guideline as a separate CR.
- Mermaid syntax is only checked as far as the fence reaching the page (drawn client-side); noted in the guideline.
