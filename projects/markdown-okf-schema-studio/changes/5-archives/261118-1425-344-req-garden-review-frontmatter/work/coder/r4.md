# CR-344 coder round 4 (test-only fix of stepSchemaOrderAndBadge)

## Root cause found

The two regexes of `stepSchemaOrderAndBadge` (test/integration/previewEditing.test.ts, old lines
1007 and 1024) did not contain `\b` but a literal BACKSPACE byte (0x08) on each side of
`okf-error`: `/<tr class="[^"]*<BS>okf-error<BS>[^"]*" data-okf-field="count"/u` (seen with
`cat -A` as `^H`). A JS regex with a literal 0x08 matches only a backspace character, so the
wait could never succeed: the predicate was always false, whatever the preview rendered. This is
the cause of the CI timeout at ~line 1006. The `finally` wait (`!regex`) passed at once for the
same reason, so it checked nothing. The bytes most likely came from an r3 Python edit script
writing `"\b"` in a non-raw string. The diagnosis's probe 3 retyped the regexp by hand with a real
`\b`, so it could not see this. A scan of src/, test/, requirements/ and docs/ (`grep -P '\x08'`
on .ts, .md, .yaml, .json) found no other backspace byte. After the edit the file has none.

## What changed

Only test/integration/previewEditing.test.ts, `stepSchemaOrderAndBadge` and three small helpers
below it. No change to src.

## Checklist

1. done: before the outside edit, `showTextDocument(document, ViewColumn.One)` then
   `waitForCurrentPreview(document)`. `requestBefore` is now read after that.
2. done: after `applyEdit`, `waitForCurrentPreview(document, requestBefore)` runs first, then the
   wait for the count row's error class (the old order is reversed).
3. done: the regexes are replaced by `countRowTag` (extracts `<tr ...data-okf-field="count"...>`,
   attribute order free, with real `\b`) and `countRowHasError` (tests `class="...okf-error..."` in
   that tag; returns undefined when there is no count row). The main wait requires `=== true`. The
   `finally` wait requires `=== false`, so a missing row no longer passes it.
4. done: `withPreviewEvidence` wraps the four waits (render after edit, error row, valid row again,
   final render). On timeout it rethrows the message with
   `[phase=… documentVersion=… document.version=… requestId=… sameDocument=… countRow=<tag>|no count row]`,
   or `[no active preview]`.

The step keeps its markers (FMSCHEMA-010/029/039) and its assertions. It is not skipped.
