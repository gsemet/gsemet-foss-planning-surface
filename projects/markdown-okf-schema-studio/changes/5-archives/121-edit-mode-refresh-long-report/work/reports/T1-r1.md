## Method

- Worktree build at 5aff39e (compiled and bundled), plus a second build of eb812ad (the commit the
  user's installed 0.3.1 comes from), exported with `git archive` to a scratch folder.
- Real VS Code windows driven through CDP with real mouse and keyboard input (the
  `markdown-studio-exploratory-qa-claude` driver), under `WINDOW-TESTS.lock` (taken, then removed).
  Light theme, 1440 px window. `repro-document.md` copied into disposable workspaces.
- Two workspaces: a plain folder, and a git repo (git enabled) where the file sits in a git-ignored
  `.agents/changes/` folder, like the original.
- Two layouts: Open With (Studio custom editor) and text editor with "Open Preview to Side".
- Probes, injected in the preview: a MutationObserver (render bursts = childList batches more than
  150 ms apart, and node records), a requestAnimationFrame sampler for `scrollY`, `scrollHeight` and
  element count, `layout-shift` entries, a ResizeObserver on the body, and the console/navigation
  observer (`observe.mjs`).
