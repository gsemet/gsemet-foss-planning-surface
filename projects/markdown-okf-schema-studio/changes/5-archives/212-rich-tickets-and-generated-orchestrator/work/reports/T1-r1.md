## Design decisions

- Exit codes: 0 ok (drift alone is 0); 1 missing/unparsable header (file still written); 2 bad changes root or no repo URL.
- Header regexes accept free text in fields, so `PR: — (Foreman)` parses; PR link only when the field starts with `#n`.
- Drift: match by name minus `NNN-` or equal first H1; item dropped from Backlog, listed in a "Drift" list after the alert, `warning: drift: ...` on stderr, paths relative to the changes root.
- Date rule: alert line `> Updated YYYY-MM-DD: N active CRs.`; the file is rewritten only when content differs once that line's date is ignored.
- Landed PR: `/pull/n` first, then `PR #n` / `PR: [#n`. A bare `Landed: #223` (CR 201/202 style) gives `—` per spec.
