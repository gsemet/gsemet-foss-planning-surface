## Candidate StRS (use cases)

- UC-PALETTE-1: A writer formats and inserts Markdown (headings, emphasis, colours, code, quotes,
  rules, emoji, GFM and MyST constructs) from palette buttons, one undoable step each, in the mode
  they chose.
- UC-PALETTE-2: A writer chooses which button set the palette offers (Strict, GFM, MyST) per
  workspace, by setting, by select or by keyboard, and the preview remembers it.
- UC-PALETTE-3: A writer inserts and edits links, images and figures through a panel or a native
  file picker that stays inside the workspace and keeps untouched source as it was.
- UC-PALETTE-4: A MyST writer references labels, other documents and bibliography keys from lists
  that the workspace provides, within bounded scans.
- UC-PALETTE-5: A writer types `/` and finds, filters and runs any palette command from the
  keyboard, without it ever getting in the way of ordinary text.
- UC-PALETTE-6: A writer pastes screenshots and rich text from other tools and gets files next to
  the document and Markdown, with refusals instead of unsafe writes.
- UC-PALETTE-7: A writer keeps the palette in reach above a tall editor box, in narrow panes and
  with reduced motion, without the text jumping.
- UC-PALETTE-8: A writer formats text inside a table cell with the inline buttons and the slash
  menu.

## Notable findings

- OPEN QUESTION confirmed (F-PALETTE-060): MyST mode shows both "Key" (`<kbd>`) and "Key (MyST)"
  (`{kbd}`), and the `/` menu lists both; nothing documents which one to use.
- Docs drift: CHANGELOG bullet 63 says `editing.defaultPaletteMode` defaults to MyST, but the code,
  `package.json` text and README say `gfm` (F-PALETTE-003/004); README lists an "inline code" palette
  button that does not exist in the registry (no inline-code action; the `/` aliases `code` and
  `pre` find Code block); CHANGELOG bullet 20 says "Save" while the link panel button reads "Insert".
- Restricted Mode asymmetry: `previewListTargets` is allowed in a read-only preview, while
  `previewListCitations`, `previewPickDocument`, `previewPickImage` and `previewPasteImage` are
  refused; none of these refusals has a test (F-PALETTE-088..093).
- No test covers the `preferGroup` wiring of the slash menu in a real page, the alias strings of
  about 125 of the 150 slash entries, the figure-form messages other than width, forced-colours
  rules or CRLF inside a palette edit.
- The cell editor has no mode select or Cmd/Ctrl+Shift+M path and no image/HTML paste hook;
  the table cell slash menu lists only cell-scope entries.
- Visual lock v04 keeps the id `…not-sticky-narrow…` for a behaviour that is now "sticky and wraps";
  v06, v08, v10 are `[assertion-only]` duplicates of v05, v07, v09 in dark.
- Thresholds not in README: palette sticky only below 40% of the viewport height and above 520 px
  pane height; bib scan caps (20 files, 2 MiB, 5 s, 1000 keys); paste caps (10 MB image, 1 000 000
  characters HTML).
