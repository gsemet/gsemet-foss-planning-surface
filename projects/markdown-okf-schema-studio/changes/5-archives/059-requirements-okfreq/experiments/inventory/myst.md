## Notable findings

- **Currency may typeset as maths in the preview.** Only the conf.py check filters prices (`$19 … ($200)`); the renderer follows myst-parser, which (per the detector's own comment) makes math from such text where Sphinx's dollarmath does not. No test pins the rendered result (F-MYST-027). Needs a check by running the preview, not possible in this read-only pass.
- **`{doc}`, `{numref}`, `{download}` have no asserted behaviour** (F-MYST-018): the brief's "each role and its fallback" is only known for `{ref}`, `{cite}`, `{abbr}`, `{sub}`, `{sup}`, `{kbd}`, `{math}`.
- **Label rename dead click** (F-MYST-044): labels starting with `_`, `.` or `-` get an anchor icon but cannot be renamed, and the click is swallowed silently in edit mode. A rename for a stale revision is dropped by the `render` gate with no answer, so the field ends with the 6 s "did not answer" text instead of the stale-line refusal (F-MYST-038).
- **conf.py check does not look into included files** (F-MYST-064) and keeps at most 10 warnings while 11 extensions are detectable (F-MYST-061).
- **The brief's file lists are outdated**: context tags (F-MYST-011 to 014) exist only in `docs/known-limitations.md`; the banner dismissal is session memory (`WorkspaceChoices.dismissedWarningBanners`), per document URI, with no test of the host side (F-MYST-070, F-MYST-071); `figureSizes.ts` has no unit test (F-MYST-031), nor has `DiagnosticsController` (F-MYST-066).
- Math error case shows raw TeX with a wavy underline but is not reported in the status region or Problems view (F-MYST-023).
- Untested paths: context tags in list items or quotes (F-MYST-014), host refusals for untrusted and open-edit rename (F-MYST-038), the 6 s timeout and 5 s auto-close (F-MYST-040), conf.py event deferral while a block edit is open (F-MYST-067), KaTeX bundle missing (F-MYST-022).
