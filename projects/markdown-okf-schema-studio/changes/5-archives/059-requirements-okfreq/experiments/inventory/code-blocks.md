## Candidate StRS (use cases)

- UC-CODE-1: A writer reads code samples (any common language, diffs, numbered and emphasized
  listings) as they would appear in documentation.
- UC-CODE-2: A reader copies the exact code of a block from the preview in one click, in any
  preview (also read-only).

## Notable findings

- The copy button always shows "Copied", even when the host refuses the text (over 1 000 000
  characters) or drops the request as stale (version mismatch while typing): no acknowledgement.
- No keyboard path to the copy button; the "Copied" state is not announced.
- Diff header lines `---`/`+++` are coloured as deletions/additions.
- Supported grammar and alias lists are not documented in README.
