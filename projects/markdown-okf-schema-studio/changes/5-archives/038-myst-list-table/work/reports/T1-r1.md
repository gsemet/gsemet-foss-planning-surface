## Autonomous decisions (for "Decisions prises en autonomie")

1. Column alignment colons (`:---`) and `:widths:`/`:align:` are presentation: dropped going to a list-table or a pipe table (a list-table has no per-column alignment). Lossless round trip holds for tables without alignment.
2. A list-table title or `:name:` going to a pipe table is refused (content loss), no `{table}` wrapper is generated.
3. `:header-rows: 0` to pipe: an empty header row is added; more than 1 header row is refused.
4. A pipe table inside a `{table}` figure: the table-bar button is disabled (block palette conversion there would nest a figure; left as is).
5. Two palette/slash actions (List table, Pipe table) in addition to the table-bar button, because a list-table has no cell editor and its block editor is the raw palette; they show only inside a table of the other form.
