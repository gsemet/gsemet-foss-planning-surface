# Inline Comment thread

Existing chip: TODO, comment.

Add a new one to allow to comment on a particular point in the md. Not on a selection of text.

format:

```
<!-- THREAD
User 1 (2026-10-16 10:47):
  this comment is a text
  that can span accross several lines
User 2 (2026-10-16 10:52):
  this a reponse.
-->
```

This appears as a chip (green color), with user with callout icon.

Expands as a temporary admonition-like callouot with the various interactions.
