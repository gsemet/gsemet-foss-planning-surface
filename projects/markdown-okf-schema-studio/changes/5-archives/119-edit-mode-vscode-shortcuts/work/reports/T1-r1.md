# T1 round 1 report (CR 119)

## Design
Undo, redo, select all and delete line in a block or table-cell text box are VS Code key bindings
(package.json: 4 commands `markdown-okf-schema-studio.edit{Undo,Redo,SelectAll,DeleteLine}`, hidden from the
palette, `when: markdownOkfSchemaStudio.previewEditing`). Page: the default key cancels the native action and is
not stopped, so it reaches VS Code; the command comes back as host message `previewEditCommand` and is applied
to the focused text box. Host sets the context (HostUi.setPreviewEditing) when the focused preview has an
editor open. Frontmatter fields keep their old behaviour. Delete line follows VS Code (Cmd/Ctrl+Shift+K;
Cmd/Ctrl+K stays the link panel / chord prefix).
