## Finding
Block editors already had the bar above the frame, sticky inside a host (CSS), so most of the spec existed. Real gaps:
1. Narrow panes (max-width 480px) dropped the sticky bar: it left the viewport when the block top scrolled out (spec 3 wants it kept inside the pane).
2. The table-cell toolbar (`.sphinx-preview-table-menu`) was `position: static`: it scrolled out of sight on a tall table.
3. Frontmatter editors show no format bar: nothing to do.
The screenshot case (bar over the first line) is the sticky bar riding over the box top when the box top is under the preview controls; it is the viewport limit (decision 1) and is kept; tests now use a state where the bar fits above the box.
