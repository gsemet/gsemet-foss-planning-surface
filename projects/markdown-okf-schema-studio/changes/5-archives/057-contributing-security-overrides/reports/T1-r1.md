### Verdict

- `markdown-it ^14.3.1`: **still needed**. Without it five MyST packages resolve Markdown-It 13,
  a line without releases since 2023. `scripts/patch-myst-imports.mjs` (postinstall) exists only
  to make MyST work on 14, which confirms the intent. Removing it would also need a relock with
  the network. Kept.
- `csv-parse ^7.0.3`: **still needed**. Without it `myst-directives` resolves the 5.x line
  (last release 2024). Removing it needs a relock with the network. Kept.
- `linkify-it ^5.0.2`: **redundant, removed**. Its only consumer is `markdown-it`, and the
  forced `markdown-it@14.3.3` already declares `linkify-it ^5.0.2`, the same floor. The lockfile
  (v3) does not record `overrides` (`grep -c overrid package-lock.json` → 0; root entry has no
  overrides key), so the lock needs no change. `npm ls --all --offline` output is byte-identical
  before and after the removal and exits 0 (no invalid/missing/extraneous). It would become
  needed again only if the `markdown-it` override were dropped while MyST still asks for 13
  (13 uses linkify-it 4); the note says so implicitly ("Markdown-It 14 also brings linkify-it 5").
