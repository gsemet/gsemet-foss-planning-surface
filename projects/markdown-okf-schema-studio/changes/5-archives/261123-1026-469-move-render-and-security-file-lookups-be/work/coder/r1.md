## Design notes

- Sync sanitizer: a regex pre-scan of the HTML primes the likely resources, the sanitizer runs, any request it asked for and the memo lacked is primed and the page is sanitized again (at most 3 extra passes, diagnostics of the earlier pass dropped). The regexes use `\x22` and `\x27` for quotes because the user-facing-text lexer test misreads quotes inside regex literals.
- `RenderingController.updatePreview` is now async and serialised per session (promise chain); `isShowable` is checked before and after the awaits.
- `FileSystem` port interface moved to `src/core/files/fileSystem.ts`; `src/host-api/fileSystem.ts` re-exports it. Needed because core may not import `host-api` and no exception may be added. Every existing import keeps working.
- `scripts/unused-exports-allowlist.json`: entry `MAX_GLOB_MATCHES` removed (the export is now used by the glob test; the check demanded it).
- Test harnesses (`test/host/hostHarness.ts`, `lifeReqHarness.ts`): a `turn` now also does one disk round trip, as the host reads through an async port.
- `test/session/readOnlyImagesSession.test.ts` and `trustReq.roots.requirements.test.ts`: the `ignored()` proxy now honours properties set on it (it hid `manager.host.files`).
- `trustReq.requirements.test.ts` missing-root test: the roots now open on the first request, so a request is made before the diagnostic assertion (same intent).
- `contentCaches.test.ts` CORE-013 stat test: counts calls through the port (`mock.method` on the file system) instead of `fs` sync functions; the realpath count filters on the file path.
- `plantUmlRenderer.test.ts` cancel test: waits for the spawn before aborting (an abort before the spawn now cancels before any process starts, which is the intended behaviour).
