# T1 round 1 report - CR 145 paste a URL as a link or image

## Before state (kept, not changed)
- Rich paste (`pasteHtml.ts`, SwRS PALETTE-213): a clipboard with `text/html` goes to the host and comes back as Markdown. Kept as is.
- Image paste (`pasteImage.ts`, PALETTE-203): an image file on a clipboard without text is saved by the host. Kept as is.
- A clipboard with plain text only (a copied URL) was a native paste: the raw URL replaced the selection. Real-window before shots show it: `Read the https://example.com/docs for details.`, and an image URL pasted in the middle of the text.
- Cmd/Ctrl+Shift+V was already left to the browser (pasteHtml `noteKey`).
- The link-scheme rule (http, https, mailto) was already in place; the new code uses the same three schemes.

## Implementation
- New `src/page/modules/pasteUrl.ts` (`installPasteUrl`, `pasteUrlEdit`, `pastedUrl`, `isImageUrl`). Over selected text: `[text](url)`; alone: `<url>`; image address (http/https, `.png .jpg .jpeg .gif .svg .webp`, query and hash ignored): `![](url)` (`![text](url)` over a selection). Destinations with parentheses go in `<...>`.
- Wired in `src/page/runtime.ts`, `src/page/features/pageRuntime.ts`, `src/page/features/blockSourceEditor.ts`: order is image paste, then URL paste, then rich-text paste. The edit goes through `textControls.applyTextEdit` (one native undo step, autosave), so the source changes only inside the edited span.
- The paste stays native for: Cmd/Ctrl+Shift+V, a clipboard that also holds `text/html`, other schemes, text with spaces or line breaks, more than 2048 characters, a caret in a fenced block, an inline code span or a link target, a selection with a line break, `[` or `]`. The table cell editor has no paste hook (native, unchanged).

## Autonomous decisions
- Image address over selected text gives `![selection](url)` (alt text from the selection); alone it gives `![](url)` with the caret in the empty alt text.
- A URL on a clipboard that also has `text/html` is left to the rich paste (copying a link from a web page keeps its current conversion).
- `www.` addresses and `tel:` are not turned into links (only http, https, mailto).
- The new SwRS got the ID PALETTE-003 from `okfreq new` (free number in the scope).
