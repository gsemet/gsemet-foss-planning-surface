## What was built

- Core pass `src/core/render/frontmatterValues.ts` (pure, `yaml` only, already a dependency), run as the tree pass "front matter values" after "wiki links" in `mystRenderer.ts`.
  - Inline code that is exactly `= this.<path>` or `=this.<path>` (at most one space) becomes `<span class="okf-frontmatter-value" data-okf-this-field="<path>">text</span>`. The text is a hast text child: never parsed as Markdown or HTML.
  - Formats: string/number as text, boolean `true`/`false`, list joined with `, ` (items formatted the same way), object as flow-style YAML on one line (`{ name: Ada, team: core }`).
  - Missing value (absent, empty, null, path through a scalar, inherited name such as `toString` or `__proto__`, no front matter, invalid YAML): the `<code>` stays as written with class `okf-frontmatter-missing` and a title that says why; one warning diagnostic per use with the source line (cap 20 per render).
  - Dotted paths (`this.a.b`): implemented (natural; own properties of plain objects only, no array indexes). A top-level key that itself holds a dot wins.
  - Only the document's own front matter (`source`). Fenced code is untouched (not an inline node).
- Refresh: no extra code needed. Every text change, from the page front matter edit or the text editor, goes through `refreshPreviewDocument` and renders the whole document again (`hostEvents.refreshPreview` -> `rendering.refreshPreviewDocument`), so the value follows. The properties table patch is separate. Proven by a render-twice unit test; the edit-mode source keeps the expression because only the HTML changes.
- Style `src/core/preview/styles/frontmatterValueStyles.ts` (added to `PREVIEW_THEME_CSS`): value inherits the text font; missing code gets a tinted background and a 2px dashed warning underline (`--studio-editorWarning-foreground`, fallback chart yellow).
- Writing skill: Inline row of the SKILL.md table (stays at 159 lines, limit 160) and a section with a rendered example in `references/examples.md` (syntax, formats, missing-key style).
