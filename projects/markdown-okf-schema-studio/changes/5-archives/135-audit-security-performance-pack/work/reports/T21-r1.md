## Design

Patches are applied in memory, from one table, by two adapters:
- `scripts/myst-patches.mjs`: the 3 transforms (dollarmath 0.5.0 and myst-to-html 1.7.4 import path utils.js -> utils.mjs; markdown-it-myst 1.0.18 split-once-per-state), `patchMystSource(path, source)` and `mystPatchPlugin` (esbuild onLoad). Version read from the package's package.json; mismatch or unexpected content throws "Review the MyST source patch for <pkg>...". Already-patched content passes (shared install is patched by T1).
- `scripts/myst-patch-hooks.mjs` + `scripts/register-myst-patches.mjs`: Node module `load` hook, used as `node --import ./scripts/register-myst-patches.mjs` for Node-run consumers.
