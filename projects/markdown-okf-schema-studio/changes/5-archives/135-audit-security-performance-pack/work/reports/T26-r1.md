# T26 round 1: split the 700+ line modules (coder report)

Worktree `../markdown-okf-schema-studio-wt-135-t26`, branch `change-requests/135-t26-split-large-modules`.
Nothing committed, nothing pushed (that is the driver's job).

## Approach

Pure moves. The code is copied verbatim (checked: every line of each old file is still present in the
old file plus its new companion, except for the edits listed under "Non-verbatim edits"). Each old
file keeps its public API: it re-exports what moved, or delegates to it, so no import outside the
split pair changed and no test changed.

Two limits applied while choosing what moved:

- A new `src/core/` file that imports a Node built-in would need a new `NODE_DEBT` entry in
  `.dependency-cruiser.cjs` (an exception; the constitution forbids adding one). So only the pure,
  no-file-access part of `fileLinks.ts` moved; disk resolution stays in `fileLinks.ts`.
- Closures (`createEditPalette`, `createMarkdownTableTools`) were split along existing seams only:
  the type declarations for the palette, and a self-contained group of pure functions for the table,
  bound through a factory exactly like the existing `createTableStructureTools`.

## Non-verbatim edits (all mechanical)

- Imports adjusted in every old and new file; `export` added on the moved declarations the old file
  now imports (listed above).
- `pageDocument.ts`: `postPendingOverlay` and `endPendingOverlay` went from `private` to `protected`
  (called by the subclass); `manager` is `protected readonly` on the base instead of
  `private readonly` on `RenderingController`; `RenderingController` has no constructor of its own.
- `sessionFactory.ts`: `this.<member>` became `manager.<member>` (`const { manager } = this`);
  `this.live.add(session); this.activeSession = session;` became `this.hooks.adopt(session);` and
  `this.releaseGroupLock(session)` became `this.hooks.releaseGroupLock(session)`, at the same place in
  the sequence. `{@link requestDocument}` became `{@link PreviewManager.requestDocument}`.
- `pageToHostMessages.ts`: `const PAGE_STATE_MESSAGE_TYPES` gained `export`.
- Doc comments: a header for each new file; `rendering.ts` header names its base class;
  `pageToHost.ts` header step 1 names `pageToHostMessages.ts`.
