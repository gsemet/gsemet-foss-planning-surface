## Blocking

### F1. The CSP splice can fail open: a `<head>` text in an attribute of `<html>` swallows the policy

`injectContentSecurityPolicy` takes the first `/<head(?:\s[^>]*)?>/` match in the whole string. The
sanitizer keeps `aria-*` and `data-sphinx-*` attributes, and parse5 merges the attributes of any
later `<html>` start tag onto the root element, then serializes `<` inside attribute values
unescaped. Probe on the worktree build (`rewriteSphinxHtml` then `injectContentSecurityPolicy`),
body `<html aria-label="<head>"><p>x</p>`:

```
<!DOCTYPE html><html aria-label="<head><meta http-equiv="Content-Security-Policy" content="default-src 'none'">"><head><title>t</title></head>...
```

The meta lands inside the attribute value: the page has no CSP element at all (same with
`data-sphinx-x="a<head>b"`). Today the MyST renderer drops raw `<html>` tags before the sanitizer
(checked 7 variants end to end through `renderPreviewDocument` + `buildPreviewWebviewHtml`: block,
inline, `{raw} html`, table cell, `<details>`, `<svg>`, upper case; CSP present in all), so it is not
exploitable from a Markdown file now. But the guarantee of TRUST-012 now rests on a non-local
invariant of another module, and the failure mode is "no policy" rather than "old policy"; the tree
version had no such dependency.

Fix (small): accept the splice only when the text before the match is exactly the serializer's
prefix, and fall back to `injectContentSecurityPolicyInTree` otherwise, for example

```ts
const SERIALIZED_PREFIX = /^(?:<!DOCTYPE[^>]*>)?(?:<!--(?:(?!-->)[\s\S])*-->)*<html(?:\s+[^\s"'>/=]+(?:="[^"]*")?)*>$/iu;
if (!opening || !SERIALIZED_PREFIX.test(html.slice(0, opening.index))) return injectContentSecurityPolicyInTree(...);
```

(parse5 always double-quotes attribute values and escapes `"` in them, so `"[^"]*"` delimits them
exactly.) Add a test in `test/security/cspInjection.test.ts`: the sanitized output of a body with
`<html aria-label="<head>">` gets the policy as a real head element (parse the result and find the
meta in `head`), and keep the existing three tests.
