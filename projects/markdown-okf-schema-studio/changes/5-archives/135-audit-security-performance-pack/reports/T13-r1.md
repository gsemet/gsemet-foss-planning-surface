## Files changed
- `src/session/sharedWatchers.ts` (new): `SharedWatchers` (one host watcher per base+pattern, refcounted, disposed with the last listener) and `SharedLinkedTargetWatches` (one host+direct watch per linked target, shared, capped at 256 targets; past the cap a closed/"failed: watch limit" stub, the preview-wide watcher and the save handler still apply).
- `src/session/previewManager.ts`, `previewSession.ts`: the per-session `**/*` dependency watcher is now a hold on the shared watcher of the resource root (`session.dependencyWatch`); the manager owns `sharedWatchers` and `linkedTargetWatches`.
- `src/session/hostEvents.ts`: `refreshReferencedPath` returns early (after the cheap `sharedRenders.invalidate()`) unless the path is the shown file, a linked target, a PlantUML include or in the dependency set; canonical path of the changed document resolved once per event, the canonical shown path cached per session; the stem watcher invalidates on create/delete only.
- `src/node-services/build/buildQueue.ts`: `dependsOn(filePath, canonical?)` uses a canonical dependency `Set` cached per stage (one `realpathSync` per dependency per render, not per query).
- `src/session/features/frontmatter.ts` (minimal): linked-target watches go through the shared registry; entries carry a precomputed `canonical`, `watchesLinkedTarget` compares it (no realpath).
- `src/session/features/links.ts`: link-target `findFiles` gets `exclude` (node_modules, .git, _build, .venv, venv) and `maxResults: 50` (exported constants).
- `test/session/eventFanOut.test.ts` (new, 8 tests), `test/host/lifeReq.requirements.test.ts` (1 test rewritten).
- SwRS (prose + marker lists, hand-ordered): LIFE-143, LIFE-044, LIFE-039, FMSCHEMA-055, FMSCHEMA-067, TOOLBAR-079. The ~268 reordered baseline files were reverted.

## Open points

- `sharedRenders.invalidate()` still runs on every foreign change (cheap, no syscalls); kept for correctness of in-flight renders.
