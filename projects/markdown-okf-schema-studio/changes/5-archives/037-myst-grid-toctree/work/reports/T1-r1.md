## What was done
- `{grid} a b c d`: xs/sm/md/lg column counts (missing ones inherit the previous; 1-12 or `auto`), one class per breakpoint, container queries on the grid wrapper so the pane width (not the window) decides. Both ``` and `:::` fences, nested grids (longer outer fences). Body cut from the raw source lines (the parser collapses blank lines), so `data-line` of every nested paragraph is exact.
- Card: title (inline markdown, flattened to text inside the link), `:link:` (+`:link-type: url|doc|ref`, `:link-alt:`) as a stretched link over the whole card, header `^^^` body `+++` footer split outside code fences.
- `{toctree}`: label = explicit `Title <target>`, else target H1 (ATX/setext, outside fences, frontmatter skipped), else file name; `.md/.myst/.markdown` candidates; links go through the existing link navigation (`data-sphinx-preview-navigation`); `:caption:` as `<p role=heading>` (not an h2, to stay out of TOC/outline); `:hidden:` renders an empty hidden block; `:glob:` sorted; `:reversed:`; missing = dashed orange span with warning icon, no link; external URLs linked. Resolved targets are added to render dependencies.

## Autonomous decisions (for the PR "Décisions prises en autonomie")
- Breakpoints are container widths tuned for a preview pane: sm 480, md 640, lg 800 px (Bootstrap's 576/768/992 refer to the window and would never reach 2 columns in a 900 px pane).
- `:gutter:`, `:class-*:`, `:shadow:` etc. are ignored (fixed gap).
- Missing toctree target: warning style only, no diagnostic entry; special names (`self`, `genindex`, `search`) show as missing; leading-`/` entries are not supported.
- Toctree inside an included file resolves relative to the main document.
- Grid-item-card `:link:` defaults to a URL as written (relative `.md` paths open in the preview).
