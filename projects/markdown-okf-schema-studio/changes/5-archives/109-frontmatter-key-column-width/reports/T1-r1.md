# T1 round 1 report - CR 109 front-matter key column

## Fix
Cause: the preview-wide `overflow-wrap: anywhere` on `th`/`td` made the key column's minimum width one letter.
- `src/core/preview/styles/propertiesStyles.ts`: `.okf-name-text` is `white-space: nowrap`, `overflow-wrap: normal`, ellipsis; key `th` has `width: 1%` (column fits the longest key); `.okf-name-cell` has `max-width: calc(40cqw - 2em)`; `[data-okf-properties]` is the size container for `cqw` (a `display: table` box cannot be one; no fixed/overlay UI lives inside the section). Marker `@implements_req SwRS-MDOKFSTUDIO-FMSCHEMA-005` added. The narrow-pane (<=640px) block is untouched.
- `src/core/frontmatter/propertiesTable.ts`: keys longer than 24 characters get `title` = full key (plus the row tooltip); short keys keep the old markup, so existing markup assertions did not change.
