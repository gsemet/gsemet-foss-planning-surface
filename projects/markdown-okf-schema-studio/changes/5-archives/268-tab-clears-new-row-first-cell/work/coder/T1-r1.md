# CR 268 coder report, round 1

## Result
The cell left with Tab, Shift+Tab or an arrow key now shows the text just typed, as inline Markdown, with no re-render and no extra save. Nothing committed.

## Cause and fix
`switchTableCell` restored the content captured when the editor opened (empty for a new row, old text otherwise). It now rewrites that captured wrapper from the typed value before restoring it, only when the text differs from the text at open (`edit.cellTextAtOpen`, new field on `BlockEdit`); an untouched cell keeps its full rendering (math, images, links).
No inline renderer exists in the page layer (the real one is MyST in `src/core/render`, heavy and not page-bundled), so a small DOM builder was added: `src/page/modules/cellInlineMarkdown.ts` (code, strong, em, del, links with safe hrefs, `<br>`, backslash escapes; text only through `textContent`, no HTML parsing). Choice stated per task.md; the full MyST rendering returns at the next page render.
