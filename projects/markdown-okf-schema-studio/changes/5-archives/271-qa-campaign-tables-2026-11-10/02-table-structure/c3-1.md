## Why this is wrong

GFM accepts `:-`, `--`, `:--` as delimiter cells and the preview renders them as a table, so an author who writes compact tables sees a table but gets none of the structure tools: no toolbar, no handles, no cell editor, only the raw text of the whole table. The same table with one more dash works, so the product contradicts itself. Nothing tells the author why.

## Steps to reproduce

1. Fixture `synth/structure-twodash-lf.md` (LF; `structure-crlf-3dash.md` is the working three-dash twin).
2. Open it, Open Preview to Side, edit mode on, click cell `a1`.
3. A whole-table text editor opens; compare with the twin.

## Suggested direction

`src/page/modules/markdownTable.ts` line 219: `/^:?-{3,}:?$/u` rejects delimiter cells under three dashes, so the table is parsed as not editable. Accept `-{1,}` when reading; keep three dashes when generating (TABLE-111).
