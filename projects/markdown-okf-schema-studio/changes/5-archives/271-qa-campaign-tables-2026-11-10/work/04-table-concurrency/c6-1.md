buffer (spy diff vs disk): unchanged        preview td: "alpha X"

## Why this is wrong

The author sees a value the file does not contain. Editing the cell reopens the editor with the true text (`alpha`), so nothing is corrupted, but the table disagrees with its file until another edit re-renders it, and the sibling paragraph block did update, so the preview looks half refreshed. In the c3-2 sheet the same family (preview table stale after a buffer change) shows up with undo.

## Steps to reproduce

1. Fixture `synth/c6-concurrency.md`; side preview, edit mode on.
2. Click the `alpha` cell, type ` X` (the buffer is written live: diff shows `alpha X`).
3. Rewrite the paragraph line of the file on disk with an external tool (VS Code then shows "content is newer" on save: standard).
4. Press Tab, then Escape (closes the next cell editor).
5. With the source focused, run File: Revert File.

Plain commit then Revert File without the external rewrite does not reproduce (checked once).

## Impact

Visual desync after an external tool touches a file with an open cell editor; no data lost.

## Suggested direction

Re-render the table block when the buffer returns to a text that matches an earlier render but not the current DOM (compare against the current table source, not the last rendered text).
