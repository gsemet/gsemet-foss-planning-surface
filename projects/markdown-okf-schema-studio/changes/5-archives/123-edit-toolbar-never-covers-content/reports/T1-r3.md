  67-toolbar-cover.md now has a 40-line code block. Its top is scrolled 150 px above the viewport, then the first row

- Fix: `tallBlockClearance` in src/page/features/editorChrome.ts, called from `keepTextInPlaceBelowPalette`,
  applies on opening only. When the host is more than one bar height above the sticking line, the page also scrolls
  up by (sticking line - visible sticky band bottom + 6 px). The first line seen goes below the bar, and earlier
  lines fill the space above it. A close scrolls back through the existing `paletteShift`.

    existing scroll-padding already keeps the caret clear. Moving the text that was visible needs a scroll at
    opening.

  - After: `after-headless-tall.png` shows rows 1-4 above the bar and row 9 onward below it.
