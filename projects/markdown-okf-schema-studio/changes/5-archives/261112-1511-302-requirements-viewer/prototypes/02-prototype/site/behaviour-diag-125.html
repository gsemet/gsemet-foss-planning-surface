Behaviour DIAG-125

SVG blocks are drawn inline after the sanitizer rebuilt them

When a document holds an svg fence or a raw svg element that fills a whole block, the preview SHALL draw it inline as a picture rebuilt from an allow-list of drawing elements and presentation attributes, with every id and reference renamed per picture, and SHALL draw an svg element inside a sentence, a comment, a math block, a code block or a raw HTML table as nothing.

Part of DIAG-001, outside the paths drawn on its map.
