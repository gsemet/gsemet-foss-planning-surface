# T1 round 1 - CR 125 report

## Behaviour
Tree pass "unclosed fences" (new `src/core/render/mystUnclosedFences.ts`, wired in `mystRenderer.ts`
right after "shift source lines"). A `mystDirective` or `code` node whose opening line is a backtick,
colon or tilde fence, whose last line is not a closing fence, and whose swallowed lines hold an ATX
heading is replaced by a code node of its opening line (raw, from the source) plus the nodes of the
swallowed lines parsed again (lines shifted back to the document's numbering, so `data-line`,
frontmatter and CRLF stay right; recursive, so nested and several open fences work). A warning
diagnostic `unclosed-fence` is reported on the opening line. Source untouched.
Left alone: closed fences, and a fence open to the end of the file with no heading after it (plain code
block still runs to EOF; directive without body keeps its existing raw block; `:::{note}` open at EOF
keeps its admonition, which the existing nested test requires).
