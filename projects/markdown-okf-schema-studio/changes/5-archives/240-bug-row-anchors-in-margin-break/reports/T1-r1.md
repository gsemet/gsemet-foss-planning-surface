# T1 round 1 report (CR 240)

## Cause

The row and column handles were placed once when edit mode applied (`tableRowMove.refresh`), then the
width mode ran (`widthMode.update`) and broke the table out of the column. Nothing placed the handles
again: the only ResizeObserver watches the content box, which a breakout does not resize. The handles
kept the left edge and row heights of the narrower table (the screenshot). Same after a row or column
move: the render re-runs `initializeContent` (edit mode, then width mode).

  end of every `update()` (the old body became `measureWide`).

- `src/page/features/tableRowMove.ts` + `pageRuntime.ts` (interface): new `reposition()` runs `position()`
