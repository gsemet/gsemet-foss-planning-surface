# T1 round 1: syntax coverage audit (CR 248)

Worktree `markdown-okf-schema-studio-wt-248`. Nothing committed. Matrix: [../matrix.md](../matrix.md).

## Result

The audit found two small gaps (fixed) and four larger or undecided ones (not fixed, listed below).
Slash menu and toolbar are built from one registry (`PALETTE_ACTIONS`), so a registry entry gives both;
the only differences are the two menu-only list entries, the shortcut-only comment toggle and the
contextual actions (colour code, list-table, pipe-table).

## Fixed (small, following the Mermaid / Vega pattern)

- No way to insert `{tab-set}` / `{tab-item}`: new action `tabs` (label "Content tabs", MyST and Full,
  `/tab-set`, `/tabs`, `/tabbed`), inserts a two-tab set after the selection. The label is not "Tabs" on
  purpose: a label starting with `tab` outranked Table for `/tab` in MyST (two existing slash tests caught it).
- No way to insert a `plantuml` fence: new action `plantuml` (Full, `/plantuml`, `/uml`, `/puml`), inserts a
  sequence diagram. Placed in Full next to the Vega charts (PlantUML is not rendered by GitHub, unlike Mermaid
  in GFM). It reuses the `mermaid` icon.
- New icon `tabs`.

## Larger gaps for the owner to file

1. Presentation HTML for READMEs (`<div align="center">`, `<p align>`, `<img width>`, `<picture>`): no insert form. Size M.
   Needs a decision on which forms to offer (alignment popover, image width) and a form/popover; renderer already handles them.
2. `{uml} file.puml` include: no insert. Size M. Needs a host file dialog for `.puml`/`.plantuml` files (the existing
   dialog is image-only) plus an action writing the directive.
3. `<sub>` / `<sup>` in GFM mode: the actions exist only in MyST (they write the `{sub}` / `{sup}` roles), so a GFM
   writer has no way to write the HTML form the skill documents. Size S-M: a GFM variant writing `<sub>`/`<sup>`, or
   moving the actions down with a mode-dependent output (product decision).
4. `{list-table}` from scratch (empty skeleton) and `{toctree}` insertion: both reachable only by hand or (list-table)
   through conversion. Size S each, optional; low value, listed for completeness.
