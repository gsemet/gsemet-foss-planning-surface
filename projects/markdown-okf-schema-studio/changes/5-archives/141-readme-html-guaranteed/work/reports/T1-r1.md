# T1 round 1 report (CR 141, README-style HTML)

## Files changed (worktree markdown-okf-schema-studio-wt-141, nothing committed)

New:
- `src/core/render/mystRawHtml.ts`: tree pass "raw html elements" (after "raw details and kbd"). Pairs opening and closing
  tags of raw `html` nodes across sibling nodes, so Markdown after a blank line inside `<div>` stays Markdown. Rebuilds
  elements from an allow-list (div, p, center, h1-h6, br, hr, img, a, picture, source, sub, sup, kbd, details, summary,
  b, i, em, strong, ...) and a per-tag attribute allow-list (align, width/height digits, alt, src, href, title, srcset,
  media, type, sizes, open); no style/class/id/event handler; script/style/iframe/object/svg... dropped with content;
  `javascript:`/`data:` URLs dropped. `<picture>` colour-scheme sources become `img.okf-theme-dark|light` plus
  `img.okf-theme-fallback` (theme-following, not OS-following). Top-level blocks get data-line/data-end-line,
  class `okf-html-block` and `data-okf-tag` = `openingTagTitle(...)` (wired the CR 140 helper). Tables keep their own path.
- `src/core/preview/styles/htmlBlockStyles.ts`: align CSS, per-theme picture image rules (cream/white = light,
  dark = dark, current = body.vscode-dark/hc), edit-mode admonition-like frame with the tag as title (edit mode only).

- `test/core/render/mystRawHtml.test.ts`, `test/integration/readmeHtmlWindow.ts`.
