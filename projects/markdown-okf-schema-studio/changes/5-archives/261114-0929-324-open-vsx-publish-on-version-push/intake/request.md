The Open VSX publish fails on every version push: the release job runs as a reusable workflow called from ci.yml, so the OIDC token names ci.yml, while the only trusted publisher open-vsx.org allows per extension is registered for release.yml (environment release). v1.9.0 needed a recovery dispatch of release.yml. Make the version push publish to Open VSX through a path that matches the registration (for example tag-release dispatches release.yml instead of calling it), keep the dispatch recovery working, and prove the real version-push path, not only a dispatch.
