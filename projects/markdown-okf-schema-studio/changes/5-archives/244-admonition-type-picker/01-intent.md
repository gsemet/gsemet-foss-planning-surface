# Admonition type picker

Split from [bug-missing-slash-for-version-admonitions](../bug-missing-slash-for-version-admonitions/01-intent.md)
(owner, 2026-11-03).

When editing an admonition (GFM alert and MyST directive) with the caret on its type, a list of
types with their icons shows above it, to change the type in one pick.
