## Autonomous decisions / open points
- `depth=N` counts list nesting levels of the generated list (a skipped heading level nests under the previous
  shallower heading); `depth=0` means no limit.
- Headings from `{include}` are not listed; heading text is taken as plain text (inline math or wiki links in a heading
  show their source text).
- Only a paragraph that is solely the marker counts (not in code, not inside a longer paragraph).
- A link to a repeated heading uses `-1`, `-2`; the host's fragment lookup finds the first same-text heading by source
  line, the `-n` ones through the element id.
- SwRS lifecycle left `draft`, like CORE-071. IDs allocated by okfreq: CORE-072, PALETTE-003.
