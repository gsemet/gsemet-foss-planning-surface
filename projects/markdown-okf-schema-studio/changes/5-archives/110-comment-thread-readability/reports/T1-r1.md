# T1 round 1 — CR 110 (comment thread readability, author name setting)

Status: done. Worktree `/Users/az02065/Projects/DevTools/markdown-okf-schema-studio-wt-110`, nothing committed.

## Cause

The comment popover took its text colour from the host token `--studio-editorWidget-foreground`.
The Dark, White and Cream modes did not define that token, so on a forced Cream page under a dark
VS Code theme the popover text was the host's pale grey on cream. The date, the quote, the orphan
meta line and the reply box also used `opacity` (0.7 and below), and the placeholder was the
browser default grey.

- `src/core/preview/styles/pageChromeStyles.ts`: `--studio-editorWidget-foreground` defined in Dark
  (#d4d4d4), White (#1f1f1f) and Cream (#2b2a27); Dark `--studio-descriptionForeground` #9d9d9d to
  #a8a8a8 (placeholder on the input was 4.07:1, now 4.65:1).
