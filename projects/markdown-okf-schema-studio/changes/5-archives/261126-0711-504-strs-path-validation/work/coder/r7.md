## The rule as applied

A StRS marker stays only where the test walks the whole declared path: starting state set up; each step through the
product mechanism (a stub for the user's choice in a native dialog or for the OS clipboard is accepted; an injected page
message, a test hook or a faked host result is not); every state and outcome named in a step asserted (`Option` bullets
aside; for an "or", one side); a one-step render-only path counts when every outcome is asserted (as audit row 30 judged
such a test); in doubt, removed. The per-marker verdicts are judgments from reading; no bench was run for them.
