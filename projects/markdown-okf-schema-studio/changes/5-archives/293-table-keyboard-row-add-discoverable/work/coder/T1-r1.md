## Behaviour

- Hint "Tab: new row" shows in the last cell of the last rendered row, before Done and Cancel; no other cell has it.
- Tab in the last cell remembers `addedRow` in the pending navigation; the reopened edit keeps `tabAddedRow = rendered row`.
- Escape or Cancel in that row: the open cell goes back to its opening text (computed on a copy), and if every cell of the model row is empty (trimmed) the row is deleted with `tableTools.deleteRow`, `saveBlockEdit()` posts one final save. Otherwise TABLE-025 as before. The mark is not carried by the structural buttons, so Row below is never marked, and it dies with the session.
