## Thread

1/ Markdown OKF-Schema Studio 1.0 is out 🎉

We read less code and more Markdown: plans, analyses, reports written by our coding agents. I wanted a surface where I can read them, annotate them and fix them, without leaving VS Code.

Image: `/Users/az02065/Projects/DevTools/markdown-okf-schema-studio/images/readme/showcase-hero.png`

2/ Agents already write rich Markdown: MyST cards and admonitions, Mermaid and PlantUML diagrams, Vega-Lite charts, large tables.

Most previews stop at GitHub Flavored Markdown. The Studio renders all of it, at a comfortable reading width. Wide tables break out of the column.

Image: `/Users/az02065/Projects/DevTools/markdown-okf-schema-studio/images/readme/margin-break-cream.png`

3/ The loop:
• the agent writes a plan in Markdown
• you read it as a real page
• you annotate: a TODO, a review thread on a sentence, a fix in a block
• you ask the agent to react, and the diff only shows what changed

Image: `/Users/az02065/Projects/DevTools/markdown-okf-schema-studio/images/readme/showcase-comment-thread.png`

4/ Edit where you read: click a block and its raw Markdown opens in place. Only that block changes, so there is no reformatting and the diff stays clean. Type / for the slash menu.

Image: `/Users/az02065/Projects/DevTools/markdown-okf-schema-studio/images/readme/showcase-myst-edit.png`

5/ An HTML report from your agent looks great, but you cannot annotate it. Here everything is plain files in your repo: the document, its review comments (JSON next to it), its schema. No account, no server, no vault.

Image: `/Users/az02065/Projects/DevTools/markdown-okf-schema-studio/images/readme/showcase-schema-cream.png`
