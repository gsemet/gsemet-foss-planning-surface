# A frontmatter field with a validation issue is visibly marked

In a bundle with a schema, a field with a validation error (for example `status: publshed` against an enum) shows only a small badge: the row carries the class `okf-error` but no style targets it, while SwRS-MDOKFSTUDIO-FMSCHEMA-035 promises a red underline. The owner wants the row marked like the information rows (answer 1), warnings in their colour. Found while filming the bundle frontmatter clip (CR-499).
