  `"      - Dry goods\n        - Refrigerated goods"`: the line was indented by the marker width

- After `Tab` and `Meta+Enter`, the buffer diff against the mark showed one line changed:

  ```diff
  @@ L69 @@
          - Dry goods
  -       - Refrigerated goods

      - Deduplication
  ```

  check failed because of a wrong DOM expression (`firstChild` was a whitespace text node). The
  expression was corrected in the scenario file and re-run with `q check` against the same page:
  `PASS UX-05 corrected nesting check → true`. The screenshot shows the same nesting.
- The editor's status line documents the keys "Enter: new line · Tab: indent · Esc or ⌘↩: done"
  (seen in the UX-03 and UX-07 replays). `Escape` closes and keeps the text, which is the keyboard
  exit route.
