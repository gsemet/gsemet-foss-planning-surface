# UX-10 replay — Inserting a new section from the Studio editor

**Status: fixed** (inserting between blocks). The empty-document part is out of scope; see the note
below.

Session `r1`, HEAD `50cd143`, workspace `ws-r1`, real input only.

## Steps run

[`scenarios/UX-10-insert-section.json`](scenarios/UX-10-insert-section.json) on
`fixtures-visual/01-handbook-overview.md` in the **Open With** editor (MyST + OKF Studio), with the
side preview closed, as in the sheet's use case:

1. Mark the buffer and turn edit mode on. Insertion points were listed after source lines 1, 5, 10,
   14, 23, 25, …
2. Click the `+` insertion point after the "Terminology drift" admonition (after line 23, before
   `## Depot topology`).
3. Type `## Incident review checklist`, `Enter`, `Enter`, `Check the dispatcher logs first.`, then
   press `Meta+Enter`.

## Observed

All 4 checks passed, with no console error.

- The `+` opened an **empty** inline editor. Its status line reads
  `New block · Enter: new line · Tab: indent · Esc or ⌘↩: done`, so the editor no longer claims to
  be the previous block.
- Buffer diff against the mark: four added lines, separated from their neighbours by blank lines.

  ```diff
  @@ L25 @@

  + ## Incident review checklist
  +
  + Check the dispatcher logs first.
  +
    ## Depot topology
  ```

- The preview renders the new `h2` "Incident review checklist" directly before "Depot topology".
