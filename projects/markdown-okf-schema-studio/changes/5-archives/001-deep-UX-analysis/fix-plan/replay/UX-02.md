# UX-02 replay — One source undo step per inline session, minimal edit range

**Status: fixed**

Session `r1`, HEAD `50cd143`, workspace `ws-r1`, real input only.

## Steps run

[`scenarios/UX-02-one-undo-per-session.json`](scenarios/UX-02-one-undo-per-session.json) on
`book/chapters/02-foundations.md`. The side preview and edit mode were still on from the UX-01
replay.

1. Press `Meta+1` to focus the source editor, then press `Meta+z` once. This undoes the 16-character
   UX-01 session.
2. Mark the buffer. Click the paragraph "Famous LLM includes…", press `Meta+ArrowDown`, and type
   ` twenty chars typed.` (20 characters, 40 ms per key), then press `Meta+Enter`.
3. Press `Meta+1`, then press `Meta+z` once.

## Observed

All 4 checks passed, with no console error.

- Step 1: one `Cmd+Z` brought the buffer back to the file on disk ("unchanged").
- Step 2: the diff against the mark is one line at L137: `…code repositories. twenty chars
  typed.`
- Step 3: one `Cmd+Z` in the source brought the buffer back to the mark ("unchanged").
- Spy change log, one event per document version:

  ```text
  v3 [{"range": [146, 73, 146, 89], "rangeLength": 16, "text": ""}]                 # Cmd+Z of UX-01
  v4 [{"range": [137, 72, 137, 72], "rangeLength": 0, "text": " twenty chars typed."}]
  v5 [{"range": [137, 72, 137, 92], "rangeLength": 20, "text": ""}]                 # Cmd+Z
  ```

  The 20 typed characters produced **one** document change: an insertion of only the typed
  characters, not a whole-block replace. In the original finding, 52 characters produced 52
  whole-block replaces.

## Remaining gap

Only continuous typing was tested. Typing with pauses longer than the 400 ms debounce is expected
to create one undo step per pause (D-02). This was not exercised.
