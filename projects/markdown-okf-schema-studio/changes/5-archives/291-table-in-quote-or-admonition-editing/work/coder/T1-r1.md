# T1 round 1 report: table inside a quote, an alert or an admonition

## Result

A click on a cell of a pipe table inside a blockquote, a GFM alert or a MyST admonition now opens the
cell editor and the table bar. Every table line is written back with its container prefix, the rest of
the container is byte for byte. A table that cannot be located safely (lazy line, mixed `>` and `> `,
count mismatch, no parse) still opens the raw block editor. Convert to list-table is disabled for such
a table with a title. The row and column drag handles are offered and keep the prefix (see open points).
