## Autonomous decisions
- TODO wrapper: Ctrl+/ removes only what it adds. Lines `<!-- TODO: … -->` / `<!-- THREAD … -->` (any
  case) are not "plain": they are left alone, and in a mixed selection the plain lines are wrapped
  while TODO lines stay. A line already a plain comment inside a mixed selection stays single-wrapped.
  Lines containing `-->` that are not plain comments are never wrapped (same rule as TODO).
- Design: a hidden `shortcutOnly` action rather than a new palette button, to avoid a new UI button,
  slash entry (the alias `comment` is already the thread's) and visual/doc ripple. Icon `thread` is
  reused (never shown).
- Table cell: does not share the binding (TODO scope block only; stays so for `comment`).
- New SwRS placed in palette-slash (shortcut handling) with REVIEW-160 cross-reference.
