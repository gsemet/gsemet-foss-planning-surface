# Research: agent plugin formats (raw official pages, fetched 2026-10-28)

| Host | Format | File path | Install command | Official source |
|---|---|---|---|---|
| Claude Code | Plugin manifest (only `name` required; `version` pins users; `skills/<name>/SKILL.md` scanned by default; names must not start with `claude-`/`anthropic-`) | `.claude-plugin/plugin.json` | `/plugin marketplace add gsemet/markdown-okf-schema-studio` then `/plugin install markdown-okf-schema-studio@markdown-okf-schema-studio`; shell: `claude plugin marketplace add ...` / `claude plugin install ...` | https://code.claude.com/docs/en/plugins-reference |
| Claude Code | Marketplace (`name`, `owner`, `plugins[]` with `name`+`source`; relative `source` `"."` = marketplace root; unknown keys warn) | `.claude-plugin/marketplace.json` | as above | https://code.claude.com/docs/en/plugins/marketplace-reference.md , https://code.claude.com/docs/en/plugin-marketplaces |
| Claude Code | Validation | n/a | `claude plugin validate <dir> [--strict]` (CLI 2.1.308 present locally) | plugins-reference "Validate the manifest" |
| Agent Plugins 1.0.0 | `plugin.json` at plugin root; required `$schema` (`https://agent-plugins.org/schemas/1.0.0/plugin.schema.json`) and `name` (<=64, `[a-z0-9.-]`); optional version, description, author, homepage, repository, license, keywords, extensions; `skills/<name>/SKILL.md` only one level deep; additionalProperties false. Spec defines no install command (client-specific) | `plugin.json` | client-specific | https://agent-plugins.org/specification , https://agent-plugins.org/schemas/1.0.0/plugin.schema.json |
| GitHub Copilot CLI | Reads Agent Plugins 1.0 `plugin.json` at plugin root (declaring the `$schema` selects it) or legacy format; skills at `skills/<name>/SKILL.md` | `plugin.json` | `copilot plugin install ./path` (local); `copilot plugin marketplace add gsemet/markdown-okf-schema-studio` (marketplace), then `copilot plugin install markdown-okf-schema-studio@markdown-okf-schema-studio`; direct `copilot plugin install gsemet/markdown-okf-schema-studio` (verified with `copilot plugin install --help`; sources: `plugin@marketplace`, `owner/repo`, `owner/repo:path`, git URL; reference https://docs.github.com/en/copilot/reference/copilot-cli-reference/cli-plugin-reference; install guide https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/plugins-finding-installing) | https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/plugins-creating |
| GitHub Copilot CLI | Marketplace: primary `.github/plugin/marketplace.json`, also looks in `.claude-plugin/` | `.claude-plugin/marketplace.json` (reused) | `copilot plugin marketplace add OWNER/REPO` | https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/plugins-marketplace |
| VS Code (Copilot agent plugins) | Supports Agent Plugins 1.0 plus Copilot, Claude and legacy formats | `plugin.json` | Command Palette "Chat: Install Plugin From Source" with the git URL; setting `chat.plugins.marketplaces: ["gsemet/markdown-okf-schema-studio"]`; `/plugin marketplace add <source>`, `/plugin install <source>`; VS Code discovers plugins installed by Copilot CLI (`~/.copilot/installed-plugins/`); Extensions view `@agentPlugins` | https://code.visualstudio.com/docs/copilot/customization/agent-plugins |
| OpenAI Codex | Root `plugin.json` is the portable entry (Agent Plugins); `.codex-plugin/plugin.json` is only an optional compatibility overlay, used when `extensions.com.openai` is absent; skills auto-discovered from root `skills/`. `agents/openai.yaml` not mentioned in the packaging docs: not used | `plugin.json` | n/a | https://developers.openai.com/codex/plugins/build |
| OpenAI Codex | Marketplace: `$REPO_ROOT/.agents/plugins/marketplace.json` (also reads `.claude-plugin/marketplace.json`); entry needs `name`, `source` (`{"source":"local","path":"./..."}`), `policy` (`installation`: AVAILABLE/INSTALLED_BY_DEFAULT/NOT_AVAILABLE; `authentication`: e.g. ON_INSTALL), `category` | `.agents/plugins/marketplace.json` | `codex plugin marketplace add gsemet/markdown-okf-schema-studio` | https://developers.openai.com/codex/plugins/build |
| Any other skills host | Plain skills copy | `.agents/skills/` or `.github/skills/` or `.claude/skills/` | copy `skills/writing-for-markdown-okf-schema-studio/` | host docs |

Notes: no manifest is invented; Codex `.codex-plugin/` is deliberately omitted (overlay only). Marketplace
name `markdown-okf-schema-studio` is not reserved; avoid `gsemet-markdown-okf-schema-studio` (GitHub
download-folder rule).
