## Test and failure before the change
New test "Auto keeps the breakout of a table while a cell is edited, and the column width while its source is
edited" (@tests_req LAYOUT-023). It renders a wide table in Auto, injects the cell editor frame as the page builds
it (selected cell + `[data-sphinx-preview-table-cell-editor]` holding a textarea), runs a layout pass, expects
wide; then removes it, sets `data-sphinx-preview-editing` on the table and expects not wide.
On the unchanged code it failed: `light: an open cell editor leaves the table at its breakout (width 688 px) -
false !== true`. After the change it passes (3/3 in the file).
Note: the unit-harness fake DOM cannot see a textarea through `querySelector`, so a fake-DOM test could not fail
before; a real browser was needed. Run it with `node --import ./scripts/register-myst-patches.mjs --test ...`
(plain `node --test` cannot load markdown-it-dollarmath).
