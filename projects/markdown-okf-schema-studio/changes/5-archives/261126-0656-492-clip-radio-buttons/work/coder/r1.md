   scratch Remotion folder (`<scratch>/remotion`, `src/story.json`, `public/clip.mp4`) is shared by all

   isolate parallel clips: each also needs its own `CLIP_SCRATCH`. Rerun with `CLIP_SCRATCH=C:/okfclip492`
   (fresh Remotion install and VS Code download) passed cleanly. No kit change made. This is worth a line
   in the recipe or the kit (follow-up, not this CR).

   lines matched within the 2 s poll, `verify` found `plan.md` equal to `EXPECTED`.
