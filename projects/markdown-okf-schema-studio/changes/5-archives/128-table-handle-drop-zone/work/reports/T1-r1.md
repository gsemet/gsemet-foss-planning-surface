# T1 round 1 report (CR 128)

## Result
While a row or column handle is dragged, the whole table and the strip of the handles are a drop zone.
The marker shows on the nearest gap, follows the pointer, goes when the pointer leaves the zone, and a
release in the zone moves the row or column. Release outside cancels (no edit).

## Reproduction (real VS Code window, unchanged code)
- Pipe table: column handle held over the handle strip above the header (and over the other handles):
  no marker. Row handle held in the strip left of the table: no marker. Over a body cell the marker
  worked on the old code; after the pointer left the table the last marker stayed (stale).
- Before-shots match the user's report: dragged column dimmed, no drop line while the pointer is in the strip.
  The list-table run stopped at the pipe failure on the old code (same code path, same table DOM).

## Root cause
Drop listeners were bound only on each row and each cell; the handle strip (a layer over the page)
and the table gaps had none, and nothing cleared the marker outside.
