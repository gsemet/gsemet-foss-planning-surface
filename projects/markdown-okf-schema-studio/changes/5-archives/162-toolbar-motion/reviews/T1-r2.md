   `hidden = false` in the same task. By then the animating mark from `startHint` has expired
   (200 ms), so adding it again starts `sphinx-preview-toolbar-unroll` (`pageChromeStyles.ts:257-263`,
   `from { height: 0 }`). I reproduced this in headless Chromium with these CSS rules and the same
   DOM steps. Height per frame after the click: `120 → 0, 12, 38, 64`. The rows visibly collapse

   `:187-196`: after a chevron click during the hint, the rows carry no
