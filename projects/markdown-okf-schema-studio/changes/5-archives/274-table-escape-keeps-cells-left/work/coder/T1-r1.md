# CR 274, T1, round 1: coder report

## Change

Escape in a table cell cancels only the cell it is pressed in. A new edit flag `keptCellChange` is set in
`switchTableCell` when the cell left (Tab, arrow, click) differs from its opening text. On Escape
(`cancelTableCellEdit`, used by the text box handler and by the document-level handler): with the flag, the
open cell goes back to `cellTextAtOpen` in the input and the model, and a final save is posted (no
`previewEditCancel`), so the buffer keeps the cells left and the page redraws from the buffer; without the flag,
`cancelBlockEdit()` as before (TABLE-025 nominal scenario unchanged). Enter, blur, Tab, IME rule unchanged.
