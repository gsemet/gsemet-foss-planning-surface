   page; the headless harness has no host, so the editor never closed. check_table_menu_above_handles
   then pressed Escape and clicked a cell without effect (editor finishing), and the final frame
   kept the saving editor, scrolled out of view, hence clipped.
   The round-2 leftover patch simulated the host render but copied the table bar
   ([data-sphinx-table-menu], which sits in the content flow above the table) into the new content:
   two bars, so the stacking check failed ("table bar or row handles missing") and 60-table-bar-groups
   stayed clipped (overlay-clipped on the stale bar). Fixed by dropping the bar from the simulated
   render too, and asserting the editor and its bar are gone afterwards.
