# T1 round 1 report - CR 116

## Root cause
The renderer maps a list followed by a blank line up to that blank line (`data-end-line` = the blank line).
The page sends that range as is; `planBlockMove` refuses a range ending on a blank line with
"The preview is out of date. Refresh it and try again." So every move involving a list was refused.
The existing e2e hard-coded ranges that ended on the last list item, so it never saw the mapped range.

## Files changed (worktree markdown-okf-schema-studio-wt-116)

  (`withoutTrailingBlankLines`); `STALE_REQUEST` now re-exported from the new file.
- src/core/protocol/staleRequest.ts (new): shared `STALE_REQUEST` constant (page cannot import sourceEdits: node deps).
