# Session titles put the batch number last

The user, 2026-11-17: a session title that carries a batch number puts it last, in parentheses,
after the role. `[Battle] 💬 Chantier 21 · CoS` reads as "Chantier 21", a project name; the user
wants `[Battle] 💬 Chantier · CoS (Batch 21)`, and the same for the Foreman:
`[Battle] ⚙️ Chantier · Foreman (Batch 21)`.

Titles without a batch (`[Battle] 💬 Chantier · CoS`, the Griller's) do not change.
