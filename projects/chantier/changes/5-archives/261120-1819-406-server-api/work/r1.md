## Divergences and risks to know

- `http.poll` is an extra schema entry (the long-poll body); the ops table is untouched.
- `/api/board` stays full and gains `protocols: [1]`; old routes stay registered.
- `routes._judged` now runs the seats check for `/api/v1/` answers too, early 401/405 included.
- `scenario/run_scenario.py`: the two `remote_board` Location checks now expect the relative
  form (needed now; the rest of the scenario is round 3).
- A write with no live writer is refused by the surface store's existing 409 path, not a new
  check; `writer.sync` keeps `{error, code, writer}` in its 409 body.
- The long-poll holds a threadpool thread for up to `HOLD_S`.
- The first two `project` reads of a freshly served project move the rev (the live reading
  starts and settles); tests warm up with three reads.
- `Context.push` is typed `Any`: the import-cycle test counts a TYPE_CHECKING import.
- Test cost: one batch per `board` fixture (0.25 s), so the op and key matrices loop inside one
  test instead of being parametrized; the file runs in about 5 s.
