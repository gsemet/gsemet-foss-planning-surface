# Answers

Grilled with the user on 2026-11-14.

Short name: `grill-format`.

1. grill-format-Q1: **Who follows the format.** The Chief of Staff and the Griller, for every grill and
   specification question. The Release driver keeps its short yes/no confirmations before an
   irreversible action. (Chosen over: every role that asks the user a question.)
2. grill-format-Q2: **The reference.** Always the item's short name plus the question's number, e.g.
   `ready-wording-Q3`, `grill-format-Q1`, even when the CR already has a number. (Chosen over:
   the CR number when it exists, e.g. `CR248-Q3`, the short name otherwise.)
3. grill-format-Q3: **How many questions at once.** At most 5, necessarily independent of one another, and never
   two subjects mixed in one series: one series is about one item. The user rephrased it: never
   two CRs in the same call of the question tool. (The user's own answer; the
   options offered were up to 4 grouped by subject, or up to 2.)
4. grill-format-Q4: **Without the question tool** (Remote Control, Copilot): the same text, and the user answers
   by reference, e.g. "Q1 A, Q2 B". (Chosen over: one question per message in text.)
5. grill-format-Q5: **The tool's limit.** A series holds as many questions as the host's question tool takes, up
   to 5: 4 on Claude Code, whose tool takes 4; 5 on Copilot. (The user's own answer; the options
   offered were two tool calls in a row, the fifth in text only, or always 4.)
6. grill-format-Q6: **One subject.** A subject is one item: a series is about one CR or backlog item, and may
   touch any of its facets (scope, words, icons). (Chosen over: one theme within an item.)
7. grill-format-Q7: **Grilled enough.** Yes: triaged P1, specified, then added to batch-17 after
   CR-249.
8. grill-format-Q8: **The reference in the record.** Yes: each answer recorded in
   `02-answers.md` starts with its reference, as here.
9. grill-format-Q9: **Numbering.** The question numbers keep counting across one item's series
   (this grill's second series started at Q8), so each reference is unique for the item's life.
10. grill-format-Q10: **Copilot.** Copilot has a question tool that takes 5 questions per call.
    (Chosen over: text only on Copilot.)
11. grill-format-Q11: **Remote Control.** The user, on Remote Control from a phone, sees the same
    question tool, with 4 questions: Remote Control relays Claude Code's tool, so its limit is the
    tool's, 4. This corrects the assumption that Remote Control has no question tool; the text-only
    case (answer 4) remains for a host or surface that truly has none.
12. grill-format-Q12: **The short name.** A shorter name the asker picks once for the item and
    keeps for its life, written at the head of `02-answers.md` (here `grill-format`), not
    necessarily the folder's slug. (Chosen over: always the folder's slug without the CR number.)
13. grill-format-Q13: **More options than the tool shows.** At most 4 options per question, on
    both sides: the asker keeps the 4 most plausible; the tool's own free answer ("Other") covers
    the rest. (Chosen over: splitting the question in two.)
14. grill-format-Q14: **The recommendation.** Always option A, on both sides, marked
    "(recommended)" in the user's language. (Chosen over: the natural order, the recommended
    option marked where it stands.)
15. grill-format-Q15: **Two sessions on one item.** One session grills an item at a time; another
    waits or takes another item. (Chosen over: duplicate references accepted.)
16. grill-format-Q16: **"Grilled enough?"** It follows the same format: a reference, options
    (specify, backlog, not yet) and a recommendation, as grill-format-Q7 did. (Chosen over: a plain
    yes/no after the restatement.)17. (observed 2026-11-14, corrected by the user) **The text before is always written.** On Remote Control from a phone the user does see the text written before the form, by scrolling up. The fault was the asker's: the text with its references was sometimes written and sometimes not ("Des fois tu l'as bien fait (je voyais les références), des fois pas"). So the rule holds without exception: every call of the question tool is preceded by its text, with each question's reference, context, options with examples and the recommendation; the form stays the short mirror of that text.
