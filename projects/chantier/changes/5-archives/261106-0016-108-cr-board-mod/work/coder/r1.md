## Decisions I took where the spec left room

- The rows' severity icon is the one already in `label` (the CLI's `label` starts with it); landed rows show the state.
- "Live" for the Foreman-silent line: batch state `open` and at least one CR `working`; a null heartbeat says nothing.
- Waiting count in the header: blocked + ready CRs + unread asks.
- `steps` line: `name verdict` joined with ` > `, a repeated text kept once, a step still ahead in brackets.
- Non-UTF-8 detection: `$.fs.read` as text, then a U+FFFD in the result (a file that genuinely holds U+FFFD is
  misreported).
- `skill.prompt` matches any skill whose name, after an optional `plugin:` prefix, is `chantier`; the pane is opened
  after the prompt is built, the prompt returned as `next` gave it. It opens in whichever session fires it.
- All mod code is one module (`register.tsx`): I did not rely on relative runtime imports, which the docs do not state.
- A pane that `ui.open` reports unplaced starts no timer.
