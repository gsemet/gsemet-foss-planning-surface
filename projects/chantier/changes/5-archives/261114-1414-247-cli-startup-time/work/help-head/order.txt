usage: chantier order [-h] [--batch BATCH] [--epoch EPOCH] [--note NOTE]
                      [--fix-for FIX_FOR] [--release]
                      kind [cr]

positional arguments:
  kind               add [--release], after, drop, merged, note, rounds,
                     slots, budget, qa, mode (series to stack); for the
                     release CR: approve, grant, confirm; the Foreman: done
                     <O-k>, merged --epoch, add --fix-for --epoch
  cr                 the CR, or the order id for `done`

options:
  -h, --help         show this help message and exit
  --batch BATCH      batch number, 4 or batch-04 (default: $CHANTIER_BATCH,
                     else the only running one)
  --epoch EPOCH      the Foreman's epoch; stale ones exit 3
  --note NOTE        add: <folder>, or a release's fix file; after: the CR ids
                     it waits for, comma separated, or - for none; note: the
                     line; rounds, slots, budget: the number; qa: what to
                     test; approve: the action; grant: releases=N fixes=on|off
                     budget=N; confirm: the user's word to run the release
                     procedure, once the other CRs are merged
  --fix-for FIX_FOR  add: the release CR this fix is for
  --release          add: the folder is the batch's release CR, which waits
                     for every other CR (refused once it has started)

exit=0
