`agents set stack -`, hold no live lease and have no number to pass. `core/leases.py` `require`,
`claim` and `renewed_in_session` take `ended_ok`: an ended lease needs no number there (used by
`ship`, `stack <crs>`, `stack --draft|--out-of-draft`, `forge-stack`). A test covers it
(`test_a_ship_of_a_cr_whose_lease_ended_needs_no_number`); `driver.md` says so. The World forgets a
number after a successful handback and after `agents set <unit> -`; `ready_words` clears the lease
when it sets a CR back to `working`.
