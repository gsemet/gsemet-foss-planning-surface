# PR 322 fix(cost): show the same steering figure in the board receipt and the cost text
## Summary

After a batch switched who steers it (Foreman to direct mode, or back), the web board's cost receipt left out the Chief of Staff's steering done outside its claim windows, while the `cost` command printed that figure. The two now come from one decision, so the receipt and the `cost` line `Chief of Staff, steering the batch (outside the budget)` show the same dollars, the same calls and the same "unknown".

## Deliverables

One decision on the Chief of Staff's read, drawn twice (`commands/cost/sessions.py`):

```python
def steer_outside(c: _Chief): ...   # unknown | the figure | none, from the read alone
# _chief_lines(c)   -> the text line (unchanged)
# chief_outside(read) -> outside.steering in the receipt (JSON shape unchanged)
```

| Case (read alone) | `cost` text | Receipt `outside.steering` |
| --- | --- | --- |
| steering calls held outside the windows, or no call inside them | the figure | the figure (before: none on a direct batch) |
| only untimed calls outside, some calls inside | unknown | unknown (before: none) |
| nothing outside, all inside | no line | none |

On a direct batch that never switched, the receipt now also shows a steering part whenever the text prints one. Closed batches keep the receipt their record held at close.

## Blast radius

Grade: **1**. A cost display; `git revert` restores the previous behaviour.
