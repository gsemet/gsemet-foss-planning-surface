## Hand-over

- Exit codes: the spec says "exit 2 (`EXIT_USAGE`)" for an unknown capability, but `EXIT_USAGE` is 1
  and `EXIT_PRECONDITION` is 2 in `core/errors.py`. I followed the observable "exits 2" (scenario
  check and test 7): the command raises with `EXIT_PRECONDITION`. For no host and no batch, the
  refusal is `detect_host`'s own, which is `EXIT_USAGE` (1), so test 9 asserts 1, not 2.
- `message-limit` is `untested` although the card says "Proved in use, same ... no dated trial": the
  spec's list of 13 omits it, and the mark rule says doubt makes it untested.
- Host resolution: an explicit `--batch` or `CHANTIER_BATCH` is resolved as usual (a missing one
  is refused); with none and no open or paused batch, or no repository, the session's host is
  used; with several running batches `resolve_batch` refuses.
- The proof files' first `Mark:` lines are long where the card's justification is.
