# Board: the user's inbox, a page of what needs the user

The user (2026-11-21) wants a new page of the web board, right after Home in the navigation: an
inbox of what needs them. They mean to stay on that page, and it tells them what arrives: an agent
has a question for the user, a PR is to review, a PR is ready to merge. Each entry has easy
actions: snooze, remind me later, discard, and act.

It is not the planning inbox (`1-inbox`, the requests to grill): it is a notification inbox for
the user. "Act" opens links only (the PR on the forge, the CR and its question); the board still
edits no batch and messages no agent (AGENTS.md).
