# Intent: the web board documented, with screenshots taken by a command

Once the board server exists (after visualization-backend, board-read-views, board-backlog-edit
and surface-autosync), `docs/` gets pages that explain how the web board is launched and how it
works, illustrated by screenshots that one command run by hand retakes, over a fixed demo
planning folder, at PC and phone widths. The README shows one representative screenshot: the web
board with a batch running, in place of the pane's image. The CR also goes through `docs/` and
fills the gaps it finds.
