Web board: visual refresh mock-ups

Static prototypes for the inbox item board-visual-refresh. Each file shows the same screen: the board with its navigation, the Batch view of a stack batch (six CRs, CR-302 to CR-307) and a strip of Triage backlog cards. Each starts with a caption bar naming the option and its trade-offs.

Every option other than the baseline starts from one refresh base: Layout A, comfortable spacing, an Inter-like font at 400/600, one deep teal accent with state dots, white hairline cards and a dotted grid under the graph. Each file changes one aspect of that base, so options from different groups combine.
