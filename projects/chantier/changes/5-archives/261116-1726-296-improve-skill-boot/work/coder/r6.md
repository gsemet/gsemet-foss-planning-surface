## Review of round 5 and changes

- `board/autosync_tool.py`: independently inspected the existing
  `chantier.procs.alive_since`. It uses psutil's `Process`, `is_running`, `status`
  and `create_time` on both platforms, not a signal. It rejects zombies, gone
  processes and reused PIDs; access-denied follows the explicit unreadable policy
  (conservative on Windows). The round-5 replacement of `os.kill(pid, 0)` is
  correct. This round additionally ignores non-object participant records and
  nonpositive PIDs. Its spawn docstring now describes actual pipe capture.
- `test_board.py`: the current-PID reuse test now forbids both `os.kill` and
  `Popen`, so a regression cannot signal pytest or launch autosync. Twelve
  simulated cases exercise live/reused/gone/denied/zombie/invalid identity under
  Windows and POSIX policies without accessing a real PID. Scratch participant
  records are used, never the live planning surface.
- The round-5 delayed watcher still used a 0.5-second busy spin, so its race was
  not fixed. Both delayed-failure and live-success children now block on stdin;
  the test releases them only after observation and watcher registration. There
  is no elapsed-time assumption or spin. Tests clean up only their own children.
  `watch_join` returns its watcher thread, allowing tests to join it and assert
  the final diagnostic or absence of diagnostics after completion.
- `startup-manifest.json`: round 5 named the short `host-core-*.md` as Foreman's
  host Startup core. Those files have no such heading and were already counted
  whole, so their nonexistent sections were silently skipped. Corrected the
  entries to `hosts/claude-code.md` and `hosts/copilot.md`: the actual extra
  Startup core sections contribute **751 / 891 bytes**.
- `test_startup_manifest.py`: validates sections even when their whole file is
  counted; measures original bytes without newline normalization; merges unique
  byte ranges, including nested/overlapping/duplicate reads; includes every
  string and section in reload action readings; asserts Foreman's actual host
  Startup core is declared. A real oversized additional reload file must trip
  the limit. The limit and acceptance criteria remain unchanged.
- `work/pr-body.md`: corrected startup/reload table, evidence and known gaps.
  Removed the false assertion that the failing scenario units are untouched.
