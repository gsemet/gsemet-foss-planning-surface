## Decisions and deviations

- Pill, dot and panel are pure markup functions plus store flags (the real frame paints from
  `drawFrame` and delegates events), not the spec's `mountAutosync`.
- POST success shape is `{autosync, output, now}`; refusals are 409 `{error, code, autosync}`,
  failures 502 with code `failed`.
- A surface with no state folder is classified `stopped` with `no_group: true`.
- The spawned process is called "join process" in the board line; the join's pid is not claimed
  to be the participant's.
- Plural wording is "1 participant" / "N participants". A site whose script is missing gives P13
  but no status line.
- The panel is rendered in both slots; CSS hides the one in the hidden container.
- Colour tokens are the prototype's exact hexes, in `tokens.css` only.
- `last_push` is remembered in-process by the board (the tool records none).
- Outside-click closing uses a capture-phase listener so a repaint does not close the panel.
