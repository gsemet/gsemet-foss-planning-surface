## Choices the spec left open

- "cut at 160 characters with `…`": the first 160 (120 for a restart's note) characters are kept,
  then `…` is appended.
- Plurals: `(1 time)` / `(2 times)`, `1 Driver restart` / `2 Driver restarts`, `failed 1 time` /
  `2 times` (the spec writes `(<k> times)` for refusals; one plural rule for all three).
- A blocked hand-back's refusal text: `refused` then an optional `:` stripped, so
  `refused: x` and a note `refused: x` group into one point.
- A refusal point's `crs` with no CR on its events reads `refused on no CR: …`.
- A cost outlier rests on the first window event of that CR (its `(events n)`); a median of 0
  gives no point.
- A red gate with no head prints no ` at …`.
- `--write`: a file ending with `\n\n` (or `\n\r\n`) gets no separator, one ending with `\n`
  gets one `\n`, any other non-empty file gets `\n\n`.
- `--since` refusals: one text form, `retro draft --since <s>: <why>; `retro draft --since 0`
  drafts from every event` (EXIT_USAGE, 1).
