# Redefine the factory mode: running batch or next batch

From the park-live-cr grill (2026-11-21): `3-ready` always means the next batch; `4-batch/1-pending/` is the running batch, which a factory batch takes on its own; the grill and the board let the user put a CR in either, in every mode. The user asks to redefine the factory mode from zero.
