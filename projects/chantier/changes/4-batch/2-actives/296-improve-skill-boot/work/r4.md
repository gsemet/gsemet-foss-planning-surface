- `session-start.md`: reload now rereads only the common, selected-host and role startup
  cores plus manifest startup sections; action readings are loaded immediately before the
  action. Board launch wording no longer says a fresh board joins autosync.

  the concepts startup section, and each Driver action requires `driver.md` plus `Your means`
