# Round 5

## Changes

- `autosync_tool.py` now uses `chantier.procs.alive_since` with the participant's
  `since` timestamp (or record mtime), including the existing Windows unreadable
  policy; it no longer probes with `os.kill`.
- `test_board.py` uses the safe helper for the live current PID and asserts the
  successful watcher is quiet before cleanup. The delayed and live watcher tests
  passed 200/200 across 100 runs.
- `session-start.md` reload text was reduced. The manifest declares its reload
  section and host-specific Foreman host-core sections. Startup tests now count
  unique transitive reads and enforce 12,288 bytes for every role/host reload,
  including router/SKILL.md.
- `test_startup_manifest.py` prints both startup and reload measurements.
