## What I chose where the spec is unproved or ambiguous

- `read_defaults` needs a role list per host: I build it from `agents/` and `com.github.copilot/agents/` of the checkout (not `plugin_files.plugin_roles`, which depends on the installed skill's location), then `layers.default_model(tree, "claude", role)`. Verified names: `griller_host.CLAUDE`, `CLEARED_ENV`, `end_tree`, `result`; `transcripts.PRICE`, `LONG_CONTEXT_TOKENS`; `layers.read_defaults`, `layers.default_model`. `griller_host.environment(run)` takes a `Run` (it cannot be built here), so the environment filter is reimplemented from `CLEARED_ENV`, case-insensitive. I do not add `CHANTIER_HOST=claude` (the spec says the quiz's own environment minus `CLEARED_ENV`).
- Price lookup is reimplemented (exact id, or minus `-YYYYMMDD`, `>100k` tier above `LONG_CONTEXT_TOKENS`) because `_price` is private. Price tuple index 1 is the 5-minute cache write, 4 the output.
- Shared seam module state: when `quiz.py` runs as `__main__` it registers itself as `sys.modules["quiz"]` so the judge's lazy `import quiz` gets the same module (one temporary folder). `quiz_judge.py` imports only the standard library at module level; its call goes through `quiz.call_claude` (lazy import), so it too needs the root environment, as the docstring says.
- `plan total: <n> runs`: n counts role runs (cases x 3), not judge calls.
- Cap while running: checked before every call, role run or judge. A reply already received but not judged because of the cap is `not run` ("cap reached before the judge"). `cap reached: <n> runs not started` counts role runs not started. A capped run exits 2 unless a call errored (4).
- Exit precedence: 4 (any call failed) over 2 (cap) over 1 (F4 violated) over 0. A role run `error` counts as not passed for F4.
- Per-run JSON keys: `verdict` (PASS, FAIL, error, not run), `reason`, `cost_usd` (the role call), `judge_cost_usd` (extra key), `error`. A case with every run `not run` has `passes: null` and is skipped by F4 and the role counts.
- `spend` line: `spend: $X measured over N calls`; with no call measured, `spend: not measured over N calls`; then `K calls not measured`. `spend.measured` is null in the JSON then.
- Results date-first form of `2-backlog/P3/evals-rework`: not merged here, so `quiz-<date>-<label>`.
- `--cards <x>` is a folder when `x` is an existing directory, else a git ref. With no `--cards` and no manifest in the working tree, the kind is `brief`.
- `brief` boot (folder, or no manifest): `python -m chantier --project <repo> brief <role> [--cards <folder>]`. The "needs `chantier brief`" line is printed only when the CLI's error is `invalid choice: 'brief'` (verified today); any other brief failure prints the CLI text and exits 2 with a different line. The printed short prompt's last line must be `Read <file> whole, first.`.
- `git archive` unpack uses `tarfile.extractall(filter="data")` on `skills agents com.github.copilot` as the spec says; it worked on Windows here.
- Redaction: home folder forms (native, posix, escaped) to `~`, then the username (from `getpass`, `USERNAME`, `USER`, `LOGNAME`, home's name) to `<user>`; a name shorter than 4 characters is matched as a whole word only. Applied to every string at record time (so the printed reasons too), and to the whole data before `--save`.
- `evals/kit/quiz.py` exposes `after_table()` (reads `AFTER` from `tests/test_start_reading.py` by `ast`, so the dry run has one source). The old-cards boot bytes equal `AFTER` exactly for foreman, cr-driver, stack-driver, qa-driver, release-driver, and are 1 below for chief-of-staff, with 541 to 660 header bytes on top.
- Line endings: the checkout's working files are CRLF (autocrlf, the index is LF); `dry_run.py` and `README.md` keep CRLF, the two new files are LF.
