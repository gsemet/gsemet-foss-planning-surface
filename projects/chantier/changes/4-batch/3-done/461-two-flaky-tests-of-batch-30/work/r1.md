# CR-461 round 1

## Changes
- `skills/chantier/scripts/cli/src/chantier/commands/live.py`, `once()`: after the wait loop, under the lock, call `_check_only(models)` before printing. Cause: a reader raises the `--only` error inside `_read` after its last feed and before `failed.append`; the main loop could see every model complete in that gap, break, and print a screen with exit 0. Now the finished models are judged by the main thread whatever the order.
- `tests/test_live_model.py`: `test_once_refuses_an_unserved_only_before_the_reader_keeps_its_error`, forced interleaving: `_start` is replaced by one that feeds each model completely and keeps no error. Before the fix: FAILED (printed a screen, no error). After: passed.
- `tests/test_triage_moves.py`, `test_w2_...`: real cause. A child's working directory is taken by the child itself during its start, after `Popen` returns, so under load the folder move ran first and succeeded (seen: `assert (0 == 4)`, 1 failure in about 48 loaded runs before the fix). Now the child prints `up` once running and the test reads that line before the move. No sleep, retry or skip.
