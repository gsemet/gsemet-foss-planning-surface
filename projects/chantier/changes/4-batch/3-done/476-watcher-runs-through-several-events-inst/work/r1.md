## What changed, file by file

CLI (`skills/chantier/scripts/cli/src/chantier/`):

- `hub/batch_prs.py`: `running_batch` is replaced by `followed_batch(repo)`. It returns the batch
  when it is running, or paused with `to_read(d)`. It returns None for a closed batch, a paused one
  with no PR left open, no file, or an unreadable file. `BatchPrs.collect` and `judge` call it. The
  module and function docstrings say "the running batch, or a paused one with open PRs".
- `hub/waits.py`: `Waits.collect` calls `followed_batch`, and the docstring follows.
- `hub/lines.py`: `watch_lines` prints the hub's line for the followed batch (running, or paused
  with `to_read`).
- `declare/interests.py`: `HELP` now reads "the PRs or MRs of the batch that runs or is paused with
  open PRs, which the forge hub reads".
- `hub/watch.py`:
  - Idle end: it comes only with no batch in flight (`followed_batch is None`). The batch is read
    at most every `SEAT_CHECK_S`. The 2 h count from the latest of the start, the last waking line
    and the last moment a batch was in flight.
  - `--stream`: at an `EVENTS` point, `tell()` prints the block with `STREAM_TOLD` in one flushed
    write, empties the block, clears `last_new`, sets `told_at`, and the watcher runs on. The next
    block comes no sooner than `wake_every` after the last telling.
  - Without `--stream`, the behaviour is unchanged.
  - `watch()` refuses `--stream --once` with `watch: --stream and --once do not go together` and
    `EXIT_USAGE`.
  - Docstring rewritten.
- `hub/watch_reads.py` (new): `Rules` (with a new `stream` field), `seat_moved`, `subscription`,
  `open_batch` and `once`, moved out of `watch.py`. This keeps `watch.py` at or under 400 lines, as
  `test_code_targets` requires (now 393).
- `hub/watch_lines.py`: `STREAM_TOLD`, worded exactly as the spec gives it.
- `hub/times.py`: the `QUIET_S` and `IDLE_END_S` comments follow the new rule.
- `hub/autostart.py`: `watch_command` appends ` --stream` when `detect_host()` is `claude`. It does
  not for `copilot`, nor with no host (a `ChantierError` gives the plain form). Every line built
  from `watch_command` follows. `pull_command` is unchanged.
- `declare/watch.py`: `HELP` states the new end rule and the stream form, and the `--stream` flag
  has a help line.

Config: `config/chantier.defaults.yml`. The comment on `events.wake_every` said "a watcher ends no
sooner than..."; it now says "tells no sooner than this after its start or its last telling".

Tests (`skills/chantier/scripts/cli/tests/`):

  would have gone past 400 lines:
  - The stream: two blocks, each closed by `STREAM_TOLD`, parametrized with `wake_every` 0 and 30

  - A batch going from running to closed mid-run: `IDLE` comes one idle period after the last poll
    that saw it in flight.
- `test_watch_events.py`: adds the `--stream --once` refusal.
- `test_watcher_autostart.py`: `watch_command` and `not_running_line` for claude, copilot and no
  host. The expected not-running line gains ` --stream`, since the test host is claude.
- `forge_world.py`: gamma is paused with cancelled CRs (`CALLS = 2` is kept).
