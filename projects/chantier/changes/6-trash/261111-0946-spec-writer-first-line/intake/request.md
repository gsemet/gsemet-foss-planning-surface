# The CLI prints the spec-writer's first prompt line

Batch-09 retro, 2026-11-11 (`4-batch/retro.md`, point 14), kept as a friction that costs tokens.

## What happened

Spec-writers were refused because the first line of their prompt was not the one they expect.
The relaunches made duplicates; three had to be stopped by hand.

## Proposed fix (to grill)

The CLI prints the exact first line for a CR's spec-writer, as `take` prints a Driver's facts,
so the Chief of Staff copies it instead of writing it.
