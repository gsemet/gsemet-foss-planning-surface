# Web board: feedback on a large screen

The user filed five screenshots of the web board on a large screen (in this CR's folder), with no
text. Their reading, confirmed with the user on 2026-11-16 (02-answers.md):

1. `sidepanel-not-closing-when-switching-view.png`: a CR's side panel stays open when the user
   switches view (Kanban to Home).
2. `triage-hovering-create-scrollbar.png`: hovering a card in the Triage view's P1 group makes a
   horizontal scroll bar appear at the bottom of the group.
3. `triage-cell-very-large-compared-to-other-pages.png`: in the Triage view the backlog cards
   take the whole screen's width, far wider than on the other pages; and a card's preview shows
   the raw frontmatter (`--- type: cr-intent id: ...`) instead of the text.
4. `compressed-sidepanel.png`: the side panel is too narrow on a large screen; its content (a
   table in a round's file) is compressed and overflows.
5. `home-multiproject.png` (the user's note: "Missing: where the project has been stated (path);
   model in project (no need to display 'all project') / multi-project-surface"): the selector at
   the top left shows the surface (its name and path, a multi-project surface) instead of "All
   projects", and each project's line shows where the project is declared (its path).
