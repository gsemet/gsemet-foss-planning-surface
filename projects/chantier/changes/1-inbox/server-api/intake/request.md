# Server API over WebSocket, UI as a separate client

The surface server (the writer, chantier's equivalent of Vercel Board: one per surface, it keeps the state and exposes the server) exposes an API over a WebSocket, with HTTP as the degraded case (behind a proxy, for instance); the web UI moves out of chantier board and becomes one client among others, so several UIs or native Android or iOS apps can be built. The user's words (2026-11-20, planning-server's grill, answer planning-server-Q29): 'cette ecrivain est celui qui maintient l'etat et expose le server. C'est donc bien l'equivalent de Vercel Board. Neamoins chantier board expose aussi la UI et je pense que il faut le sortir pour que tout passe en websocket ou HTTP (cas degradé derriere un proxy par exemple). Ca me permettra de faire plusieurs UI ou app android ou ios native par exemple'. Comes after 2-backlog/P3/planning-server.
