# An outside poller writes issue events into the journal

Split off `forge-connectors` by its spec critic (2026-11-20, settled by the Chief of Staff): the outside-poller half of planning-server-Q24 ("Pour les d'événements sur les issues je penses que je ferais un polling extérieur"). `chantier interests` lists what the CRs wait for (the issues their `issue:` lines name); `chantier journal add issue@1` lets an outside poller append an issue event, refused when no CR names the issue, naming every CR folder that names it; the `issue@1` type is published in Part A's schemas; the watcher wakes on it when the poller says so (default yes). Its first specification text is forge-connectors' 03-change-spec.md at surface commit 7fd03eab (§4.2 `issues`, §5, §7.1 edits 2 and 3, "Writing an outside poller", the scenario case `outside_poller`), with the decisions FC-2, FC-3, FC-4 and FC-7 in forge-connectors' 02-answers.md.
