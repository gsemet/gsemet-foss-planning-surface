# Release notes: kind-first plain text and framed images

Teach the Release Driver to write release-note text that states the kind of release first (feature, fix, restore, breaking, internal), says each change in one plain sentence, states bad news plainly, and to capture images framed on the changed element. The notes' structure and format do not change. Source: the Fable audit of markdown-okf-schema-studio's notes, 2026-11-24 (see `intake/request.md`).
