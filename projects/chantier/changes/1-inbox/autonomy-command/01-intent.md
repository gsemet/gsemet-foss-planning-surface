# Autonomy command: go on alone while the owner is away

## Intent

The owner often tells the Chief of Staff, before leaving, to go on in full autonomy. `/chantier:autonomy` makes that one command: it names first what would block while the owner is away, then goes on alone. A question that comes up is decided with the recommendation and recorded "to confirm by the owner". It never merges, releases or deletes without the owner. It accepts a budget and a number of rounds. Claude Code and Copilot.

Split from `1-inbox/shortcut-commands`, which keeps the four batch commands and the shared base. This CR comes after it.
